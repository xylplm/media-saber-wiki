# Media Saber 媒体库管理工具

Docker：https://hub.docker.com/repository/docker/xylplm/media-saber

## 功能：

一款适合自己人用的媒体管理工具。

前端：Angular
移动客户端：Flutter
后端：GO

由多位热心Pter共同努力，立足于开发自用，完全自主开发，做一款全新、高效、稳定、快速、方便好用、功能强大的媒体管理工具！

鉴于NT MP等公开项目的不稳定性，本项目为私密项目，仅开发组自用和受邀用户小范围使用。
