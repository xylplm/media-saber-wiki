## 🚀 功能总览

**云端存储** 是 Media Saber 提供的一套完整自动化方案，用于实现：

> **订阅下载 → 自动上传云盘 → 云端整理 → 生成 STRM → Emby 302 直链播放**

该方案的核心目标是：

- 本地几乎不存储媒体文件
- 播放时直接走云盘直链（302）
- 订阅完成后全流程自动化
- Emby / Jellyfin 体验与本地媒体一致

---

## 🧩 适合人群

- 使用 115 / 天翼 / 夸克 等云盘
- 已有 Emby / Jellyfin 媒体服务器
- 希望降低本地硬盘占用
- 追求「订阅后不再管」的用户

## 🚀 首次大批量导入快速方案

如需进行 **首次大规模导入** 115 网盘内容并生成 STRM，可使用专用工具快速完成：

::: tip 📌 快速导入选项

**推荐方案：** [🔗 115网盘目录树生成STRM](/usage/cloud_storage/115_tree_gen_strm)

- 在 115 网盘端一键导出目录树
- 在 Media Saber 中导入并批量生成 STRM
- 相比逐个手动配置，可节省数倍时间
- 特别适合媒库体积大、文件众多的场景

:::
