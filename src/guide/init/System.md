## 💡 参数配置建议

:::info 📝 默认配置说明
在 **系统设置** 中的大部分参数保持默认即可。这些默认配置已经能够满足大多数场景的使用需求。
:::

:::tip 🎯 高级配置
如果您有更高级的管理需求或个性化习惯，也可以在熟悉系统后，根据实际情况对相关参数进行调整。
:::

## 🎓 常见设置项

系统设置中常见的可配置项包括：

| 设置项 | 说明 | 默认值 | 调整建议 |
|--------|------|--------|---------|
| 代理设置 | 网络代理配置 | 无 | 需要时配置 |
| 端口设置 | 应用访问端口 | 3000 | 无冲突时保持不变 |
| 日志级别 | 系统日志详细程度 | 普通 | 调试时可改为详细 |
| 性能参数 | 系统资源占用 | 推荐值 | 根据硬件调整 |
