# 🟠 飞牛影视 (FNOS)

## 📋 简介

飞牛影视（FNOS）是飞牛系统中的媒体服务能力，用于管理和播放媒体内容。

## ⚙️ 配置说明

### 🔧 配置字段

- 📡 **服务器地址（host）**：FNOS 服务地址，格式示例为 `http://192.168.31.2:5666`
  - 说明：配置 IP 地址和端口
- 👤 **账号（username）**：飞牛影视登录账号
  - 说明：注意，这里是飞牛影视账号，不是设备账号
- 🔐 **密码（password）**：飞牛影视登录密码
  - 说明：你的密码

> 💡 服务器类型编码：`600`（fnos）

### 📋 配置步骤

1. 在媒体服务器页面点击“新增媒体服务器”
2. 选择“飞牛影视 (FNOS)”作为服务器类型
3. 填写服务器名称（自定义）
4. 输入服务器地址（`http://IP:PORT`）
5. 输入飞牛影视账号与密码
6. 点击“测试”按钮验证配置
7. 测试成功后点击“保存”

## ⚠️ 注意事项

- 确保 FNOS 服务地址在当前网络环境可访问
- 账号密码需具备访问媒体库所需权限
- 建议优先填写可被客户端访问的地址（内网/外网按实际场景选择）
- 若测试失败，优先检查端口、防火墙与账号密码是否正确
