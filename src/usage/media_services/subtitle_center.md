# 🎬 字幕中心

字幕中心用于配置字幕来源、媒体库策略，并查看异步补齐任务。它和媒体库同步、媒体健康中心联动：

1. **媒体库同步**负责扫描本地侧车字幕，写入字幕快照
2. **字幕中心**按策略搜索、下载、写入字幕
3. **媒体健康中心**只读取已有快照，发现缺字幕问题并一键跳回字幕中心处理

> ⚠️ 健康中心不会在查询时扫盘或访问外部字幕源；缺字幕事实来自字幕快照。

## 快速开始

1. 先完成 [媒体服务器](/usage/media_services/server.html) 同步
2. 在字幕中心配置至少一个可用来源，详见 [字幕来源配置教程](/usage/media_services/subtitle_providers.html)
3. 为需要自动补齐的媒体库新增策略并启用
4. 点一次“扫描媒体库”，让路径状态和字幕快照先就绪
5. 需要排查缺字幕时，去 [媒体健康中心](/usage/media_services/media_health.html)

## 页面分区

### 概览

- 查看最近任务、待处理候选、失败/冷却来源
- 支持手动检查单个媒体，或打开批量巡检

### 任务

- 查看排队、处理中、待选择、已完成、失败任务
- 列表展示媒体服务器名 + 媒体库名（不再只显示 UUID）
- 任务详情里可：
  - 写入候选字幕
  - 上传本地字幕
  - 重新搜索
  - 取消任务（进行中）
  - 删除记录（已结束）

### 巡检批次

- 查看媒体库巡检进度、完成/待确认/缺失/失败计数
- 列表同样展示媒体服务器名 + 媒体库名
- 可暂停 / 继续 / 取消进行中的批次
- 已结束批次可单条删除；删除会连带清理关联字幕任务

### 历史清理

- 任务与批次右上角「更多」菜单提供：
  - **批量删除**：进入批量模式，点选可删记录，底部浮条可全选 / 删除所选
  - **清空已结束**：一键清理全部终态记录
- 规则：
  - **仅真正结束的记录可删**（完成 / 失败 / 取消 / 已跳过）；排队、处理中、下载中、写入中、待选择、**刷新待完成** 不可选、不可删
  - 删除批次会**级联删除**关联字幕任务、候选与扫描清单
  - 任务可独立删除，不依赖批次
  - **不会回滚**已写入媒体目录的字幕文件，也不会回滚字幕快照
- 批量删除 / 清空前会二次确认；批次清理文案会明确提示关联任务一并删除

### 设置

- **字幕来源**：OpenSubtitles、Assrt、SubDL、射手影音、迅雷看看、SubHD、字幕库
- **媒体库策略**：语言偏好、格式优先级、来源顺序、自动采用阈值、入库/巡检开关

## 推荐策略

| 场景 | 建议 |
| --- | --- |
| 首次上线 | 先启用 Assrt / OpenSubtitles，观察几天再开网页源自动写入 |
| 本地媒体多 | 可开启射手影音、迅雷看看做哈希/CID 精确匹配 |
| 网页源 | SubHD、字幕库默认更适合人工确认，Cookie/过盾按需开启 |
| 网络受限 | 海外 API 可单独开系统代理，不影响其他来源 |

## 和健康中心的关系

- 健康中心的「缺字幕」来自字幕快照 `language_state=missing`
- 点“检查字幕”会创建字幕任务，并跳到字幕中心
- 已有任务时，可直接“查看字幕任务”

## 常见问题

### 为什么来源显示“未配置 / 冷却中”？

- 未配置：还没保存凭据，或网页源关键项不完整
- 冷却中：上游限流、认证失败或连续错误后，系统会暂时熔断该来源

### 为什么测试显示失败，但公共提示和页面提示不一致？

- 业务错误会由公共拦截器先提示
- 页面成功提示只在 `code=20000` 时出现
- 连通性测试测的是**已保存配置**，不是弹窗里未保存的输入

### 为什么某些来源搜不到？

- 射手影音依赖本地可读媒体哈希，网盘/STRM 不会走哈希匹配
- 迅雷看看依赖标题检索 + 可选 CID 校验
- OpenSubtitles / SubDL 优先 TMDB/IMDb 身份检索
- 网页源可能需要 Cookie、代理或过盾

### 为什么删不掉某些任务 / 批次？

- 进行中的记录（排队、处理中、下载中、写入中、待选择、刷新待完成等）不能删除，需先取消或等其结束
- 「刷新待完成」表示字幕文件已写入，但媒体库刷新队列仍在处理，因此也不可删
- 删除只清理任务/批次记录与候选，**不会**删掉已经写到媒体目录的字幕文件
- 删除批次会一并清理该批次关联的字幕任务
