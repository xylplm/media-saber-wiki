# 🎬 字幕中心

字幕中心用于配置字幕来源、媒体库策略，并查看异步补齐任务。它和媒体库同步、媒体健康中心、文件管理联动：

1. **媒体库同步**扫描媒体项与内封/侧车事实，维护字幕快照
2. **字幕中心**按策略搜索、下载、写入外挂字幕
3. **媒体健康中心**只读取已有快照，发现缺字幕后一键跳回字幕中心
4. **文件管理**可对单个文件「字幕检查」，或对目录发起「字幕巡检」批次

> ⚠️ 健康中心不会在查询时扫盘或访问外部字幕源；缺字幕事实来自字幕快照。

## 快速开始

1. 先完成 [媒体服务器](/usage/media_services/server.html) 同步
2. 打开 **媒体服务 → 字幕中心 → 来源与策略**
3. 配置至少一个可用来源，详见 [字幕来源配置教程](/usage/media_services/subtitle_providers.html)
4. 编辑 **默认策略**（全局兜底，始终存在、不可删除）
5. 需要例外规则时，再为具体媒体库新增覆盖策略并启用
6. 点一次「发起巡检」或策略上的扫描，让快照先就绪
7. 排查缺字幕时，去 [媒体健康中心](/usage/media_services/media_health.html)

## 页面分区

顶部操作：

- **刷新**：重新拉取任务、来源与策略状态
- **手动检查**：为指定媒体查找字幕
- **发起巡检**：按媒体库创建批量巡检批次

导航分区：

| 分区 | 作用 |
| --- | --- |
| 总览 | 待处理、待确认候选、失败/冷却来源、运行中巡检 |
| 字幕任务 | 单条任务列表与详情 |
| 巡检批次 | 媒体库 / 本地目录巡检进度 |
| 来源与策略 | 字幕来源 + 默认策略 + 媒体库覆盖策略 |

### 总览

- 查看最近任务、待处理候选、失败或冷却中的来源
- 快捷跳到字幕任务、巡检批次或来源与策略
- 支持手动检查单个媒体，或打开批量巡检

### 字幕任务

- 查看排队、处理中、待选择、已完成、失败、已跳过等状态
- 列表展示媒体服务器名 + 媒体库名（不再只显示 UUID）
- 支持筛选、批量删除已结束记录
- 任务详情里可：
  - 写入候选字幕（含「转简体后写入 / 转简体升级」）
  - 上传本地字幕
  - 重新搜索
  - 取消任务（进行中）
  - 删除记录（已结束）

### 巡检批次

- 查看媒体库巡检、本地目录巡检的进度与完成/待确认/缺失/失败计数
- 可暂停 / 继续 / 取消进行中的批次
- 已结束批次可单条或批量删除；删除会连带清理关联字幕任务
- 从 [文件管理](/usage/directory_management/file_management.html) 发起的目录巡检，也会出现在这里

### 历史清理

- 任务与批次「更多」菜单提供：
  - **批量删除**：进入批量模式，点选可删记录，底部浮条可全选 / 删除所选
  - **清空已结束**：一键清理全部终态记录
- 规则：
  - **仅真正结束的记录可删**（完成 / 失败 / 取消 / 已跳过）；排队、处理中、下载中、写入中、待选择、**刷新待完成** 不可删
  - 删除批次会**级联删除**关联字幕任务、候选与扫描清单
  - 任务可独立删除，不依赖批次
  - **不会回滚**已写入媒体目录的字幕文件，也不会回滚字幕快照
- 批量删除 / 清空前会二次确认

### 来源与策略

#### 字幕来源

OpenSubtitles、Assrt、SubDL、射手影音、迅雷看看、SubHD、字幕库。配置与测试说明见 [字幕来源配置教程](/usage/media_services/subtitle_providers.html)。

#### 默认策略 vs 媒体库覆盖策略

| 类型 | 说明 |
| --- | --- |
| 默认策略 | 全局兜底，始终生效且不可删除；本地文件/目录与未单独配置的媒体库都用它 |
| 媒体库覆盖策略 | 只对某一媒体库生效；删除后回退默认策略 |

策略常见字段：

- **字幕偏好**：只要纯简体 / 简体优先双语后备 / 简体优先繁中后备 / 接受所有含中文
- **找不到简体时，用繁体转成简体**：开关默认关闭
- **自动采用强度**：分数越高，自动写入越少，更多留给你确认
- **入库后自动检查 / 巡检后自动检查**
- **格式优先级、来源优先级**（可拖拽排序）

## 繁体转简体

当策略打开 **「找不到简体时，用繁体转成简体」** 时：

1. 系统仍**优先原生简体**（及你允许的简中双语/多语言）
2. 只有上面都找不到时，才把繁体 / 繁中双语当作原料
3. 写盘前转换为简体对白，生成 `.zh-CN` 外挂字幕
4. 不会把结果写成繁体侧车；也不会改视频内封字幕

任务详情里，若当前策略已开启且候选是繁体类，会显示：

- 标记：**可转简体**
- 按钮：**转简体后写入** / **转简体升级**

关闭该开关时，行为与旧版一致：繁体只在字幕偏好允许时作为后备，按原样保留。

## 推荐策略

| 场景 | 建议 |
| --- | --- |
| 首次上线 | 先配默认策略 + Assrt / OpenSubtitles，观察几天再开网页源自动写入 |
| 尽量补齐简体 | 打开「繁体转简体」，严格「只要纯简体」也可兜底转换 |
| 本地媒体多 | 可开启射手影音、迅雷看看做哈希 / CID 精确匹配 |
| 网页源 | SubHD、字幕库更适合人工确认，Cookie / 过盾按需开启 |
| 网络受限 | 海外 API 可单独开系统代理，不影响其他来源 |

## 和健康中心、文件管理的关系

- 健康中心的「缺字幕」来自字幕快照 `language_state=missing`
- 健康中心点 **检查字幕** 会创建/打开字幕任务，并跳到字幕中心
- 文件管理对单个视频点 **字幕**，可检查同目录侧车并搜索补齐
- 文件管理对目录点 **字幕巡检**，会复用字幕中心的巡检批次

## 常见问题

### 为什么来源显示“未配置 / 冷却中”？

- 未配置：还没保存凭据，或网页源关键项不完整
- 冷却中：上游限流、认证失败或连续错误后，系统会暂时熔断该来源

### 为什么测试显示失败，但公共提示和页面提示不一致？

- 业务错误会由公共拦截器先提示
- 页面成功提示只在 `code=20000` 时出现
- 连通性测试测的是**已保存配置**，不是弹窗里未保存的输入

### 为什么某些来源搜不到？

- 射手影音依赖本地可读媒体哈希，网盘 / STRM 不会走哈希匹配
- 迅雷看看依赖标题检索 + 可选 CID 校验
- OpenSubtitles / SubDL 优先 TMDB/IMDb 身份检索
- 网页源可能需要 Cookie、代理或过盾

### 打开了繁体转简体，为什么还是没有字幕？

- 仍需要至少一个可用字幕来源
- 候选还要过季集/分数闸门；强制字幕默认不自动采用
- 远程 STRM 若无本地目录，只能搜索，不能写盘

### 为什么删不掉某些任务 / 批次？

- 进行中的记录（排队、处理中、下载中、写入中、待选择、刷新待完成等）不能删除
- 「刷新待完成」表示字幕文件已写入，但媒体库刷新队列仍在处理，因此也不可删
- 删除只清理任务/批次记录与候选，**不会**删掉已经写到媒体目录的字幕文件
