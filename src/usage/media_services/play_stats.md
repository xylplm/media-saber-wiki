# 📊 观影报告

观影报告把媒体服务器上「谁在看、看了什么、看了多久」沉淀成可视化的数据面板，帮助你了解媒体库的真实使用情况，并为容量规划与内容清理提供依据。

它基于媒体服务器的播放事件统计，不影响正常的刮削、整理和播放，只做观看行为的记录与分析。

## 能看什么

### 实时在看

页面顶部展示当前正在播放的会话：有多少人在看、看的是什么。让面板有“活”的状态，而不仅是历史数据。

### 总览指标

四个核心指标卡，并带有与上一周期的环比：

- **总播放次数**：所选时间范围内的有效播放次数（极短的“试看”不计入）
- **总观看时长**：累计观看时长，按「X 小时 Y 分钟」直观展示
- **活跃用户**：有观看行为的用户数
- **转码占比**：转码播放在总播放中的占比，直连越多越省服务器资源

### 趋势与时段

- **播放趋势**：按日展示播放次数与观看时长的变化曲线
- **时段分布（24h）**：展示一天中各时段的观看热度，方便发现“黄金时段”

### 排行榜

- **热门内容**：按播放次数排序的内容榜，可在「全部 / 电影 / 剧集」之间切换
- **用户活跃榜**：按观看时长排序的用户榜

### 分布分析

- **设备分布**：各播放设备的占比
- **播放方式**：直连与转码的占比
- **内容来源**：云盘直链（STRM）与本地内容的占比

### 播放历史

按时间倒序展示每一条播放记录，包含用户、内容、设备、时长、来源标签与时间，支持翻页。

### 零播放清单

列出媒体库中长期（默认 90 天）无人观看的内容，作为清理参考。当前版本只提供建议清单，不会自动删除任何文件。

## 时间范围

页面右上角可切换统计范围：今天 / 近 7 天 / 近 30 天 / 近 90 天。趋势、排行、设备分布、播放历史都会随范围变化；实时在看与零播放清单不受范围影响。

## 数据来源说明

观影报告支持两种数据采集方式，记录上会以标签区分可信度：

| 标签 | 来源 | 说明 |
|---|---|---|
| 实时 | 媒体服务器 Webhook | 精准记录用户、设备、进度、时长 |
| 估算 | 定时采集（最近播放） | 用于不支持 Webhook 的媒体服务器，时长/设备为粗粒度估算 |

- 支持 Webhook 的服务器（如配置好回调的 Emby / Jellyfin / Plex）走「实时」采集，数据最准。
- 不支持或未配置 Webhook 的服务器（如部分 NAS 媒体服务、免费版本），由定时采集兜底补全，标记为「估算」。
- 两种方式互斥：某服务器一旦收到过 Webhook 事件，定时采集会自动跳过它，避免重复计数。
- 只采集 [媒体库启用范围](/usage/media_services/server.html#媒体库启用范围) 内的媒体库：未启用库的播放不会进入统计，Webhook 也不会推送其消息。

> 配置 Webhook 的方法见 [Webhook](/usage/other/webhook.html)。

## 开始使用

1. 在 [媒体服务器](/usage/media_services/server.html) 中添加并启用媒体服务器。
2. 为支持的服务器配置 [Webhook](/usage/other/webhook.html)：
   - 先在媒体服务器页打开 **Webhook 地址** 一键复制
   - 再到 Emby / Jellyfin / Plex 后台粘贴
   - 消息推送开关可按需关闭，不影响观影报告实时采集
3. 不配置 Webhook 也能通过定时采集获得估算数据。
4. 进入「媒体服务 → 观影报告」查看面板。

> 统计数据从功能启用起开始累积，新部署初期数据较少属正常现象，随着观看行为积累会逐渐丰富。

## 定时推送

如果希望把新增入库、热门观看和播放概览按日报、周报或月报推送到消息渠道，可以启灵 [媒体库报告](/usage/cultivation_secrets/media_library_report.html) 插件。插件会复用这里的播放统计数据，并按你指定的执行时间生成报告。

## 一键清理

页面右上角的「清理」可清空全部观影历史记录。此操作不可恢复，会有二次确认。清理后实时在看与媒体库本身不受影响。

## 注意事项

- 观影报告统计的是观看行为，与媒体库的同步、刮削相互独立。
- 网盘 `.strm` 内容的播放同样会被统计，并在「内容来源」中标记为云盘直链。
- 完成度达到约 90% 视为“已看完”，极短的播放（不足 1 分钟）视为“试看”，不计入有效播放次数。
- 时段分布按服务器本地时间统计。
- 零播放清单依据媒体库同步数据，建议先同步媒体服务器以获得最新结果。
