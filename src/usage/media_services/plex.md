# 🔵 Plex

## 📋 简介

Plex是一个流行的媒体服务器软件，可以组织、管理和播放个人媒体收藏。它提供了精美的用户界面和强大的功能，支持在各种设备上流畅播放媒体内容。

## ⚙️ 配置说明

### 🔧 配置字段

- 📡 **服务器地址**：Plex服务器的访问地址，通常为 `http://IP:32400` 或 `https://域名` 格式
- 🔑 **API密钥（X-Plex-Token）**：访问Plex API所需的令牌
- 📂 **媒体播放地址 / 外网地址**：用于远程访问的播放地址
- 🚪 **代理端口**：用于strm302播放的代理端口（可选）
- 🔔 **代理通知**：开启后发送媒体代理相关通知（可选）
- 🔀 **媒体路径映射**：把媒体服路径映射为 Media Saber 可访问路径；同步/巡检/代理共用（可选）
- ☁️ **网盘挂载路径**：用于声明网盘挂载前缀，帮助代理正确识别并解析直链（可选）

### 🌐 获取API密钥

1. 登录Plex管理界面
2. 点击右上角的用户头像
3. 选择"设置"
4. 在页面URL中找到`X-Plex-Token=`参数，复制其后的令牌值
5. 或者通过Plex Web界面按F12打开开发者工具，在网络选项卡中查找包含令牌的请求

### 📋 配置步骤

1. 在媒体服务器页面点击"新增媒体服务器"
2. 选择"Plex"作为服务器类型
3. 填写服务器名称（自定义）
4. 输入服务器地址（Plex服务器的IP和32400端口）
5. 输入API密钥（X-Plex-Token）
6. 点击"测试"按钮验证配置
7. 测试成功后点击"保存"

## 🚀 媒体代理（STRM 必读）

- 网盘直链场景下，Plex 的 `.strm` 播放需要启用媒体代理处理直链分发
- 若未配置媒体代理，通常无法完成 `302` 跳转播放
- 详细配置请查看：[[媒体代理能力详解]](/usage/media_services/media_proxy)

## 🔔 Webhook 配置（播放事件通知 + 观影报告）

配置 Plex 的 Webhook 后（需要 Plex Pass），Media Saber 可以实时接收播放等事件：

- 用于**消息通知**（如"XX开始播放XX"等推送）
- 用于 [观影报告](/usage/media_services/play_stats.html) 的「实时」播放统计来源（相比定时估算更精准）

**推荐做法：**

1. 在 Media Saber 保存该 Plex 媒体服务器
2. 打开列表/编辑页中的 **Webhook 地址**
3. 复制内网或外网完整地址（按媒体服务 ID 生成）

**地址格式：**

```
http[s]://your-domain.com[:port]/api/v1/webhook/mediaServer/{媒体服务ID}?apiKey=your-api-key
```

> 🔑 优先用页面一键复制。手动配置时，`{媒体服务ID}` 是保存后显示的服务 ID；`your-api-key` 见 [我的信息 - API KEY 管理](/usage/main_page/my_info.html)。也可去掉 `apiKey` 参数改用请求头鉴权，详见 [API 鉴权文档](/usage/other/api_auth.html)。

在 Plex 控制台 `设置` → `Webhook` 中添加该地址即可，完整的分步图文教程请查看：👉 [Webhook 配置文档 - Plex 章节](/usage/other/webhook.html#🎬-plex-webhook配置)

## 🆕 新增代理字段说明

### 🔔 代理通知

开启后，Plex 的媒体代理在处理播放请求时会发送相关通知，便于观察代理是否命中、是否使用直链或是否发生降级回退。

- 适合调试代理或排查播放问题时开启
- 仍需在消息通知渠道中勾选 **媒体代理** 推送类型
- 稳定运行后可按需关闭

### 🔀 媒体路径映射

把 Plex 返回的路径映射为 Media Saber 可访问路径。**同步入库、字幕巡检、健康中心、文件写入**使用映射后路径；**媒体代理/直链**与**库刷新反向匹配**也使用同一规则。

- 每行填写一条规则
- 格式为 `原路径前缀:目标路径前缀`（左侧=媒体服路径，右侧=MS 可访问路径）
- 例如：`/data/media:/video/media`
- 修改后请对该媒体服务器执行一次**全量同步**，再跑字幕巡检

适用场景：

- Plex 容器路径与 Media Saber 容器路径不一致
- 容器路径、宿主机路径、网盘挂载路径存在差异
- 需要把 Plex 的媒体路径统一收敛到可访问目录

### ☁️ 网盘挂载路径

用于声明哪些路径属于网盘挂载目录，让 Plex 播放请求在命中这些路径时可以更顺利地走媒体代理直链流程。

- 每行填写一个路径前缀
- 例如：`/115/media`
- 命中后代理会按去掉该前缀后的相对路径继续解析
- 对非 `.strm` 资源也能生效

适用场景：

- Plex 媒体库直接建立在挂载目录之上
- 希望 Plex 的本地路径也能被代理识别成可直链的网盘资源

### 🧹 手动清理代理缓存

编辑 Plex 媒体服务器时提供「手动清理代理缓存」入口：媒体库刷新、路径调整或播放地址异常时，可一键清空该 Plex 实例的播放代理缓存（会话、条目 part 状态等），无需重启服务即可让代理按最新媒体库状态重新解析。

### 🧪 分析 strm

Plex 媒体服务器配置中提供两个 strm 分析字段：

| 字段 | 说明 |
|------|------|
| **分析 strm** | 默认关闭。开启后收到媒体服务器「新文件入库」通知时，新入库条目为 `.strm` 文件则自动入队分析真实音轨/字幕并落库，数据与 [strm 媒体信息探测](/usage/cultivation_secrets/strm_media_probe.html) 插件共用，已分析过的内容自动跳过。配合「STRM元数据增强」，Plex 播放 strm 即可看到真实媒体信息 |
| **定时分析 strm** | 开启「分析 strm」并填写 Cron（如 `0 4 * * *`）后，按周期拉取该服务器媒体库条目清单，仅对其中 `.strm` 文件执行分析；留空则仅由入库事件触发 |

## ⚠️ 注意事项

- 确保Plex服务器在网络中可访问
- 默认Plex端口为32400，请确保此端口未被防火墙阻止
- API密钥需要具有足够的权限以访问媒体库信息
- 如果使用Plex Pass订阅，可以获得更多高级功能
- 需要确保防火墙设置允许相关端口通信
- 对于远程访问，建议配置HTTPS以提高安全性
- 某些功能可能需要Plex Pass订阅才能使用
