# 🩺 媒体健康中心

媒体健康中心用于集中发现媒体库中需要关注的问题，帮助你从“已经同步了哪些媒体”进一步看到“哪些媒体还不完整、识别不准或可以升级”。

它不会替代媒体服务器本身的刮削和播放功能，而是基于 Media Saber 同步到的媒体库数据做一次健康检查。

## 能看什么

### 缺集

展示电视剧中已入库但缺少的集数。

常见用途：

- 查看某部剧第几季缺了哪些集
- 对比已有集数和缺失集数
- 直接发起补订阅或搜索

### 未匹配

展示可能没有正确匹配到媒体信息的项目。

常见原因包括：

- 没有识别到 TMDB 信息
- 标题像资源文件名
- 年份缺失
- 电视剧缺少有效季集信息
- 媒体路径或媒体类型异常

遇到这类问题时，建议先使用“识别测试”确认名称和路径是否能被正确识别，再根据结果调整识别词、整理规则或媒体服务器刮削结果。

### 可升级

展示当前资源质量低于目标质量的媒体。

系统会根据当前媒体文件名、路径和默认订阅质量配置判断是否有升级空间。例如当前是 `720p`，目标配置中包含 `1080p` 或 `2160p`，就可能出现在可升级列表中。

可升级问题支持发起搜索，搜索结果仍会继续使用现有站点、过滤规则、排序规则和规则解释。

## 状态说明

| 状态 | 说明 |
|---|---|
| 待处理 | 当前仍需要处理的问题 |
| 处理中 | 已经创建补订阅或发起搜索 |
| 已忽略 | 用户主动忽略的问题 |
| 已恢复 | 问题已被恢复或重新进入检查 |

默认进入页面时会优先展示仍需处理的问题，避免已忽略内容干扰判断。

## 推荐处理流程

1. 先同步媒体服务器，确保健康中心使用的是最新媒体库数据。
2. 先处理“未匹配”，因为识别错误会影响缺集和可升级判断。
3. 再处理“缺集”，确认缺失集数后创建补订阅或发起搜索。
4. 最后处理“可升级”，按需要搜索更高质量资源。
5. 处理完成后重新同步媒体服务器，对应问题会自动消失或更新状态。

## AI 与 MCP 查询

如果你已经接入 Media Saber MCP，AI 也可以查询媒体健康中心。

你可以直接问：

- “查看媒体健康中心”
- “哪些电视剧缺集？”
- “有哪些未匹配媒体？”
- “查一下可以升级的媒体”
- “看看这个健康问题的详情”

AI 默认只会查询未完成问题，不会自动忽略、恢复、补订阅或发起搜索。

## 注意事项

- 健康中心依赖媒体服务器同步结果，数据不对时请先重新同步媒体服务器。
- 极影视、绿影视、飞牛影视等不同媒体服务的同步字段可能略有差异，建议保持 Media Saber 和媒体服务本身为较新版本。
- 缺集判断只针对电视剧。
- 可升级判断依赖资源名称、路径和默认订阅质量配置，建议资源命名尽量保留清晰的分辨率信息。
