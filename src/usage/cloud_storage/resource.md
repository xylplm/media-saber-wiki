# ☁️ 云端资源

云端资源是全体用户上报沉淀的 **网盘资源库**：电影、剧集按统一格式收录（含 TMDB 信息、季集、分辨率、贡献者等元数据）。你可以在这里检索资源，把别人的资源 **转存 / 离线下载到自己的网盘**，使用时按你的境界单价扣除仙石——这也是贡献者获得下载分成收入的来源。

::: warning 📜 免责申明
- 云端资源均为 **用户上报的文件 HASH**：本程序不存储任何用户文件，只保存文件 hash，文件的下载与存储均由对应网盘提供。
- 本程序 **明令禁止** 上报违反国家法律法规的资源 hash，一经发现，立即 **拉黑删除**。
- 如有用户发现此类资源，请提交 issue 或通知群管理员，我们会在第一时间删除。
- 请大家自觉维护云端资源库生态，让它更健康、更和谐。
:::

::: tip 入口
工作台 **Hash 贡献榜** 卡片：点击榜单行内的造物主，或点击境界条右侧排名区打开完整榜单后进入，即可跳转到云端资源页（自动带上对应贡献者的筛选条件）。
:::

## 🔍 搜索条件

| 条件 | 说明 |
|------|------|
| 类型 | 电影 / 剧集 |
| 媒体 | 输入片名，TMDB 联想选择条目 |
| 关键词 | 文件名关键词过滤（自动记忆历史关键词） |
| 季 / 集 | 剧集精确季集 |
| 开始集 / 结束集 | 剧集集数范围 |
| 贡献者 ID | 只看某位贡献者的资源 |

::: warning 分组视图的限制
分组视图仅对 **剧集** 开放，且必须提供 **片名关键词** 或选择 **TMDB 条目** 才能查询——避免无条件下发全量分组查询造成超时。匹配结果过多时也会提示补充条件缩小范围。
:::

## 🖼️ 三种视图

右上角可切换 **卡片 / 表格 / 分组** 三种布局（分组仅剧集可用）。

### 卡片视图

每条资源一张卡片，**点击卡片即发起下载**（弹出下载弹窗，选择目标网盘与目录）。卡片更多信息菜单里提供管理操作（见下文「管理操作」）。

### 表格视图

- 列：驱动类型、标题（含标签）、大小、发布时间、操作
- 点击 **标题** 发起下载；标题旁的标签显示媒体类型、分辨率、视频编码、贡献者 / 来源站点、季集、H&R 天数，以及可点击跳转的 IMDB / 豆瓣链接
- 「已入库」徽章表示该资源已进入你的媒体库
- 勾选多条后底部浮出批量工具栏：**一键下载** / **一键删除**（删除需权限）
- 操作列的识别按钮可带出该资源到 [名称识别测试](/usage/media_organization/name_recognition_test.html)

### 分组视图（剧集）

把同一部剧的资源按 TMDB 聚合成剧集卡片（海报、评分、来源数量）：

- 每个卡片内按 **来源**（指纹）分组，来源头部显示驱动、集数、总体积
- 点击来源展开 **季 → 集** 结构，悬停单集可见文件名、体积与贡献者，点击单集即下载
- 来源头部的 **批量下载** 按钮可整包下载该来源全部集数

## 📥 使用与计费

下载云端资源时会按资源类型自动选择使用方式，**按你的境界单价扣除仙石**（特权境界免费）：

| 资源类型 | 使用方式 |
|----------|----------|
| 网盘分享 | 分享转存到你的网盘，也可复制分享链接 |
| 云下载 | 提交离线下载任务（ed2k），也可复制链接 |
| 私有种子 | 下载种子文件到下载器，可查看种子详情页 |

::: important 余额与配额
仙石不足、当日 / 当周额度用尽、或账号被 **封印** 时，使用会失败并给出明确提示——贡献资源或维护云识别词可以继续赚取仙石，详见 [修为境界](/usage/user_level/)。
:::

## 🛠️ 管理操作（需对应权限）

具备编辑 / 删除权限的用户（如站长与维护团队）在卡片或表格的更多信息菜单中可以：

- **编辑云资源信息**：修正文件名、TMDB 条目、类型、季集、描述与标签
- **加入黑名单**：屏蔽问题资源
- **删除云资源**：彻底删除；表格多选后可用「一键删除」批量处理，逐条执行并汇总成功 / 失败
