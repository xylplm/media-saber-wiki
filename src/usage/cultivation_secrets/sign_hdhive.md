# 🐝 HDHive 签到

HDHive 站点自动签到。

## ⚙️ 功能特点

- 自动每日签到
- 支持赌狗模式（Premium 双倍积分）
- 支持定时自动执行
- 执行结果消息通知

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 消息推送 | 否 | 执行完成后发送通知 |
| 赌狗模式 | 否 | Premium 双倍积分，但极端情况可能扣分 |
| 周期 | 否 | 定时执行周期（cron 表达式） |
| 用户名 | 是 | HDHive 用户名 |
| 密码 | 是 | HDHive 密码 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次签到

## 📖 使用说明

1. 填写 HDHive 用户名和密码
2. 根据需要开启赌狗模式
3. 设置定时周期或手动运行

## ⚠️ 注意事项

- 赌狗模式下 Premium 可获得双倍积分，但极端情况可能扣分
- 支持多实例
