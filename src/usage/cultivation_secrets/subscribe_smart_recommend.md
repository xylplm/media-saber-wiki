# 🎬 订阅精选推荐

基于用户订阅历史智能分析，精选推荐电影和电视剧，通过消息渠道推送交互卡片，支持一键订阅。也可直接推送豆瓣榜单内容。

## ⚙️ 功能特点

- 分析用户订阅历史，智能推荐相似影视
- 推送消息渠道交互卡片（支持微信、苹果、安卓）
- 支持按 TMDB 评分、年代、地区过滤
- 支持推荐电影和/或电视剧
- 可选直接推送豆瓣榜单内容
- 单例插件

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | Cron 表达式，如 `30 8 * * *`（每天8:30） |
| 渠道 | **是** | 消息渠道（需先在消息通知中勾选本插件），目前支持微信、苹果、安卓 |
| 推荐数量 | **是** | 每次推荐数量，上限 3，默认 1 |
| 最低 TMDB 评分 | 否 | 低于该值不推荐，如 `7.5`，不填或 0 不限制 |
| 数据采样 | 否 | 分析最近 n 个订阅用于推荐，不填或 0 使用全部数据 |
| 排序 | 否 | 推荐结果的排序方式 |
| 年代 | 否 | 如 `2025-2026`，不填不限制 |
| 地区 | 否 | 选择地区过滤 |
| 推荐电影 | 否 | 是否推荐电影 |
| 推荐电视剧 | 否 | 是否推荐电视剧 |
| 忽略特殊季 | 否 | 是否忽略 Season 0 |
| 豆瓣榜单 | 否 | 选择后不做智能推荐，直接推送指定榜单内容 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次推荐推送

## 📖 使用说明

1. 先在「消息通知」中为本插件勾选消息渠道；
2. 在本插件中选择对应的渠道；
3. 根据喜好设置评分、年代、地区等过滤条件；
4. 选择推荐电影和/或电视剧；
5. 点击「运行一次」测试推送效果。

### 两种模式

- **智能推荐**：不选择豆瓣榜单时，基于订阅历史分析推荐
- **榜单推送**：选择豆瓣榜单后，直接推送榜单内容（每个榜单推送指定数量）

## ⚠️ 注意事项

- 必须先在消息通知渠道中勾选本插件，渠道选项才会出现；
- 目前交互卡片仅支持微信、苹果、安卓客户端；
- 智能推荐效果取决于订阅历史数据量，订阅越多推荐越准确。
