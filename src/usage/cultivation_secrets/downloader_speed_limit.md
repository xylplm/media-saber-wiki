# ⏬ 下载器限速

根据种子的标签和分类自动进行上传限速，方便对不同类型的种子设置不同的限速策略。支持 qBittorrent 和 Transmission。

## ⚙️ 功能特点

- 按标签设置不同的上传限速值
- 按分类设置限速（仅 qBittorrent）
- 支持全局限速，对所有种子统一生效
- 支持覆盖模式，覆盖已有的限速设置
- 支持过滤特定状态的种子
- 支持排除特定 Tracker 的种子
- 标签限速优先级高于分类限速
- 支持多实例

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 执行周期 | 否 | Cron 表达式，留空则仅手动执行 |
| 下载器 | **是** | 选择要处理的下载器，可多选 |
| 通知 | 否 | 执行完成后发送统计通知 |
| 覆盖模式 | 否 | 是否覆盖种子已有的限速设置 |
| 全局限速 | 否 | 启用后对所有种子生效 |
| 全局限速(KB/s) | 否 | 全局上传限速值，0 表示不限速 |
| 排除的 Tracker | 否 | 包含这些域名的种子将被跳过，逗号分隔 |
| 包含的种子状态 | 否 | 只处理指定状态的种子，逗号分隔，留空处理全部 |
| 标签限速映射 | 否 | 每行一个，格式 `标签:限速(KB/s)`，行数越高优先级越高 |
| 分类限速映射(仅QB) | 否 | 每行一个，格式 `分类:限速(KB/s)`，优先级低于标签 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次限速任务

## 📖 使用说明

### 配置示例

**标签限速映射：**
```
VIP:100
HD:50
SD:20
```

**分类限速映射（仅 qBittorrent）：**
```
TV:100
Movie:50
```

### 优先级规则

1. 同一种子有多个标签时，使用第一个匹配的标签限速值；
2. 标签限速优先级高于分类限速；
3. 限速值设为 0 表示不限速。

### 使用建议

- 首次使用建议先手动执行一次，确认效果后再设置定时任务；
- 如果已对种子设置了限速但后来删除了配置，种子上的限速不会自动消失；
- 建议同时使用覆盖模式以确保限速生效。

## ⚠️ 注意事项

- 本插件只设置上传限速，不影响下载速度；
- Transmission 不支持分类限速映射；
- 删除限速配置后，已设置的种子限速需手动清除。
