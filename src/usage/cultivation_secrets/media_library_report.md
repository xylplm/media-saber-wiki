# 📬 媒体库报告

媒体库报告可以按你指定的时间，把媒体库新增入库、热门观看和播放概览整理成一条消息推送出去。适合每晚看当天变化、每周回顾家庭影院使用情况，或每月做一次内容与观看盘点。

它复用「我的媒体库」的同步数据和「观影报告」的播放统计，不会额外扫描媒体文件，也不会影响正常播放。

## ✨ 能做什么

- 支持日报、周报、月报，报告周期只决定统计窗口
- 执行时间由你在插件配置里指定，可以按自己的作息设置
- 支持多实例，不同实例可以统计不同媒体服务器或媒体库
- 支持新增入库、热门观看、播放概览三个模块按需开关
- 支持只统计电影、只统计剧集，或电影与剧集都统计
- 支持空报告跳过，避免没有内容时打扰
- 同一实例在同一统计窗口内只会推送一次，避免重复提醒

## 🧭 报告周期

| 周期 | 统计范围 |
|------|----------|
| 日报 | 上一个自然日 |
| 周报 | 上一个自然周，周一到周日 |
| 月报 | 上一个自然月 |

例如周报设置为每周一 8:30 执行，会统计刚刚结束的周一到周日；日报设置为每天 8:30 执行，会统计昨天的数据。

## ⚙️ 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 报告周期 | 否 | 选择日报、周报或月报，默认周报 |
| 执行时间 | 否 | Cron 表达式，决定什么时候生成报告 |
| 媒体服务器 | 否 | 选择要统计的媒体服务器，留空表示全部 |
| 包含媒体库 | 否 | 每行一个媒体库名称，只统计这些媒体库 |
| 排除媒体库 | 否 | 每行一个媒体库名称，排除不想进入报告的媒体库 |
| 统计电影 | 否 | 是否把电影纳入统计 |
| 统计剧集 | 否 | 是否把剧集纳入统计 |
| 播放概览 | 否 | 是否显示播放次数、观看时长、活跃用户、转码占比 |
| 新增入库 | 否 | 是否显示本次新增的电影与剧集 |
| 热门观看 | 否 | 是否显示统计范围内播放次数较多的内容 |
| 空报告跳过 | 否 | 开启后，所启用模块都没有数据时不推送 |
| 新增展示数 | 否 | 新增入库最多展示多少条，最多 50 |
| 热门展示数 | 否 | 热门观看最多展示多少条，最多 50 |
| 消息推送 | 否 | 开启后通过已勾选本插件的消息渠道推送 |

### 常用执行时间

| 表达式 | 适用场景 |
|--------|----------|
| `30 8 * * *` | 每天 8:30 生成日报 |
| `30 8 * * 1` | 每周一 8:30 生成周报 |
| `30 8 1 * *` | 每月 1 日 8:30 生成月报 |

> 📖 Cron 语法可参考 [Cron 表达式说明](/usage/other/cron_rule.html)。

## 🚀 使用步骤

1. 先在 [媒体服务器](/usage/media_services/server.html) 中添加并同步媒体服务器。
2. 如需播放概览和热门观看，建议先确认 [观影报告](/usage/media_services/play_stats.html) 已有播放统计数据。
3. 进入「秘术宝阁」启灵「媒体库报告」。
4. 设置报告周期、执行时间、统计范围和要展示的模块。
5. 在消息渠道中勾选「媒体库报告」，并确认渠道本身可正常推送。
6. 保存后等待定时执行，也可以在插件工具栏点击「运行一次」。

## 🔧 工具栏操作

- **运行一次**：立即按当前配置生成一次报告。首次运行会先建立基线，下一次开始推送新增入库。

## 🧩 多实例用法

媒体库报告支持分神术。你可以创建多个实例，让它们互不影响：

- 家庭周报：统计全部媒体服务器，每周一早上推送
- 个人日报：只统计自己的 Emby 媒体库，每天晚上推送
- 月度盘点：只开启播放概览和热门观看，每月 1 日推送

每个实例都有独立的执行时间、统计范围、基线和去重记录。

## 🔔 消息推送

插件开启「消息推送」后，还需要在「系统设置 → 消息通知」中进入对应渠道，勾选「媒体库报告」。只有勾选了本插件的渠道才会收到报告。

如果只想手动生成结果、不推送消息，可以关闭「消息推送」后点击「运行一次」。

## ⚠️ 注意事项

- 首次运行只建立媒体库基线，不会把历史全库内容当作新增推送。
- 新增入库依赖媒体库同步数据，建议保持媒体服务器定时同步。
- 播放概览和热门观看依赖观影报告数据；新部署或刚开启统计时，数据较少是正常现象。
- 包含媒体库和排除媒体库填写的是媒体服务器中的媒体库名称，需要与实际名称一致。
- 同一实例、同一报告周期、同一统计窗口只会推送一次；手动多次运行也不会重复推送同一份报告。
