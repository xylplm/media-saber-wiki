# 📱 Giffgaff保号提醒

Giffgaff 手机卡 180 天内保号提醒。

## ⚙️ 功能特点

- 每天 10 点自动检测是否需要发送保号提醒
- 距离上次发送日期超过设置天数时自动通知或自动发短信
- **自动保号**（通知 / 走短信 / 两者都做）**同一天最多触发一次**，避免异常重复发送
- 点击通知链接获取短信链接后自动更新发送日期
- 支持自定义提醒天数和发送内容
- 支持三种发送方式：仅通知 / 走短信（自动发送）/ 两者都做

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 接收手机号 | 是 | 格式：`+86139XXXXXXXXX` |
| 提醒天数 | 是 | 提前提醒天数，默认 170 |
| 发送内容 | 是 | 短信发送内容 |
| 上次发送日期 | 是 | 格式：`YYYYMMDD` |
| 运行通知 | 否 | 执行后发送通知 |
| 发送方式 | 是 | 保号短信的发送方式，默认「仅通知」。可选「仅通知」「走短信」「两者都做」 |
| 短信不回调 | 否 | 仅对「走短信」生效。关闭（默认）：需设备回执确认成功后才更新保号日期；开启：发送即更新，不等回执 |

### 📨 发送方式说明

| 方式 | 行为 |
|------|------|
| 仅通知 | 原逻辑，到点发通知提醒你手动发短信 |
| 走短信 | 自动调用 [ESP32 桌面小助手服务](/usage/cultivation_secrets/esp32_desktop_assistant.html)，通过外挂 ML307R 4G 模组自动发送保号短信 |
| 两者都做 | 通知 + 自动短信都执行 |

::: tip 走短信需要什么？

选择「走短信」或「两者都做」时，需要：

1. 装配了 ML307R 4G 模组的 [ESP32 桌面小助手](/client/esp32/) 已通过 SSE 在线（后端按 `client=esp32_desktop` 识别，**与浏览器 Web、手机 APP 的 SSE 分开统计**）
2. 后端已安装并启用 [ESP32 桌面小助手服务](/usage/cultivation_secrets/esp32_desktop_assistant.html) 插件

**不接 4G 模组**的小助手仍可正常使用看板、语音等，只是无法收发短信；保号选「仅通知」不受影响。模组未就绪 / 小助手未在线 / 插件未启用时会跳过短信，不影响通知。

:::

### ⚡ 短信不回调说明

| 状态 | 行为 |
|------|------|
| 关闭（默认） | 发送短信后，**等待设备回执确认成功**才更新保号日期。更可靠：若设备离线、发送失败，日期不更新，下次定时会重新发送。适合追求可靠保号的用户。 |
| 开启 | 发送短信即**立即更新保号日期**，不等设备回执。简单省心：发送一次就完事，不重复发，即使回执丢失也不影响。适合设备网络不稳定、不想因回执丢失而重复发送的场景。 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次检测（仅触发通知，不会真的发短信，可放心测试）

## 📖 使用说明

1. 填写接收手机号（含国际区号）
2. 设置提醒天数（默认 170，即提前 10 天提醒）
3. 填写上次发送短信的日期
4. 新激活手机卡将激活日期填写为上次发送日期
5. 选择发送方式：想自动发选「走短信」，想手动发选「仅通知」

## ⚠️ 注意事项

- 每天 10 点自动检测，无需额外设置 cron
- 定时自动保号同一天只会触发一轮（通知和/或短信），不会因重复调度误触发多次
- 选「仅通知」时，手动发送短信后请手动更新上次发送日期
- 点击通知链接获取短信链接后会自动更新日期
- 选「走短信」时，发送成功后会自动记录，无需手动更新日期
- 本插件为单实例插件，只能添加一个
