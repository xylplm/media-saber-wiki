# 📱 Giffgaff保号提醒

Giffgaff 手机卡 180 天内保号提醒。

## ⚙️ 功能特点

- 每天 10 点自动检测是否需要发送保号提醒
- 距离上次发送日期超过设置天数时自动通知
- 点击通知链接获取短信链接后自动更新发送日期
- 支持自定义提醒天数和发送内容

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 接收手机号 | 是 | 格式：`+86139XXXXXXXXX` |
| 提醒天数 | 是 | 提前提醒天数，默认 170 |
| 发送内容 | 是 | 短信发送内容 |
| 上次发送日期 | 是 | 格式：`YYYYMMDD` |
| 运行通知 | 否 | 执行后发送通知 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次检测

## 📖 使用说明

1. 填写接收手机号（含国际区号）
2. 设置提醒天数（默认 170，即提前 10 天提醒）
3. 填写上次发送短信的日期
4. 新激活手机卡将激活日期填写为上次发送日期

## ⚠️ 注意事项

- 每天 10 点自动检测，无需额外设置 cron
- 手动发送短信后请手动更新上次发送日期
- 点击通知链接获取短信链接后会自动更新日期
- 本插件为单实例插件，只能添加一个
