# 🌊 刷流

刷子神器。

## ⚙️ 功能特点

- 自动从站点 RSS 抓取种子并下载刷流
- 支持保种体积上限、上传/下载速度限制
- 支持过滤规则、关键字包含/排除
- 重复下载检测，避免重复刷取
- 支持多实例，可为不同站点配置不同策略

## 🚀 配置指南

### 基础配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 站点 | **是** | 选择刷流站点 |
| 周期 | **是** | cron 表达式 |
| 下载器 | **是** | 选择目标下载器 |
| 保存目录 | **是** | 覆盖下载器中的目录设置 |
| 标签 | 否 | 多个逗号隔开，建议设置否则部分业务会失效 |
| RSS 地址 | 否 | 留空使用站点配置 RSS |
| 保种体积(GB) | 否 | 超过设定值不再新增，冗余量 5GB |
| 消息推送 | 否 | 开关 |

### 速度控制

| 参数 | 必填 | 说明 |
|------|------|------|
| 上限上传速度(KB/s) | 否 | 下载器上传速度在此之上时停止添加 |
| 上限下载速度(KB/s) | 否 | 下载器下载速度在此之上时停止添加 |
| 上传限速(KB/s) | 否 | 单种子上传限速 |
| 下载限速(KB/s) | 否 | 单种子下载限速 |
| 同时下载任务数 | 否 | 使用标签区分种子 |

### 过滤条件

| 参数 | 必填 | 说明 |
|------|------|------|
| 过滤规则 | 否 | 选择预设过滤规则 |
| 包含 | 否 | 关键字或正则 |
| 排除 | 否 | 关键字或正则 |
| 识别 | 否 | 开关，能识别到媒体信息的才会被处理 |
| 重复下载检测 | 否 | 开关（默认开启），已下载种子不重复下载，记录保存 48 小时 |

### 高级选项（局限性）

| 参数 | 必填 | 说明 |
|------|------|------|
| Hit&Run | 否 | 大多数站点 RSS 不支持 |
| 促销 | 否 | 大多数站点 RSS 不支持 |
| 最小种子大小(GB) | 否 | 大多数站点 RSS 不支持 |
| 最大种子大小(GB) | 否 | 大多数站点 RSS 不支持 |
| 最小做种人数 | 否 | 大多数站点 RSS 不支持 |
| 最大做种人数 | 否 | 大多数站点 RSS 不支持 |
| 最小发布时间(分钟) | 否 | — |
| 最大发布时间(分钟) | 否 | — |

### 云存储

| 参数 | 必填 | 说明 |
|------|------|------|
| 云存储 HASH 上报 | 否 | 开关，下载完成后自动上报，只有配置了标签才会上报 |
| 云存储 HASH 上报检查周期 | 否 | cron 表达式 |

### 🔧 工具栏操作

- **运行一次**：手动触发一次刷流任务

## 📖 使用说明

1. 选择站点、下载器，设置保存目录和执行周期；
2. 建议设置标签，便于区分刷流种子；
3. 设置保种体积上限，防止磁盘占满；
4. 根据需要配置过滤规则和速度限制；
5. 配合删种插件管理种子生命周期。

## ⚠️ 注意事项

- 需要转移到媒体库的请自行走目录同步机制
- 删种请配合删种插件使用
- 种子不单独存储，通通使用标签来区分，建议设置标签否则部分业务会失效
- 相同种子五分钟内不会重复下载
- 标记为「局限」的参数大多数站点 RSS 不支持，实际效果有限
