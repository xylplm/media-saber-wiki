# 🎬 癫影签到

癫影（dian115.com）站点自动签到。

## ⚙️ 功能特点

- 自动每日签到
- 支持运气模式
- 支持定时自动执行
- 执行结果消息通知

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 消息推送 | 否 | 执行完成后发送通知 |
| 运气模式 | 否 | 开启后使用运气模式签到，关闭则使用普通模式 |
| 代理 | 否 | 开启后通过系统代理访问站点，网络受限时使用 |
| 周期 | 否 | 定时执行周期（cron 表达式） |
| Cookie | 是 | 登录后从浏览器开发者工具中获取 |

### 🍪 获取 Cookie

1. 浏览器登录 [https://m.dian115.com](https://m.dian115.com)
2. 按 F12 打开开发者工具，切到「网络」标签
3. 刷新页面，找到任意请求，复制请求头中的 `Cookie` 字段值
4. 将完整 Cookie 粘贴到插件配置中

### 🔧 工具栏操作

- **运行一次**：立即执行一次签到

## 📖 使用说明

1. 获取并填写癫影站点的 Cookie
2. 根据需要开启运气模式
3. 设置定时周期或手动运行

## ⚠️ 注意事项

- Cookie 过期后需要重新获取并更新配置
- 普通模式和运气模式的区别由站点决定，具体奖励以实际签到结果为准
- 支持多实例
