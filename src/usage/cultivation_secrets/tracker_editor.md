# 🔄 Tracker替换

批量替换种子 Tracker，支持周期性巡检。

## ⚙️ 功能特点

- 批量替换下载器中种子的 Tracker 地址
- 支持多条替换规则
- 支持周期性巡检（不推荐）
- 执行结果消息通知

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 下载器 | 是 | 选择需要操作的下载器 |
| Tracker替换配置 | 是 | 替换规则，每行一个：`待替换文本\|替换的文本` |
| 周期执行 | 否 | 定时巡检周期（cron 表达式），不推荐开启 |
| 消息推送 | 否 | 执行完成后发送通知 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次 Tracker 替换

## 📖 使用说明

1. 选择需要操作的下载器
2. 在配置中填写替换规则，每行一条，格式为 `旧Tracker|新Tracker`
3. 点击"运行一次"执行替换

**配置示例：**
```
tracker.old.com|tracker.new.com
old-announce|new-announce
```

## ⚠️ 注意事项

- 不推荐开启周期巡检，会增加下载器负载，建议手动运行
- 替换操作会直接修改种子 Tracker，请确认规则正确
- 支持多实例，可为不同下载器创建不同配置
