# 💾 系统备份

系统级备份与一键还原工作台。可备份配置与 PostgreSQL 数据库，支持加密备份、云端同步、备份包校验、上传还原，以及还原前快照保护。

> 旧版「自动备份」已升级为「系统备份」。若你仍看到旧名称，更新到最新版本后重新进入修仙秘籍即可。

## ⚙️ 功能特点

- 定时 / 手动创建系统备份快照
- 支持仅配置，或配置 + PostgreSQL 数据库一起备份
- 本地备份列表与云端备份列表统一管理
- 支持 AES 加密备份包（`.msbak`）
- 备份完成后可自动同步到云存储
- 还原前自动校验备份包，并生成还原前快照
- 支持上传本地备份包后校验并还原
- 可检查 / 缓存 `pg_dump`、`psql` 数据库工具
- 单例插件，全局只保留一个实例
- Web 端与 APP 端均可使用；APP 提供独立「配置参数」页

## 🧭 工作台能做什么

启灵后进入系统备份工作台，可看到：

| 区域 | 说明 |
|------|------|
| 概览 | 最新备份、备份目录、是否含数据库、是否加密、数据库工具状态 |
| 快捷操作 | 立即备份、上传还原、下载最新、还原最新、同步云端、检查 / 准备工具 |
| 备份列表 | 本地 / 云端切换查看，支持单条下载、还原、删除 |
| 配置参数 | 定时、保留份数、目录、加密、云端同步等设置 |

## 🚀 配置指南

在工作台右上角打开 **配置参数**（APP 同样在右上角菜单进入）。

### 基础配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 定时任务 | 否 | Cron 表达式，留空表示不自动备份 |
| 本地保留数量 | **是** | 超过后自动删除最早的本地备份 |
| 备份位置 | 否 | 本地备份目录，留空默认 `./config/backup` |
| 备份数据库 | 否 | 开启后将 PostgreSQL 一并写入备份包 |
| 缓存数据库工具 | 否 | 将 `pg_dump` / `psql` 缓存到 `config/tools`，便于无系统工具环境 |
| 通知 | 否 | 推送备份、同步、还原结果 |

### 云端同步

| 参数 | 必填 | 说明 |
|------|------|------|
| 同步到云端 | 否 | 备份完成后提交云端上传任务 |
| 云存储目录 | 否 | 云端备份目录；重装后配置同一目录即可扫描还原 |
| 云端保留数量 | 否 | 超过后自动清理最早的云端备份 |

### 加密配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 加密备份包 | 否 | 开启后生成 `.msbak` 加密包 |
| 加密算法 | 否 | AES-128 / AES-192 / AES-256，建议 AES-256 |
| 加密密钥 | 条件必填 | 开启加密后必须填写；还原加密包时必须使用同一密钥 |
| 保留明文包 | 否 | 加密成功后是否额外保留明文 zip |

## 🔧 工作台操作

### 备份

1. 确保实例已 **启灵**
2. 点击 **立即备份**
3. 在本地列表中查看新生成的备份
4. 如已开启云端同步，可再点 **同步云端**，或切换到云端列表查看

### 下载

- **下载最新**：下载本地最新一份备份
- 列表中的 **下载**：下载指定本地备份

### 还原

还原路径都有二次确认，并会先校验备份包：

| 操作 | 说明 |
|------|------|
| 还原最新 | 校验并还原本地最新备份 |
| 列表还原 | 还原指定本地 / 云端备份 |
| 上传还原 | 选择 `.zip` 或 `.msbak` 上传，校验通过后确认还原 |

还原完成后需要 **重启服务**，配置才会完全生效。

### 云端

- **扫描云端**：刷新云端备份列表
- **同步云端**：把最新本地备份提交到云端
- 云端条目支持还原、删除；本地条目额外支持下载

### 数据库工具

| 操作 | 说明 |
|------|------|
| 检查 | 检查 `pg_dump` / `psql` 是否可用 |
| 准备 / 缓存 | 准备数据库工具缓存，便于备份数据库场景 |

## 📱 APP 使用说明

APP 端入口同样在 **修仙秘籍 → 系统备份**：

1. 打开插件后可直接查看备份工作台
2. 右上角菜单进入 **配置参数**，设置定时、目录、加密、云端等
3. 支持本地 / 云端列表切换、立即备份、下载、还原、上传还原、同步云端
4. 未启灵时先打开启灵开关，再刷新备份列表

## 📖 推荐使用流程

1. 启灵「系统备份」
2. 打开配置参数，设置本地保留数量、是否备份数据库
3. 如需异地备份，开启云端同步并填写云存储目录
4. 如需加密，开启加密并生成密钥，**妥善保存密钥**
5. 点击「立即备份」验证一次
6. 确认本地列表出现新备份；如开启云端，再检查云端列表

## ⚠️ 注意事项

- Docker 部署请确保备份目录已做持久化映射
- 加密密钥丢失后，加密备份包将无法还原
- 还原会覆盖当前配置（以及开启时的数据库），请先确认备份包正确
- 还原前系统会生成还原前快照，但仍建议重要环境先手动确认
- 还原完成后请重启服务
- 上传还原仅支持 `.zip` / `.msbak`，单文件建议不超过 512 MB
- 插件为单例，全局只保留一个实例
