# 🍋 柠檬神游

自动完成柠檬站点每日免费神游三清天，获取奖励。

## ⚙️ 功能特点

- 自动完成每日免费神游任务
- 支持定时自动执行
- 支持手动获取 Cookie
- 执行结果消息通知

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 通知 | 否 | 执行完成后发送通知 |
| 定时任务 | 否 | 定时执行周期（cron 表达式） |
| Cookie | 是 | 柠檬站点 Cookie |

### 🔧 工具栏操作

- **运行一次**：立即执行一次神游任务
- **获取Cookie**：自动获取站点 Cookie

## 📖 使用说明

1. 点击"获取Cookie"或手动填写站点 Cookie
2. 设置定时任务周期
3. 保存后将自动定时执行

## ⚠️ 注意事项

- Cookie 过期后需重新获取
- 本插件为单实例插件，只能添加一个
