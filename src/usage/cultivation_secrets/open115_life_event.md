# 📋 115 生活事件

定时拉取 115 网盘「生活」模块的最近操作事件，自动触发文件整理和 Strm 生成，实现 115 云存储的增量自动化管理。

## ⚙️ 功能特点

- 定时拉取 115 生活最近操作事件
- 根据事件自动触发文件整理
- 根据事件自动生成 Strm 文件
- 删除文件时可联动删除本地 Strm
- 支持按事件类型和路径过滤
- 支持跳过首次运行
- 支持多实例

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 消息推送 | 否 | 开启后推送任务执行情况 |
| 周期 | 否 | Cron 表达式，例如 `*/15 * * * *`（每15分钟） |
| 115 云存储 | **是** | 选择已配置的 115 云存储，用于拉取事件和执行操作 |
| 最大页数 | 否 | 每页 1000 条，默认 3 页，上限 5 页 |
| 事件类型 | 否 | 选择要处理的事件类型，留空处理全部 |
| 包含路径 | 否 | 只处理这些路径下的事件，一行一个，如 `/115/未整理-增量` |
| 跳过首次 | 否 | 首次运行时忽略所有事件 |
| 文件整理 | 否 | 匹配云存储文件整理配置，自动整理 |
| 生成 Strm | 否 | 匹配云存储 Strm 生成配置，自动生成 |
| 联动删除 Strm | 否 | 删除文件事件时联动删除本地 Strm 文件 |

### 🔧 工具栏操作

- **运行一次**：立即拉取并处理事件
- **清空状态**：重置处理时间记录，下次运行将重新处理所有事件

## 📖 使用说明

1. 先在系统中配置好 115 云存储连接；
2. 启灵本插件并选择对应的 115 云存储；
3. 根据需要开启「文件整理」和/或「生成 Strm」；
4. 建议首次启用时开启「跳过首次」；
5. 设置合适的拉取周期（推荐 15 分钟）。

## ⚠️ 注意事项

- 必须先配置好 115 云存储连接才能使用本插件；
- 文件整理和 Strm 生成依赖系统全局配置的规则；
- 「清空状态」后下次运行会重新处理所有可见事件，请谨慎使用；
- 拉取频率不宜过高，避免触发 115 接口限制。
