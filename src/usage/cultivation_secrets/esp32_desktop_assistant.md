# 📟 ESP32 桌面小助手服务

配合 **Media Saber ESP32 桌面小助手定制固件** 使用的后端插件，作为小助手扩展能力的统一入口：可选 **ML307R 4G 模组** 短信收发、设备状态展示、手动发短信，并为 [Giffgaff 保号提醒](/usage/cultivation_secrets/giffgaff_keep_alive.html) 等秘籍提供自动发短信能力。

::: tip 4G 是可选的

不接 4G 模组时，小助手仍可正常使用语音、NAS 看板、站点数据、消息中心等；本插件也可启灵并保存基础设置，只是**无法收发短信**，插件「设备与短信」页会提示无小助手在线或模组未就绪。硬件接线与供电见 [4G 短信与设备状态](/client/esp32/sms.html)。

:::

## ⚙️ 功能特点

- 通过 SSE 向在线小助手下发 `send_sms` 等设备指令（**仅** `client=esp32_desktop` 连接）
- 小助手上报发送回执、收件箱、设备状态（WiFi / 模组就绪等）
- 配置页为**自定义界面**（非通用 JSON 动态表单）：双选项卡 + 对应底部按钮
- 单例插件：全站建议仅一台装配短信模组的小助手在线，避免广播重复发送
- 其它秘籍（如 Giffgaff 保号）可调用本插件 `send_sms` 自动发短信

## 🚀 配置指南

在「修仙秘籍」打开本实例配置弹窗：

| 选项卡 | 内容 | 底部按钮 |
|------|------|----------|
| **基础设置** | 是否启灵、短信接收转发、失败通知、使用说明提示框 | 取消 / 应用 / 确认 |
| **设备与短信** | 小助手在线台数、刷新状态、最近上报、手机号 / 超时 / 内容、手动发送短信 | 刷新状态 / 关闭 / 发送短信 |

### 基础设置参数

| 参数 | 说明 |
|------|------|
| 是否启灵 | 与其它秘籍相同：启灵后插件逻辑生效；封印后不处理指令与转发 |
| 短信接收转发 | 小助手 + ML307 收到新短信时，经你已开启的消息渠道转发（需装配模组） |
| 失败通知 | 短信发送失败时通知（需打开本插件消息通知） |

### 设备与短信

- **小助手在线**：只统计 SSE 连接带 `client=esp32_desktop` 的设备；仅开着浏览器 Web（`web`）或手机 APP（`app`）**不算**在线。
- **最近上报**：展示小助手最近一次 `report_status` 的 WiFi、信号、IP、短信模组是否就绪。
- **手动发短信**：填写国际区号手机号与内容，点「发送短信」；无在线小助手时按钮不可用。

## 📖 使用说明

1. 按 [ESP32 客户端文档](/client/esp32/) 完成硬件（可选 4G）、刷录定制固件并连上你的 Media Saber 服务端。
2. 在「秘术宝阁」启灵 **ESP32 桌面小助手服务**，打开「是否启灵」并保存。
3. 需要短信时：装配 ML307R、插入 SIM，确认固件 SSE 带 `client=esp32_desktop`（定制固件已默认）。
4. 打开「设备与短信」→「刷新状态」，确认在线且模组就绪后，可先手动发一条测试短信。
5. 需要自动保号时：另启灵 [Giffgaff 保号提醒](/usage/cultivation_secrets/giffgaff_keep_alive.html)，发送方式选「走短信」或「两者都做」。

## ⚠️ 注意事项

- 必须使用 **Media Saber 定制固件**，任意 ESP32 设备不可用。
- SSE 设备指令为**全局广播**：多台小助手同时在线会重复下发，请确保仅一台带短信模组的小助手在线。
- 短信内容默认 GSM 字符集，适合英文 / 数字保号内容；中文短信需模组 UCS2，属进阶能力。
- 发送采用异步下发 + 设备回执；调用方（如保号）可配置是否等回执再更新日期，见 Giffgaff 文档「短信不回调」。
