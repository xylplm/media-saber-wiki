# 📊 系统进程

查看当前docker容器系统进程。

## ⚙️ 功能特点

- 实时查看容器内运行的系统进程
- 显示进程 PID、名称、运行时间
- 显示 CPU 使用率和内存占用
- 表格形式清晰展示进程信息
- 无需配置，开箱即用

## 🚀 配置指南

> 💡 这是一个页面工具（tools-pages），无需任何配置，打开即可查看当前进程列表。

### 🔧 工具栏操作

- 打开页面即自动加载当前进程列表

## 📖 使用说明

1. 进入「工具」页面找到「系统进程」；
2. 打开后自动展示当前容器内所有进程；
3. 查看各进程的 PID、名称、运行时间、CPU% 和内存占用。

## ⚠️ 注意事项

- 单例插件，全局只有一个实例
- 这是页面工具，在前端工具页面中使用
- 显示的是 Docker 容器内的进程，非宿主机进程
- 进程信息为打开页面时的快照
- 如需实时监控，请刷新页面获取最新数据
