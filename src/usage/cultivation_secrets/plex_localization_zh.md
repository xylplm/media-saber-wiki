# 🀄 Plex 拼音本地化

为 Plex 媒体库实现中文标题拼音排序和标签中文化（类型/风格/情绪），解决 Plex 中文排序混乱的问题。

> 借鉴了 Plex 群主 x1ao4 的项目，感谢 x1ao4。

## ⚙️ 功能特点

- 中文标题自动生成拼音排序字段
- 标签中文化：类型、风格、情绪等标签翻译为中文
- 支持选择指定媒体库处理
- 支持并发处理，提升效率
- 支持多实例

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| Plex 服务器 | **是** | 选择要处理的 Plex 服务器（仅显示 Plex 类型） |
| 媒体库 | 否 | 选择要处理的媒体库，需先选择服务器后加载列表，留空处理全部 |
| 周期 | 否 | Cron 表达式，例如 `0 3 * * *`（每天凌晨3点） |
| 并发线程数 | 否 | 处理时的并发数，默认 1，建议 1-8 |
| 通知 | 否 | 开启后任务执行结束发送通知 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次拼音本地化

## 📖 使用说明

1. 确保已在系统中配置好 Plex 媒体服务器连接；
2. 选择 Plex 服务器，然后选择需要处理的媒体库；
3. 首次运行建议先手动执行一次，观察效果；
4. 确认无误后设置定时周期自动维护。

## ⚠️ 注意事项

- 仅支持 Plex 媒体服务器，Emby/Jellyfin 不适用；
- 并发线程数不宜过高，避免对 Plex API 造成压力；
- 大型媒体库首次处理可能耗时较长；
- 新增媒体后需再次运行才能更新排序。
