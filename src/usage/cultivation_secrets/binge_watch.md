# 📺 追剧提醒

订阅的电视剧更新时通知提醒。

## ⚙️ 功能特点

- 监控订阅电视剧的更新状态
- 新剧集可用时自动发送通知
- 支持通知中附带剧集图片
- 支持图片代理，解决网络访问问题
- 可选择监控特定订阅或全部订阅

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 开关 | 否 | 启用/禁用插件 |
| 定时任务 | 否 | 检查频率，cron 表达式 |
| 启用图片 | 否 | 开关，通知中是否包含剧集图片 |
| 图片代理 | 否 | 图片代理地址，用于解决图片无法访问的问题 |
| 图片地址 | 否 | 自定义图片地址 |
| 订阅列表 | 否 | 选择要监控的订阅，留空监控全部 |

### 🔧 工具栏操作

- **运行一次**：手动触发一次追剧检查并发送通知

## 📖 使用说明

1. 开启插件开关；
2. 设置定时任务周期（建议每小时或每天检查）；
3. 如需图片通知，开启「启用图片」；
4. 如有网络问题，配置图片代理；
5. 选择需要监控的订阅，或留空监控全部。

## ⚠️ 注意事项

- 非单例插件，可创建多个实例监控不同订阅
- 留空订阅列表时将监控所有已订阅的电视剧
- 图片代理仅在启用图片时生效
- 通知发送依赖系统通知渠道配置
