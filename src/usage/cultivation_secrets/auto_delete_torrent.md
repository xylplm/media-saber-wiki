# 🗑️ 删种

自动删种。

## ⚙️ 功能特点

- 按分享率、做种时间、体积等多维度条件筛选
- 支持标签、保存路径、Tracker 等精细过滤
- 满足条件后可执行删除等动作
- 支持多实例，可为不同下载器配置不同策略

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | cron 表达式，如 `0 * * * *` |
| 下载器 | **是** | 选择目标下载器 |
| 动作 | **是** | 满足条件后的后续动作 |
| 最小体积(GB) | 否 | 体积 ≥ 该值则满足，最小最大都要设置才能生效 |
| 最大体积(GB) | 否 | 体积 ≤ 该值则满足 |
| 最低分享率 | 否 | 分享率 ≥ 该值则满足 |
| 最少下载时间(分钟) | 否 | 下载时间 ≥ 该值则满足 |
| 最少做种时间(小时) | 否 | 做种时间 ≥ 该值则满足（未完成种子从添加时间开始，完成种子从完成时间开始） |
| 最大平均上传速度(KB/s) | 否 | 平均上传速度 ≤ 该值则满足 |
| 包含标签 | 否 | 包含所有标签则满足，英文逗号隔开 |
| 包含保存路径 | 否 | 支持正则 |
| 包含 Tracker | 否 | 支持正则 |
| 排除 Tracker | 否 | 支持正则 |
| 包含错误信息 | 否 | 支持正则 |

### 🔧 工具栏操作

- **运行一次**：手动触发一次删种检查

## 📖 使用说明

1. 选择目标下载器和满足条件后的动作；
2. 设置筛选条件（分享率、做种时间、体积等）；
3. 配置执行周期或手动运行一次验证效果；
4. 可通过标签、路径、Tracker 进一步缩小范围。

## ⚠️ 注意事项

- 最小体积和最大体积需同时设置才能生效
- 多个条件之间为"且"关系，需全部满足才会触发动作
- 建议先手动运行一次确认匹配结果，再开启定时任务
