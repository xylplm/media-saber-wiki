# 🌱 IYUU自动辅种

基于IYUU官方Api实现自动辅种。

## ⚙️ 功能特点

- 基于 IYUU 官方 API 自动匹配辅种资源
- 将已有种子匹配到其他 PT 站点相同内容
- 支持多下载器和多站点
- 支持按标签忽略特定任务
- 自动删除零字节无效种子

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| IYUU Token | **是** | IYUU 官方 Token |
| 下载器 | **是** | 多选，参与辅种的下载器 |
| 站点 | 否 | 多选，限定辅种的目标站点 |
| 定时任务 | 否 | 自动辅种频率，cron 表达式 |
| 代理域名 | 否 | 用于替换站点域名的代理地址 |
| 忽略标签 | 否 | 逗号分隔，包含这些标签的任务不参与辅种 |
| 通知 | 否 | 开关，辅种完成后发送通知 |
| 自动开始 | 否 | 辅种后自动开始做种 |
| 自动删除零字节 | 否 | 自动删除大小为零的无效种子 |

### 🔧 工具栏操作

- **运行一次**：手动触发一次辅种任务
- **绑定站点**：将本地站点与 IYUU 站点进行绑定
- **清除缓存**：清除辅种缓存，重新匹配所有种子

## 📖 使用说明

1. 前往 IYUU 官网获取 Token；
2. 填写 Token 并选择参与辅种的下载器；
3. 点击「绑定站点」完成站点绑定；
4. 设置定时任务周期；
5. 点击「运行一次」验证辅种是否正常。

## ⚠️ 注意事项

- 单例插件，全局只能有一个实例
- 首次使用必须先完成站点绑定
- Token 可在 IYUU 官网免费获取
- 辅种不会重复添加已存在的种子
- 清除缓存后会重新扫描所有种子，耗时较长
