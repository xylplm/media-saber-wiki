# 🔄 媒体服务刷新

定时刷新媒体服务器（Emby / Jellyfin / Plex）中的媒体库，支持排除指定媒体库，确保新入库内容及时在媒体服务中可见。

## ⚙️ 功能特点

- 定时触发媒体服务器扫描媒体库
- 支持排除不需要刷新的媒体库
- 支持多实例，可为不同媒体服务器创建独立配置

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | Cron 表达式，例如 `30 8 * * *`（每天8:30） |
| 媒体服务器 | **是** | 选择要刷新的媒体服务器 |
| 排除的媒体库 | 否 | 不需要刷新的媒体库名称，一行一个，留空刷新全部 |
| 通知开关 | 否 | 开启后推送刷新结果 |

### 🔧 工具栏操作

- **运行一次**：立即触发一次媒体库刷新

## 📖 使用说明

1. 确保已在系统中配置好媒体服务器连接；
2. 选择要刷新的媒体服务器；
3. 如有不需要频繁刷新的媒体库（如收藏、音乐等），填入排除列表；
4. 设置合适的定时周期。

## ⚠️ 注意事项

- 刷新频率不宜过高，避免对媒体服务器造成不必要的负载；
- 排除的媒体库名称必须与媒体服务器中的名称完全一致；
- 如使用 CloudDrive2 挂载，建议同时启灵「CloudDrive2 刷新配置」插件，确保刷新前缓存已更新。
