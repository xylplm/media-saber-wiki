# 📂 云存储增量整理

定时扫描指定云存储目录，自动发现新增文件并根据云存储文件整理和 Strm 生成配置进行增量整理。

## ⚙️ 功能特点

- 只扫描目录下一层文件或文件夹，记录最后处理时间，实现增量整理
- 根据系统中已配置的云存储文件整理规则和 Strm 生成规则自动处理
- 支持跳过首次运行，避免历史文件被重复处理
- 支持多实例（领悟分神术），可为不同目录创建独立配置

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 消息推送 | 否 | 开启后推送当前任务执行情况 |
| 定时扫描 | 否 | Cron 表达式，例如 `*/15 * * * *`（每15分钟） |
| 要整理的目录 | **是** | 选择云存储目录路径 |
| 跳过首次 | 否 | 首次运行时忽略所有已有文件 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次增量扫描整理

## 📖 使用说明

1. 先在系统的「云存储管理」中配置好文件整理规则和/或 Strm 生成规则；
2. 启灵本插件，选择需要监控的云存储目录；
3. 建议首次启用时开启「跳过首次」，避免对已有文件重复处理；
4. 设置合适的定时扫描周期，或手动点击「运行一次」测试。

## ⚠️ 注意事项

- 只扫描目录下一层，不会递归深入子目录；
- 整理规则依赖系统全局配置，本插件不单独配置整理逻辑；
- 如使用 CloudDrive2 挂载，建议同时启灵「CloudDrive2 刷新配置」插件。
