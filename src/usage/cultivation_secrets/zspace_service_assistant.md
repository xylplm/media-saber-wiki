# 📱 极空间服务助手

集成极空间（ZSpace）NAS 的系统消息推送和服务状态查询功能。支持系统消息通知、CPU/内存/温度阈值告警，并作为 NAS 信息提供者接入首页 **天序工作台 · 系统机体**。

## ⚙️ 功能特点

- 定时获取极空间系统消息并推送通知
- 系统状态监控：CPU、内存、温度阈值告警
- 作为 nasInfo provider 接入天序工作台「系统机体」（可与本机切换）
- 单例插件

## 🚀 配置指南

### 连接配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 服务器地址 | **是** | 完整地址，如 `http://192.168.31.88:5055` |
| Cookie 信息 | **是** | 极空间的登录 Cookie |

### 系统消息通知

| 参数 | 必填 | 说明 |
|------|------|------|
| 启用系统消息通知 | 否 | 极空间有新系统消息时发送通知 |
| 消息推送定时任务 | 否 | 获取频率，推荐 `*/10 * * * *`（每10分钟） |

### 系统状态告警

| 参数 | 必填 | 说明 |
|------|------|------|
| 启用其他服务最新状态查询 | 否 | 允许其他服务调用极空间状态接口 |
| 启用系统状态提醒通知 | 否 | 超过阈值时发送告警 |
| 系统状态检测定时任务 | 否 | 检测频率，推荐 `*/5 * * * *`（每5分钟） |
| 系统状态提醒发送频率(分钟) | 否 | 告警发送间隔，默认每次都发，设置后需间隔指定分钟 |
| CPU 提醒百分比阈值 | 否 | 默认 80% |
| 内存提醒百分比阈值 | 否 | 默认 80% |
| 温度提醒阈值(℃) | 否 | 默认 60℃ |

### 🔧 工具栏操作

- **立即执行一次**：手动触发一次状态采集
- **手动发送状态通知**：立即发送一次状态告警通知

## 📖 使用说明

### Cookie 获取方法

1. 使用浏览器登录极空间 Web 管理界面；
2. 按 F12 打开开发者工具，切换到 Application → Cookies；
3. 选择极空间域名，复制完整 Cookie 值；
4. 粘贴到插件配置的「Cookie 信息」字段。

### 配置步骤

1. 填写极空间服务器地址（含协议和端口）；
2. 填写从浏览器获取的 Cookie；
3. 根据需要开启系统消息通知和/或状态告警；
4. 点击「立即执行一次」验证连接是否正常。

## ⚠️ 注意事项

- Cookie 会过期，失效后需重新从浏览器获取并更新；
- 服务器地址必须包含协议（`http://` 或 `https://`）和端口号；
- 消息推送频率推荐 10 分钟以上，状态检测推荐 5 分钟以上；
- 确保 Media Saber 容器能访问极空间的地址和端口。
