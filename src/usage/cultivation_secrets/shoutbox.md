# 💬 发群聊消息

自动发送站点群聊区消息。

## ⚙️ 功能特点

- 支持多站点同时发送
- 支持多条消息随机发送
- 可自定义发送间隔
- 支持定时自动执行

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 消息推送 | 否 | 执行完成后发送通知 |
| 周期 | 否 | 定时执行周期（cron 表达式） |
| 站点 | 否 | 勾选需要发送消息的站点 |
| 消息内容 | 否 | 一个站点对应一行，多条消息用 `\|` 隔开 |
| 发送间隔秒 | 否 | 每条消息发送间隔，默认 15 秒 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次发送任务

## 📖 使用说明

1. 勾选需要发送消息的站点
2. 在消息内容中填写对应内容（一行对应一个站点）
3. 多条消息用 `|` 分隔，系统会随机选择发送
4. 设置定时周期或手动运行

## ⚠️ 注意事项

- 支持多实例，可为不同站点组创建不同配置
- 发送间隔不宜设置过短，避免触发站点限制
- 消息内容行数需与勾选站点数量对应
