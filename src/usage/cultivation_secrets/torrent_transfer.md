# 🔄 转种

转移下载器中的做种任务到另一个下载器。

## ⚙️ 功能特点

- 支持在不同下载器之间转移做种任务
- 支持多种处理方式：复制、移动、硬链接、软链接
- 支持按路径过滤任务
- 支持按标签过滤任务
- 可定时自动执行转种

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 开关 | 否 | 启用/禁用插件 |
| 通知 | 否 | 开关，转种完成后发送通知 |
| 自动开始 | 否 | 转种后自动开始做种 |
| 定时任务 | 否 | 自动转种频率，cron 表达式 |
| 种子来源路径 | **是** | 种子文件的来源路径 |
| 源下载器 | **是** | 转出任务的下载器 |
| 目标下载器 | **是** | 转入任务的下载器 |
| 处理方式 | 否 | copy/move/hardlink/softlink |
| 标签过滤 | 否 | 仅转移包含指定标签的任务 |
| 包含路径 | 否 | 仅转移匹配路径的任务 |
| 排除路径 | 否 | 排除匹配路径的任务 |

### 🔧 工具栏操作

- **立即转种**：手动触发一次转种操作

## 📖 使用说明

1. 开启插件开关；
2. 选择源下载器和目标下载器；
3. 填写种子来源路径；
4. 选择处理方式（推荐硬链接节省空间）；
5. 根据需要配置标签和路径过滤；
6. 点击「立即转种」验证配置。

## ⚠️ 注意事项

- 非单例插件，可创建多个实例处理不同转种需求
- 硬链接要求源和目标在同一文件系统
- 软链接在跨文件系统时可用，但部分下载器可能不支持
- 移动模式会从源下载器删除任务，请谨慎使用
- 建议先小范围测试再批量转种
