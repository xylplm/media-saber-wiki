# ☁️ 云备份

定时同步本地文件至云存储，支持加解密。

## ⚙️ 功能特点

- 定时将本地文件备份至云存储路径
- 支持 AES-GCM 加密，大文件自适应分块加解密
- 支持动态目录监控（持续写入的目录）
- 支持文件忽略规则（.gitignore 语法）
- 支持多实例，可配置多个备份任务

## 🚀 配置指南

### 基础配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | cron 表达式 |
| 备份路径 | **是** | 要备份的文件所在目录 |
| 云存储路径 | **是** | 备份文件存放的云存储目录 |
| 消息推送 | 否 | 开关 |
| 跳过首次 | 否 | 开关，首次运行时忽略所有文件 |
| 动态目录 | 否 | 开关，持续写入数据的目录，会检查是否在写文件，有性能损耗 |
| 文件忽略 | 否 | .gitignore 规则过滤 |

### 加密配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 加密算法 | 否 | 常规/较高/最高安全级别，**保存后不能更改** |
| 密钥 | 否 | **保存后不能更改，请妥善保管** |
| 生成密钥 | — | 按钮，先选择算法并保存，然后点击生成 |
| 加密路径 | 否 | 加密后文件所在目录 |
| 一键加密 | — | 按钮，执行加密操作 |
| 备份成功删除加密文件 | 否 | 开关 |

### 解密配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 要解密的路径 | 否 | 待解密文件所在目录 |
| 解密输出路径 | 否 | 解密后文件输出目录 |
| 一键解密 | — | 按钮，执行解密操作 |

### 🔧 工具栏操作

- **运行一次**：手动触发一次备份任务
- **异常中断恢复**：从上次中断处继续备份
- **恢复出厂设置**：重置插件配置

## 📖 使用说明

1. 设置备份路径和云存储路径；
2. 如需加密，先选择加密算法并保存，再点击生成密钥；
3. 配置执行周期或手动运行一次验证；
4. 密钥请妥善保管，丢失后无法解密。

## ⚠️ 注意事项

- 加密算法和密钥保存后**不能更改**，请谨慎选择
- 密钥丢失将导致加密文件无法恢复
- 动态目录模式会检查文件写入状态，有一定性能损耗
- 加密采用 AES-GCM 算法，支持大文件（大于 32 MB）自适应分块加解密
