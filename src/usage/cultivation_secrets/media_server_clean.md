# 🧹 媒体服务清理

清理大文件、删除不需要的媒体等。

## ⚙️ 功能特点

- 自动清理超过指定体积的媒体文件
- 支持定时自动执行
- 暂时只支持 Emby 媒体服务器
- 暂时只支持电影类型

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | 定时执行周期（cron 表达式） |
| 媒体库 | 否 | 选择媒体服务器（暂时只支持 Emby） |
| 最大体积GB | 否 | 超过该值的单个媒体文件会被清理 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次清理任务

## 📖 使用说明

1. 选择 Emby 媒体服务器
2. 设置最大体积阈值（单位 GB）
3. 设置定时周期或手动运行

## ⚠️ 注意事项

- 暂时只支持 Emby 媒体服务器
- 暂时只支持电影类型的媒体文件清理
- 清理操作不可逆，请谨慎设置体积阈值
- 本插件为单实例插件，只能添加一个
