# 🏷️ 下载器站点标签

定时给下载器中的种子添加站点标签，方便统计各站点种子数量。

## ⚙️ 功能特点

- 自动识别种子所属站点并添加标签
- 支持多下载器同时处理
- 支持自定义标签前缀
- 可选仅处理已完成种子
- 支持排除特定 Tracker 和筛选种子状态

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 执行周期 | 否 | 定时执行周期（cron 表达式） |
| 下载器 | 是 | 勾选需要处理的下载器 |
| 消息推送 | 否 | 执行完成后发送通知 |
| 仅处理已完成种子 | 否 | 开启后只处理已完成的种子 |
| 覆盖已有标签 | 否 | 开启后覆盖种子已有的标签 |
| 使用站点显示名称 | 否 | 使用站点显示名称作为标签 |
| 标签前缀 | 否 | 标签前缀，如 `site_` |
| 单次最大处理数量 | 否 | 单次最大处理种子数量，默认 500 |
| 排除的Tracker | 否 | 需要排除的 Tracker 地址，逗号分隔 |
| 包含的种子状态 | 否 | 仅处理指定状态的种子，逗号分隔 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次标签任务

## 📖 使用说明

1. 勾选需要处理的下载器
2. 根据需要设置标签前缀和过滤条件
3. 设置定时周期或手动点击"运行一次"执行

## ⚠️ 注意事项

- 支持多实例，可为不同下载器创建不同配置
- 首次运行时种子数量较多可能耗时较长
- 标签前缀建议统一设置，便于管理
