# 📋 PT Depiler 站点

从 PT Depiler 导入站点数据到 Media Saber，快速同步站点配置信息。

## ⚙️ 功能特点

- 从 PT Depiler 批量导入站点数据
- 自动同步站点配置信息
- 单例插件，全局生效
- 支持手动触发导入

## 🚀 配置指南

> 💡 本插件为页面工具（tools-pages），在前端工具页面中使用，通过交互界面完成导入操作。

### 🔧 工具栏操作

- **运行一次**：手动触发一次站点导入

## 📖 使用说明

1. 确保已安装并配置好 PT Depiler；
2. 进入工具页面找到「PT Depiler 站点」；
3. 按照界面提示完成站点数据导入；
4. 导入完成后在站点管理中确认站点信息。

## ⚠️ 注意事项

- 单例插件，全局只能有一个实例
- 导入会同步 PT Depiler 中的站点配置
- 已存在的站点不会被覆盖
- 导入前请确保 PT Depiler 数据准确
