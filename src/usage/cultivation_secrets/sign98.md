# ✅ 98签到

98论坛自动签到与回帖。

## ⚙️ 功能特点

- 自动签到打卡
- 自动回帖评论
- 支持 AI 评论润色
- 支持帖子黑名单过滤
- 定时随机延时执行，模拟真人行为

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 通知 | 否 | 执行完成后发送通知 |
| 代理 | 否 | 使用系统代理 |
| AI评论润色 | 否 | 使用 AI 对回帖内容进行润色 |
| 通知隐藏评论内容 | 否 | 通知中不显示评论内容 |
| 通知隐藏用户信息 | 否 | 通知中不显示用户信息 |
| 仅评论不签到 | 否 | 只回帖不执行签到 |
| 定时任务 | 否 | 定时执行周期（cron 表达式） |
| 域名 | 是 | 论坛域名，不要带 `https://` |
| 版块ID | 否 | 回帖的版块 ID，逗号分隔 |
| 自定义AI模型 | 否 | 指定 AI 润色使用的模型 |
| Cookie | 是 | 论坛 Cookie |
| 回帖内容 | 是 | 回帖内容列表，一行一条 |
| AI补充提示词 | 否 | AI 润色的补充提示词 |
| 帖子标题黑名单 | 否 | 包含关键词的帖子不回复 |
| 帖子内容黑名单 | 否 | 包含关键词的帖子不回复 |
| 发帖人黑名单 | 否 | 指定用户的帖子不回复 |

### 🔧 工具栏操作

- **签到**：立即执行一次签到
- **AI润色测试**：测试 AI 润色效果
- **获取Cookie**：自动获取论坛 Cookie

## 📖 使用说明

1. 填写论坛域名（不带 `https://`）
2. 点击"获取Cookie"或手动填写 Cookie
3. 填写回帖内容（一行一条）
4. 如需 AI 润色，开启后先进行润色测试
5. 设置定时任务周期

## ⚠️ 注意事项

- 可设置每天 2 次签到
- 系统 UA 不要使用手机 UA
- 开启 AI 评论润色后请先进行润色测试确认效果
- 定时时间系统会默认往后半小时内随机延时
- 支持多实例
