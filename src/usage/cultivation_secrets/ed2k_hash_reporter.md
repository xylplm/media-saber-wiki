# 🔗 ED2K 链接 HASH 上报

云存储 HASH 上报的 ED2K 专用版本。适用于只有 ED2K 链接、没有本地文件的场景，直接从链接中提取 MD4 HASH 并上报到云端。

## ⚙️ 功能特点

- 无需本地文件，直接从 ED2K 链接提取 HASH
- 支持直接粘贴多行 ED2K 链接
- 支持从本地列表文件批量导入
- 文本与文件可同时使用，自动合并去重
- 支持并发处理，最大 10 并发
- 支持多实例

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 云存储驱动名 | **是** | 仅显示支持 MD4/ED2K HASH 上报的驱动 |
| ED2K 文本 | 否 | 直接粘贴 ED2K 链接，每行一个，支持 `#` 和 `//` 注释 |
| 列表文件路径 | 否 | 本地 ED2K 列表文件的绝对路径 |
| 并发数 | 否 | 同时处理的条目数量，默认 1，最大 10 |
| 周期执行 | 否 | Cron 表达式，留空则仅手动运行 |
| 消息推送 | 否 | 开启后推送导入与上报汇总结果 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次导入上报

## 📖 使用说明

1. 选择支持 ED2K HASH 上报的云存储驱动；
2. 在「ED2K 文本」中粘贴链接，或填写列表文件路径；
3. 点击「运行一次」测试上报是否正常；
4. 如需定期导入新链接，可设置周期执行。

### ED2K 链接格式

```
ed2k://|file|文件名.mkv|文件大小|HASH值|/
```

## ⚠️ 注意事项

- 当前只支持具备 MD4 上报语义的驱动；
- HASH 会被规范化为 `ed2k:md4:size` 格式上报；
- 空行和注释行（`#`、`//` 开头）会被自动忽略。
