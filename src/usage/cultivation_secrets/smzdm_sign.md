# 🛒 什么值得买签到

什么值得买自动签到。

## ⚙️ 功能特点

- 自动每日签到
- 支持自动获取 Cookie
- 执行结果消息通知

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 通知 | 否 | 执行完成后发送通知 |
| 定时任务 | 否 | 定时执行周期（cron 表达式） |
| Cookie | 是 | 什么值得买 Cookie |

### 🔧 工具栏操作

- **签到**：立即执行一次签到
- **获取Cookie**：自动获取站点 Cookie

## 📖 使用说明

1. 访问 `https://zhiyou.smzdm.com/user/tequan/` 登录账号
2. 点击"获取Cookie"或手动导出 Cookie 填写
3. 设置定时任务周期

## ⚠️ 注意事项

- Cookie 获取网址为 `https://zhiyou.smzdm.com/user/tequan/`
- Cookie 过期后需重新获取
- 支持多实例
