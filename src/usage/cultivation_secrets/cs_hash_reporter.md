# 📤 云存储 HASH 上报

递归扫描本地目录中的媒体文件，通过消息队列异步生成并上报文件 HASH 到云端，用于云存储资源匹配和共享。

## ⚙️ 功能特点

- 递归扫描指定本地目录下的所有媒体文件
- 通过 MQ 异步生成并上报 HASH 到云端
- 上报本地文件时自动探测采集媒体信息（规格 / 编码 / 音轨字幕等，见下文「媒体信息采集」）
- 支持按文件体积过滤，跳过样片/预告片等小文件
- 支持自动执行（重启后自动开始）
- 支持多实例，可为不同目录创建独立配置

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 自动执行 | 否 | 开启后每次更新或重启 MS 后自动开始扫描上报 |
| 消息推送 | 否 | 开启后推送本次扫描和任务投递结果 |
| 扫描目录 | **是** | 递归扫描该本地目录下的媒体文件 |
| 云存储驱动名 | **是** | 选择上报时使用的云存储驱动，根据实际上传的云存储选择 |
| 最小体积(MB) | 否 | 小于该体积的文件不上报，适合过滤样片等小文件，不填或 0 表示不过滤 |
| 贡献榜数量 | 否 | 完整榜单默认展示条数，默认 15（首页工作台预览固定前三） |

### 🔧 工具栏操作

- **运行一次**：立即执行一次扫描上报

## 📖 使用说明

1. 选择需要扫描的本地媒体目录（需为本地存储路径）；
2. 选择对应的云存储驱动名（决定上报到云端时的驱动标识）；
3. 如有大量小文件（预告片、样片等），建议设置最小体积过滤；
4. 点击「运行一次」测试，确认扫描和上报正常后可开启自动执行；
5. 上报结果可在首页 **天序工作台 · Hash 贡献榜** 查看预览与完整榜单（不再提供独立首页部件）。

## 📊 媒体信息采集

插件在扫描上报 **本地文件** 时，会自动使用系统的 ffprobe 探测组件读取文件的媒体信息，归一后随 HASH 一并上报，无需额外配置：

- **采集内容**：分辨率档位（4320p / 2160p / 1080p / 1080i / 720p / 480p 等）、视频 / 音频编码、声道、HDR 类型（杜比视界 / HDR10 / HLG / SDR）、是否标注含中文音轨 / 中文字幕，以及容器、时长、码率和完整的音轨字幕语言清单；
- **云端资源页能力**：[云端资源](/usage/cloud_storage/resource.html) 列表支持按 **规格 / HDR / 中文字幕 / 中文音频** 筛选，资源卡片与详情弹窗会展示规格徽章和探测到的媒体信息；
- **仅本地文件生效**：只有本地真实文件会被探测；云对云转存、分享接收等场景照常上报 HASH 但 **不联网探测**，这类资源没有媒体信息属正常现象；
- **探测失败不影响上报**：ffprobe 不可用、单文件超时或个别文件探测失败时只记日志，HASH 照常上报，不受影响。

::: tip ffprobe 依赖
媒体信息采集依赖系统已安装 ffprobe。未安装时首次触发会自动尝试安装；若失败，请前往 **系统设置 → 基础配置 → ffprobe 探测组件** 卡片一键安装或手动上传安装包。
:::

## ⚠️ 注意事项

- 扫描目录必须为本地存储路径，不支持云存储挂载路径；
- 大目录首次扫描可能耗时较长，请耐心等待；
- 上报依赖 MQ 服务，确保系统消息队列正常运行；
- 站长可在运维管理中维护 **上传屏蔽词**：文件名、描述或标签包含屏蔽词的资源会被拒绝上报（任务状态显示「内容不符合要求，跳过上报」），不会计入云端贡献，本地文件不受影响——修改文件名后可重新上报。
