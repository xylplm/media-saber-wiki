# 💾 自动备份

自动备份系统配置文件和数据库。

## ⚙️ 功能特点

- 定时自动备份系统配置文件
- 支持同时备份 PostgreSQL 数据库
- 自动清理过期备份，保留指定数量
- 支持自定义备份目录
- 单例插件，全局生效

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 定时任务 | 否 | 备份频率，cron 表达式 |
| 备份最大保存数量 | **是** | 超过后自动删除最早的备份 |
| 通知 | 否 | 开关，备份完成后发送通知 |
| 备份数据库 | 否 | 开关，开启后同时备份 PostgreSQL 数据库 |
| 备份位置 | 否 | 指定自定义备份目录，留空使用默认 `./config/backup` |

### 🔧 工具栏操作

- **立即备份一次**：手动触发一次完整备份
- **下载最新备份**：下载最近一次备份文件

## 📖 使用说明

1. 设置备份频率和最大保存数量；
2. 根据需要开启数据库备份；
3. 如需自定义备份路径，填写备份位置；
4. 点击「立即备份一次」验证配置是否正常。

## ⚠️ 注意事项

- **配置文件恢复**：解压备份文件，将 `basic.yaml` 和 `default_categories.yaml` 复制到 config 目录
- **数据库恢复**：`psql -U username -d database_name < backup.sql`
- 恢复前请先停止系统服务
