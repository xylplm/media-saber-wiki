# 💚 绿联NAS社区助手

绿联NAS社区自动登录活跃和回复帖子，请勿滥用！

## ⚙️ 功能特点

- 自动登录活跃（每日访问论坛首页）
- 自动回复帖子
- 支持 AI 评论润色
- 支持帖子标题黑名单过滤
- 定时随机延时执行

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 通知 | 否 | 执行完成后发送通知 |
| 登录活跃 | 否 | 每天自动访问论坛首页 |
| 回复帖子 | 否 | 自动回复帖子，慎重开启 |
| AI评论润色 | 否 | 使用 AI 对回帖内容进行润色 |
| 通知隐藏评论内容 | 否 | 通知中不显示评论内容 |
| 通知隐藏用户信息 | 否 | 通知中不显示用户信息 |
| 定时任务 | 否 | 定时执行周期（cron 表达式） |
| 回复帖子版块ID | 否 | 指定回复的版块 ID |
| 每次回复帖子数量 | 否 | 单次最多 5 条，每天最多 20 条 |
| 自定义AI模型 | 否 | 指定 AI 润色使用的模型 |
| Cookie | 是 | 绿联社区 Cookie |
| 回帖内容 | 否 | 回帖内容列表，一行一条 |
| AI补充提示词 | 否 | AI 润色的补充提示词 |
| 帖子标题黑名单 | 否 | 包含关键词的帖子不回复 |

### 🔧 工具栏操作

- **每日活跃**：立即执行一次登录活跃
- **AI润色测试**：测试 AI 润色效果
- **获取Cookie**：自动获取社区 Cookie

## 📖 使用说明

1. 点击"获取Cookie"或手动填写社区 Cookie
2. 根据需要开启"登录活跃"和/或"回复帖子"
3. 如开启回复帖子，填写回帖内容
4. 如需 AI 润色，开启后先进行润色测试
5. 设置定时任务周期

## ⚠️ 注意事项

- 登录活跃每天自动访问论坛首页
- 回复帖子单次最多 5 条，每天最多 20 条
- 开启 AI 评论润色后请先进行润色测试确认效果
- 定时时间系统会默认往后半小时内随机延时
- 本插件仅供学习测试，不对账号安全性负责
- 本插件为限量插件，支持多实例
