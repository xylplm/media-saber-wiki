# 💚 绿联服务助手

集成绿联 NAS 状态查询和状态告警通知功能。支持系统消息推送、CPU/内存/温度阈值告警，并作为 NAS 信息提供者接入首页 **天序工作台 · 系统机体**。

## ⚙️ 功能特点

- 定时获取绿联系统消息并推送通知
- 系统状态监控：CPU、内存、温度阈值告警
- 作为 nasInfo provider 接入天序工作台「系统机体」（可与本机切换）
- 支持图文消息格式推送（含详细磁盘和存储信息）
- 支持多实例，可配置多台绿联 NAS

## 🚀 配置指南

### 连接配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 服务器地址 | **是** | 完整地址，如 `http://192.168.31.88:9999` |
| 绿联用户名 | **是** | 绿联 NAS 登录用户名 |
| 绿联密码 | **是** | 绿联 NAS 登录密码 |

### 系统消息通知

| 参数 | 必填 | 说明 |
|------|------|------|
| 启用系统消息通知 | 否 | 绿联有新系统消息时发送通知 |
| 消息推送定时任务 | 否 | 获取频率，推荐 `*/10 * * * *`（每10分钟） |

### 系统状态告警

| 参数 | 必填 | 说明 |
|------|------|------|
| 启用其他服务最新状态查询 | 否 | 允许其他服务调用绿联状态接口 |
| 启用系统状态提醒通知 | 否 | 超过阈值时发送告警 |
| 启用图文消息(mpnews) | 否 | 以图文格式推送状态（含磁盘和存储详情），需消息渠道支持 |
| 系统状态检测定时任务 | 否 | 检测频率，推荐 `*/5 * * * *`（每5分钟） |
| 系统状态提醒发送频率(分钟) | 否 | 告警发送间隔，默认每次都发 |
| CPU 提醒百分比阈值 | 否 | 默认 80% |
| 内存提醒百分比阈值 | 否 | 默认 80% |
| 温度提醒阈值(℃) | 否 | 默认 60℃ |

### 🔧 工具栏操作

- **立即执行一次**：手动触发一次状态采集
- **手动发送状态通知**：立即发送一次状态告警通知

## 📖 使用说明

1. 填写绿联 NAS 的地址、用户名和密码；
2. 根据需要开启系统消息通知和/或状态告警；
3. 如需图文格式推送，开启「启用图文消息」（需消息渠道支持且配置了默认背景图）；
4. 点击「立即执行一次」验证连接是否正常。

## ⚠️ 注意事项

- 确保 Media Saber 容器能访问绿联 NAS 的地址和端口；
- 图文消息需要消息渠道支持 mpnews 格式；
- 状态检测频率不宜过高，推荐 5 分钟以上；
- 消息推送频率推荐 10 分钟以上。
