# 🌐 远程网络唤醒

通过标准 WOL（Wake-on-LAN）魔术包远程唤醒局域网设备，支持定时唤醒和广播/单播两种发送模式。

## ⚙️ 功能特点

- 发送标准 WOL 魔术包唤醒设备
- 支持广播发送和单播发送
- 广播失败时自动回退到目标地址
- 支持从局域网 ARP 邻居表自动发现 MAC 地址
- 支持定时唤醒和手动唤醒
- 支持失败重试
- 支持多实例，可为不同设备创建独立配置

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 消息推送 | 否 | 开启后推送唤醒执行结果 |
| 定时唤醒 | 否 | Cron 表达式，如 `0 8 * * *`（每天早8点） |
| 目标 MAC 地址 | **是** | 被唤醒设备的 MAC 地址，如 `AA:BB:CC:DD:EE:FF` |
| 开启广播 | 否 | 默认开启，先发广播地址，失败回退到目标地址 |
| 广播地址 | 否 | 默认 `255.255.255.255`，可填网段广播地址 |
| 目标地址 | 否 | 关闭广播时必填；开启广播时作为回退地址 |
| UDP 端口 | 否 | 常见为 9 或 7，默认 9 |
| 重试次数 | 否 | 失败后的额外重试次数，默认 2 |
| 重试间隔(秒) | 否 | 每次重试的等待秒数，默认 5 |

### 🔧 工具栏操作

- **唤醒一次**：立即发送一次唤醒包

## 📖 使用说明

1. 确保目标设备已开启 WOL 功能（通常在 BIOS/UEFI 中设置）；
2. 填写目标设备的 MAC 地址（支持手动输入或从自动发现列表选择）；
3. 一般情况下保持默认的广播模式即可；
4. 跨网段场景可关闭广播，直接指定目标 IP 地址；
5. 点击「唤醒一次」测试是否能成功唤醒。

## ⚠️ 注意事项

- 目标设备必须支持并已开启 WOL 功能；
- 自动发现 MAC 地址依赖系统 ARP 邻居表，需目标设备近期在同一网段出现过；
- 跨网段唤醒需要路由器支持转发广播包或使用单播模式；
- WOL 只能唤醒，不能关机或重启。
