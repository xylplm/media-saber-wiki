# 📁 媒体库文件夹合并

自动将旧媒体库目录中的文件合并到带有 TMDB ID 的新目录下。适用于媒体库从无 TMDB ID 命名迁移到规范命名的场景。

**示例：** `猎罪图鉴 (2022)` → `猎罪图鉴 (2022) {tmdb-139797}`

## ⚙️ 功能特点

- 只合并到带有 TMDB ID 的目标文件夹
- 目标已有同名文件时不覆盖，冲突文件移至备份目录
- 处理完成后自动删除无媒体文件的空目录
- 备份文件已存在时自动追加序号
- 旧目录和新目录可以相同（同父目录模式）

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 旧目录 | **是** | 需要合并出去的旧媒体库目录 |
| 新目录 | **是** | 合并目标目录，可与旧目录相同 |
| 备份目录 | **是** | 冲突文件的备份存放位置 |
| 消息推送 | 否 | 开启后推送本次合并结果 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次合并

## 📖 使用说明

1. 确认新目录中已有带 TMDB ID 的文件夹（如 `{tmdb-xxxxx}` 格式）；
2. 配置旧目录、新目录和备份目录；
3. **运行前必须先关闭「云存储管理 / 媒体库联动删除云存储」**，否则插件会拒绝执行；
4. 点击「运行一次」执行合并。

### 合并逻辑

- 目标位置不存在 → 移动文件到新目录
- 目标已有同名文件 → 不覆盖目标，将旧目录中的冲突源文件移到备份目录
- 处理完成后 → 删除旧目录中无媒体文件的空目录

## ⚠️ 注意事项

- ⚠️ **运行前必须关闭「媒体库联动删除云存储」**，否则插件拒绝执行；
- 本插件为单例，全局只能有一个实例；
- 合并操作涉及文件移动，建议先备份重要数据；
- 旧目录和新目录相同时，会按同父目录模式扫描下级目录对。
