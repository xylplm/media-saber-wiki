# 📝 订阅 MP 云识别词

订阅 MP 共享的识别词，并自动生成识别词数据。

## ⚙️ 功能特点

- 自动下载并同步 MP 云识别词
- 支持多个下载链接
- 支持 Github 文件地址
- 可一键删除已同步数据

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | 定时执行周期（cron 表达式） |
| 下载链接 | 否 | 识别词文件地址，一行一个 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次同步
- **删除数据**：删除已同步的识别词数据

## 📖 使用说明

1. 在下载链接中填写识别词文件地址（一行一个）
2. Github 文件地址请填写包含 `raw` 的直链地址
3. 设置定时周期或手动运行

## ⚠️ 注意事项

- Github 文件地址请使用 raw 直链格式
- 本插件为单实例插件，只能添加一个
- "删除数据"操作不可逆，请谨慎使用
