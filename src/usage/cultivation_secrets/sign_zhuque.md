# 🔥 朱雀签到

朱雀站点修仙系统自动签到插件，支持原神角色技能自动释放，智能管理多角色技能冷却时间，获取灵石奖励。

## ⚙️ 功能特点

- 自动检查并释放角色技能，获取灵石奖励
- 智能管理多个角色的技能冷却时间
- 根据最低等级角色自动调度下次释放
- 支持时间微调，避免因时间误差导致技能未冷却
- 支持多实例

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 通知 | 否 | 开启后推送执行结果（需在消息通知渠道中勾选本插件） |
| 定时任务 | 否 | Cron 表达式，建议间隔 1 小时以上，如 `5 */2 * * *`（每2小时第5分钟） |
| 时间微调(秒) | 否 | 在计算的释放时间基础上增加的秒数，建议 0-60 秒 |

### 🔧 工具栏操作

- **立即执行**：立即检查并释放可用技能

## 📖 使用说明

1. 先在「站点管理」中配置朱雀站点的登录信息；
2. 启灵本插件，设置定时任务周期；
3. 点击「立即执行」验证是否能正常释放技能；
4. 插件会自动管理冷却时间，无需手动干预。

## ⚠️ 注意事项

- 必须先在站点管理中配置朱雀站点登录信息；
- 为了账号安全，定时任务间隔建议保持在 1 小时以上；
- 时间微调用于补偿服务器时间差，一般设 0 即可。
