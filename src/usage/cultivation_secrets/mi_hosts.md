# 🌐 小米路由Hosts

定时将本地 Hosts 同步至小米路由 Hosts。

## ⚙️ 功能特点

- 自动同步本地 Hosts 到小米路由器
- 支持替换模式和合并模式
- 支持忽略列表过滤
- 可选读取全部 Hosts 或仅自定义部分

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 运行通知 | 否 | 执行完成后发送通知 |
| 读取全部hosts | 否 | 推荐关闭，仅同步自定义部分 |
| 合并模式 | 否 | 推荐关闭，使用替换模式 |
| 同步周期 | 否 | 定时执行周期（cron 表达式） |
| 应用ID | 是 | 米家 App 应用 ID |
| 设备ID | 是 | 小米路由器设备 ID |
| 客户端ID | 是 | 客户端 ID |
| 作用域 | 否 | 默认 `1+1000+3` |
| 访问令牌 | 是 | 米家 App 访问令牌 |
| 忽略列表 | 否 | 不同步的 Hosts 条目，`|` 分隔 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次同步

## 📖 使用说明

1. 通过抓包米家 App 获取应用 ID、设备 ID、客户端 ID 和访问令牌
2. 填写相关参数
3. 推荐关闭"读取全部hosts"和"合并模式"
4. 设置同步周期或手动运行

## ⚠️ 注意事项

- 参数获取方法涉及抓包米家 App，需要一定技术基础
- 推荐关闭合并模式，使用替换模式避免冗余
- 推荐关闭读取全部 Hosts
- 本插件为单实例插件，只能添加一个
