# 📚 豆瓣榜单订阅

自动添加未入库的电影、电视剧订阅。

## ⚙️ 功能特点

- 支持多个豆瓣榜单同时订阅
- 自动检测未入库影视并添加订阅
- 支持自定义榜单地址
- 支持豆瓣想看、爱看列表订阅
- 可控制获取页数，避免过度请求

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 周期 | 否 | 定时执行周期（cron 表达式） |
| 榜单 | 否 | 勾选需要订阅的榜单，建议控制在 3 个以内 |
| 获取前n页 | 否 | 每个榜单获取的页数，建议控制在 3 以内 |
| 自定义榜单 | 否 | 自定义榜单地址，一行一个 |

### 🔧 工具栏操作

- **运行一次**：立即执行一次榜单订阅任务

## 📖 使用说明

1. 勾选需要订阅的豆瓣榜单
2. 如需自定义榜单，在文本框中填写地址（一行一个）
3. 设置定时周期或手动点击"运行一次"执行

## ⚠️ 注意事项

- 如需订阅豆瓣想看、爱看列表，请先在【系统配置 -> 服务配置 -> 豆瓣Cookie】填写豆瓣 Cookie
- 榜单数量建议控制在 3 个以内，避免频繁请求
- 获取页数建议控制在 3 以内
- 本插件为单实例插件，只能添加一个
