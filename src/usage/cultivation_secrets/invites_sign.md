# 💊 药丸签到

药丸（Invites）站点自动签到。

## ⚙️ 功能特点

- 自动每日签到
- 支持代理访问
- 支持自动获取 Cookie
- 执行结果消息通知

## 🚀 配置指南

| 参数 | 必填 | 说明 |
|------|------|------|
| 通知 | 否 | 执行完成后发送通知 |
| 代理 | 否 | 使用系统代理 |
| 定时任务 | 否 | 定时执行周期（cron 表达式） |
| Cookie | 是 | 站点 Cookie |

### 🔧 工具栏操作

- **签到**：立即执行一次签到
- **获取Cookie**：自动获取站点 Cookie

## 📖 使用说明

1. 点击"获取Cookie"或手动填写站点 Cookie
2. 设置定时任务周期
3. 保存后将自动定时执行

## ⚠️ 注意事项

- Cookie 过期后需重新获取
- 支持多实例
