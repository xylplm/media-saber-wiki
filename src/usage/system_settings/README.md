# ⚙️ 系统设置

系统设置包含 Media Saber 的各项基础配置，包括基础设置、用户管理、种子排序、种子匹配、消息通知和过滤规则等功能模块。

## 📋 功能模块

系统设置包含以下主要功能模块：

### 🎛️ [基础设置](./basic_settings)
系统各项基础配置，包括代理服务器、外网访问地址、媒体库路径等核心设置。

### 👥 [用户管理](./user_management)
用户账户的管理和权限设置。

### 📊 [种子排序](./torrent_sort)
种子文件的排序规则和优先级配置。

### 🎯 [种子匹配](./torrent_match)
种子文件与媒体资源的匹配规则配置。

### 📨 [消息通知](./message)
系统消息通知的配置，包括邮件、微信、Telegram等通知方式。

### 🔍 [过滤规则](./filter_rules)
媒体资源过滤规则的设置和管理。

## 🔧 配置建议

1. **基础设置**：建议首先配置代理服务器和外网访问地址，确保系统能正常访问外部服务。
2. **用户管理**：根据实际使用需求设置用户权限。
3. **种子相关**：根据下载器类型和资源特点调整排序和匹配规则。
4. **通知服务**：配置合适的通知方式，及时了解系统运行状态。
5. **过滤规则**：根据媒体库需求设置合适的过滤条件。
