# ⚙️ 系统设置

系统设置包含 Media Saber 的各项基础配置，包括基础设置、用户管理、种子排序、种子匹配、消息通知和过滤规则等功能模块。

## 📋 功能模块

系统设置包含以下主要功能模块：

### 🎛️ [基础设置](./basic_settings)
系统各项基础配置，包括基础配置、媒体配置、订阅搜索、媒体整理、刮削配置、智能体配置和第三方服务配置。页面支持悬浮保存条、实际修改数量提示，以及 PC、平板、手机、2K、4K 的自适应表单布局。

### 👥 [用户管理](./user_management)
用户账户的管理和权限设置。

### 📊 [种子排序](./torrent_sort)
种子文件的排序规则和优先级配置。

### 🎯 [种子匹配](./torrent_match)
种子文件与媒体资源的匹配规则配置。

### 📨 [消息通知](./message)
系统消息通知的配置，包括企业微信、飞书、Telegram 等渠道；Telegram / 飞书 / 微信支持远程交互。

### 🔍 [过滤规则](./filter_rules)
媒体资源过滤规则的设置和管理。

### 🩺 [系统体检](./system_health)
集中检查站点、下载器、媒体服务器、云盘、网络与队列的健康状态，提供健康评分、问题定位与一键修复引导。

## 🔧 配置建议

1. **基础设置**：建议首先配置代理服务器、外网访问地址和 TMDB API Key，确保系统能正常访问外部服务；批量修改后通过底部悬浮保存条统一保存。
2. **用户管理**：根据实际使用需求设置用户权限。
3. **种子相关**：根据下载器类型和资源特点调整排序和匹配规则。
4. **通知服务**：配置合适的通知方式，及时了解系统运行状态。
5. **过滤规则**：根据媒体库需求设置合适的过滤条件。
