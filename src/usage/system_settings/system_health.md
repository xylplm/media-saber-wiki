# 🩺 系统体检

> 系统体检把分散在各处的依赖项（站点、下载器、媒体服务器、云盘、网络、任务队列、运行时资源）汇总成一份集中的"体检报告"，一键检查各功能点是否正常，并给出红黄绿状态、健康评分与一键修复引导。出问题时不用再到处翻，进这一个页面就能定位和处理。

入口：**系统设置 → 系统体检**。

---

## 🔎 页面构成

进入页面无需等待，会先展示一批低成本、即时可见的信息；深度连通检测则由「一键体检」按需触发。

### 即时状态

页面顶部的状态卡片实时反映运行时与配置概况，进页面即可看到：

- **CPU / 内存 / 磁盘**：当前使用率，超过阈值会变黄（≥85%）或变红（≥95%）。
- **任务队列**：待处理任务数与今日失败数。
- **版本**：当前运行版本。

### 快捷检查

针对最常用的几类依赖（网络、站点、下载器、媒体服务器、云盘）提供快捷卡片：

- 显示该类已配置的数量与最近一次检查的状态灯。
- **检查**：只对该一类做连通检测，结果即时并入体检报告。
- **前往配置**：直接跳转到对应的配置页面。

### 常见问题排查

内置一份常见问题知识库（默认折叠，点击标题展开），针对高频疑难给出"现象 + 原因建议 + 一键处理"，例如：

| 现象 | 建议 |
| --- | --- |
| TMDB 连接超时 / 刮削失败 | 配置可用的代理服务器 |
| 微信收不到消息图片 | 配置外网访问地址 |
| 所有站点显示未适配 | 拉取最新站点配置 |
| 种子被识别成另一部剧 | 添加识别词进行纠正 |
| 云盘播放 / 转存报错 | 重新授权对应网盘 |
| 下载任务无法添加 | 检查下载器配置与连通 |

可映射到检查项的条目提供「检测」按钮一键排查，其余直接「去处理」跳转到相应页面。

---

## 🩺 一键体检

点击顶部的 **一键体检**，系统会逐项检查各功能点：

- 检查项以流式方式**一项一项点亮**，进度实时可见。
- 全部完成后给出 **健康评分（0–100）** 与等级（优秀 / 良好 / 需处理）。
- 评分采用扣分制：异常按重要程度扣分较多，警告扣分较少，**未配置的项不扣分**（不会无端制造焦虑）。

体检范围包括：

- **运行时**：CPU、内存、磁盘空间。
- **网络可达**：TMDB、代理出口、豆瓣等。
- **第三方服务**：Pansou、OCR、所选过盾增强服务等。
- **下载器 / 媒体服务器 / 站点 / 云盘**：逐个实例连通检测。
- **任务队列**：积压、今日失败、是否有暂停的队列。

## 🚦 体检报告

### 待处理问题

体检后，所有"警告 / 异常"会汇总到顶部的 **待处理问题** 面板，按严重程度置顶，每条都带跳转修复入口，无需在分组里逐个翻找。

### 分组明细

报告按依赖类型分组、整行展示，**有问题的分组自动排在前面**，全部正常的分组默认收起。每个问题项提供三段式说明：

- **结论**：一句话说清哪里有问题。
- **原因**：为什么会这样、有什么影响。
- **建议**：如何修复。

每个检查项还支持以下操作：

- **去修复**：跳转到对应配置页。
- **重新检查**：只重测该项，原地见效。
- **忽略 / 恢复**：对暂时无需处理的项（如临时下线的站点）进行忽略，忽略后不再计分、不再告警，可随时恢复。
- **复制诊断信息**：一键复制该项的状态与详情，便于求助或反馈。

---

## 📊 首页如何看到体检分

- **天序工作台顶栏**：固定展示体检分与健康级别，点击即可进入本页；工作台「系统机体」也可直达体检中心。
- **自定义部件（可选）**：仍可在首页定制中添加 **「系统-体检概览」** 小部件，查看评分与正常 / 警告 / 异常数量。

---

## ⚠️ 关于"非实时"

体检报告是一次检查的**快照**，会被缓存下来，方便你跳转到其他页面修复后再回来查看，不会丢失。

但请注意：**报告不是实时的**。如果你已经在其他页面修复了某个问题，体检页不会自动感知，需要点击对应项的 **重新检查**，或重新做一次 **一键体检** 来刷新状态。页面顶部也会标注"X 分钟前体检"作为提醒。
