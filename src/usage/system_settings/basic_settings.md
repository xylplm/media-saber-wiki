# 🎛️ 基础设置

> 本文档详细介绍 **Media Saber** 系统的各项基础配置。系统设置页面已组织为 **7 个功能模块**，每个设置字段都配有详细的**用途说明**、**默认值示例**和**操作建议**，并已适配 PC、平板、手机、2K 与 4K 屏幕，帮助你快速上手和高效配置。

::: warning 📌 重要提示

- **TMDB API Key** 是必配项，没有它系统无法正常运行
- 某些配置（如代理、超时时间）需要根据你的网络环境调整
- 标有 **⚠️** 的配置项为高级调试选项，非必要情况下建议保持默认值
- 部分字段修改后需要重启应用才能生效
- 修改配置后，页面底部会出现悬浮保存条；把字段改回原值时，修改数量会自动回落

:::

## 💾 保存与页面交互

系统配置页面采用选项卡分组展示，表单会根据屏幕宽度自动调整列数：手机单列、平板双列、PC 多列，2K/4K 屏幕会展示更舒展的多列布局。长地址、重命名模板、正则等内容较长的字段会自动占用更宽区域，开关类配置会保持紧凑，避免大屏空旷或小屏拥挤。

当你修改配置后，页面底部会出现悬浮保存条：

- 显示当前实际修改项数量
- 保存中、已保存、保存失败会有状态提示
- 将某个字段改回原值后，该字段不再计入修改数量
- 没有实际修改时不会显示保存条
- 保存过程中继续修改其它字段时，未保存的修改会继续保留提示

::: tip 使用建议
批量调整多个选项卡时，可以先逐项修改，最后点击悬浮保存条统一保存。若某项只是试改，直接改回原值即可，系统不会把它计入待保存数量。
:::

## ⚙️ 基础配置 (系统配置)

### 代理服务器
**说明：** 将使用代理服务器访问themoviedb、telegram、google等境外网站和服务，拉取站点配置文件、系统更新同样需要代理；站点默认不使用代理，如需使用需在站点维护中开启。

#### 📋 什么时候需要配置

- TMDB 刮削、Telegram 通知等境外服务访问超时或失败
- 站点配置拉取、系统更新卡住不动（两者都要访问 GitHub）

如果所在网络可以直连访问上述服务，**不用配置**，留空即可。

#### 🔗 代理地址从哪里获取

代理地址来自你电脑或 NAS 上的代理软件（Clash、v2rayN、sing-box 等），在软件的端口设置里查看「本地监听端口 / 混合端口」，按它支持的协议拼上 `http://` 或 `socks5://` 前缀：

- Clash 系默认混合端口 `7890`，可填 `http://127.0.0.1:7890`
- v2rayN 系默认 SOCKS 端口 `10808`，可填 `socks5://127.0.0.1:10808`

::: warning ⚠️ Docker 部署必看
Media Saber 跑在 Docker 里时，`127.0.0.1` 指容器自己，**不是**宿主机。代理软件装在宿主机或别的机器上时，要写成那台机器的内网 IP，例如 `http://192.168.1.10:7890`，并且代理软件要开启「允许局域网连接（Allow LAN）」。
:::

#### 📝 格式速查

| 场景 | 格式示例 |
|------|----------|
| Http 代理 | `http://127.0.0.1:7890` |
| SOCKS5 代理 | `socks5://127.0.0.1:8018` |
| SOCKS5 远程解析域名（域名解析走代理端） | `socks5h://127.0.0.1:8018` |
| 带账号密码的 Http 代理 | `http://用户名:密码@127.0.0.1:7890` |
| 带账号密码的 SOCKS5 代理 | `socks5://用户名:密码@127.0.0.1:8018` |

::: warning ⚠️ 常见填写错误
- 必须带协议前缀（`http://` 或 `socks5://`），只写 `127.0.0.1:7890` 无效
- 冒号、@ 必须是英文半角符号，不能输入中文全角的 `：` `＠`
- 用户名或密码里含 `@` `:` `/` 等特殊字符时要做 URL 转码，例如 `@` 写成 `%40`
- 填完记得点页面下方的保存
:::

**默认值/示例：** 空

**操作建议：** 需要访问 TMDB、Telegram、GitHub（拉取站点配置、系统更新）等境外服务时才配置；配置保存后立即生效，无需重启。某个站点要不要走代理，去「站点维护」里按站点单独开启。

**说明：** 用于外网访问访问本系统使用的地址，通常为http协议://域名:端口，如：http://www.example.com:8888

::: warning ⚠️ 修改警告
修改此地址会影响：消息提示中的图片链接、外部访问资源的URL、Strm文件内部的访问路径。如果已使用 Strm 功能，修改后请前往：云存储 → Strm生成 → Strm修复 → 修复Host。
:::

**默认值/示例：** 空
- `http://your.domain:8443`

**操作建议：** 填写完整协议和端口，Telegram Webhook 推荐 88 或 8443。

::: warning ⚠️ 修改警告
修改此地址同样会影响消息链接、资源 URL 和 Strm 文件路径，修改前请确认影响范围。
:::

**说明：** 可以指定登录跳转指定页面菜单，不再是默认首页

**默认值/示例：** `默认首页`

**操作建议：** 可选填，如 `我的媒体库`、`寻影探剧`、`搜索任务`、`站点数据`、`站点签到`、`站点资源`、`站点公告`、`站点消息`、`电影订阅`、`电视剧订阅`、`正在下载`、`目录同步`、`小工具`等。

### User-Agent
**说明：** 程序所有对外请求都将默认使用此User-Agent。如发现被豆瓣、PT站等封堵，请适当修改此项

**默认值/示例：** 当前浏览器 UA

**操作建议：** 如被豆瓣/PT站封禁可自定义 UA。可点击输入框后的箭头按钮获取当前浏览器的User-Agent。

### GitHub Token
**说明：** GitHub 个人访问令牌（PAT），用于访问 GitHub API。突破 GitHub API 的匿名访问限制（60 次/小时），提升至 5000 次/小时，确保程序更新、站点配置文件拉取、CTMD 自建 TMDB 信息文件获取等功能的稳定性和速度。详细获取教程请参见 [GitHub Token 生成获取教程](/usage/other/github_token.md)

**默认值/示例：** 空
- `ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

**操作建议：** 用于程序更新、站点配置文件拉取、CTMD 信息文件获取等功能。强烈推荐配置此项以获得更好的使用体验。Token 建议设置 30-90 天的有效期并定期轮换。[点击查看详细教程](/usage/other/github_token.md)

## 🎬 媒体配置

### TMDB API Key
**说明：** 在themoviedb.org网站申请API Key，该项必须配置，否则所有功能无法正常运行

**默认值/示例：** 空
- `xxxxxxx`

**操作建议：** 无此项无法正常匹配媒体。必须配置此项才能使用系统功能。

### TMDB 接口地址
**说明：** TMDB 接口地址，可自建代理服务，留空默认使用 TMDB 官方地址。第三方代理域名地址不保证完全可用，请斟酌使用。

**默认值/示例：** 空（留空使用官方地址）
- `https://api.themoviedb.org/3` (官方地址)
- `https://api.tmdb.org/3` (官方地址)
- 自建代理服务参考：[GateCross/ms_tmdb](https://github.com/GateCross/ms_tmdb)

**自建方式：**
1. 准备 PostgreSQL 数据库，获取 `ms_tmdb` 项目 `docker` 目录下的 `docker-compose.yml` 和 `tmdb.yaml`。
2. 修改 `tmdb.yaml` 中的 `Postgres.*` 数据库连接信息和 `Tmdb.ApiKey`，如需代理访问官方 TMDB，可继续配置 `Tmdb.ProxyURL`。
3. 在配置文件所在目录执行 `docker compose up -d` 启动服务，Docker 部署默认访问地址为 `http://服务器IP:8080`。
4. 本项填写 `http://服务器IP:8080/api/v3`；如仅启动后端服务，则填写 `http://服务器IP:8888/api/v3`。

`docker-compose.yml` 示例：

```yaml
version: "3.8"

services:
  app:
    image: sereindusk/ms_tmdb:latest
    container_name: ms_tmdb_app
    environment:
      TMDB_CONFIG_FILE: /app/etc/tmdb.yaml
    ports:
      - "8080:80"
    volumes:
      - ./tmdb.yaml:/app/etc/tmdb.yaml
      # 需要上传封面时可打开下面一行
      # - ./uploads:/app/uploads:rw
    restart: unless-stopped
```

`tmdb.yaml` 示例：

```yaml
Name: ms-tmdb-api
Host: 0.0.0.0
Port: 8888
# 请求处理超时时间（毫秒），默认 30 秒
Timeout: 30000

# PostgreSQL 配置，请改成自己的数据库地址
Postgres:
  Host: "host.docker.internal"
  Port: 5432
  User: "postgres"
  Password: "postgres"
  DBName: "ms_tmdb"
  SSLMode: "disable"

# TMDB 配置，请替换为自己的密钥
Tmdb:
  ApiKey: ""
  BaseURL: "https://api.tmdb.org/3"
  DefaultLanguage: "zh-CN"
  RateLimit: 40
  # 需要代理访问官方 TMDB 时填写，例如 http://127.0.0.1:7890
  ProxyURL: ""
  LocalWriteEnabled: true
  AutoSync:
    Enabled: true
    CronExpr: "*/30 * * * *"
    Mode: "update_unmodified"
    BatchSize: 50
    StartDelaySecond: 15
```

**操作建议：** 官方无法访问时可填写代理地址。

## 🔍 订阅搜索

### 媒体搜索结果包含成人内容条目
**说明：** 开启该选项后将会在刮削或者检索时包含TMDB数据库的成人内容请谨慎开启！服务来自TMDB，本程序并没有成人资源，仅做API参数开关。请勿用于非法用途，责任自负！需要先去TMDB个人设置中将【搜索结果中包含成人内容条目】选项开启，开启该选项后将会在刮削或者检索时包含成人内容

**默认值/示例：** 关闭

**操作建议：** 请谨慎开启，仅在合法使用场景下启用。

### 媒体库缺失
**说明：** 订阅时只订阅媒体库缺失的电影剧集，多个媒体服务时记得打开默认

**默认值/示例：** 开启

**操作建议：** 开启后可避免重复订阅已入库内容。

### 新增订阅默认进入自定义模式
**说明：** 开启后，新增订阅时所有可跟随字段初始即为自定义状态，并预填当前默认值作为起点，三个设置分区默认展开；关闭时新增订阅维持全跟随默认。已有订阅与编辑行为不受影响。适合每个订阅都要单独调整配置的用户；配合订阅表单「包含/排除」的历史值选择（可输可选）使用效率更高

**默认值/示例：** 关闭

**操作建议：** 绝大多数用户保持关闭（新增订阅零配置、改默认设置即时生效）；仅当你每个订阅都要逐项修改时才开启。注意：开启后新建的订阅不再跟随默认设置实时联动。

### RSS 周期
**说明：** RSS 订阅刷新的时间间隔，需要在订阅管理中设置RSS 站点。为了减小站点压力，该功能最小周期建议大于 10 分钟。低于 10 分钟的频率会使用缓存数据。支持 Cron 表达式。

**默认值/示例：** 空（支持 Cron 表达式，如 `0 */30 * * * ?` 表示每 30 分钟执行一次）

**操作建议：** 建议设置合理的刷新周期，避免对站点造成过大压力。

**默认值/示例：** 空（支持 Cron 表达式，如 `0 0 0 * * ?` 表示每天午夜执行一次）

**操作建议：** 建议设置合理的搜索周期，避免对站点造成过大压力。

## 🤖 智能体配置

智能体配置使用同一套 AI 服务连接，同时为常规任务和灵犀伴影选择模型。页面支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages 三种接口格式；如果暂时不使用 AI 功能，可以保持为空。

### 接口格式
**说明：** 选择与你的 AI 服务商兼容的接口格式。不同格式的服务地址和可用模型可能不同。

**默认值/示例：** OpenAI Chat Completions
- `OpenAI Chat Completions`：适用于兼容 OpenAI Chat Completions 的服务。
- `OpenAI Responses`：适用于原生支持 OpenAI Responses 的服务。
- `Anthropic Messages`：适用于兼容 Anthropic Messages 的服务。

**操作建议：** 先按服务商说明选择格式；切换格式后，系统会清空两个模型字段，请重新选择或填写匹配的模型。

### AI 服务地址
**说明：** AI 服务的访问地址。

**默认值/示例：** 空
- OpenAI Chat Completions / OpenAI Responses：通常填写到 `https://api.openai.com/v1`。
- Anthropic Messages：填写服务根地址，例如 `https://api.anthropic.com`。

**操作建议：** 使用第三方服务时请填写服务商提供的地址。Responses 格式需要服务商原生支持；切换格式或地址后，建议重新获取模型列表并测试模型。

### AI API Key
**说明：** AI 服务的访问密钥，用于常规 AI 功能和灵犀伴影。

**默认值/示例：** 空
- `sk-xxxxxxx`

**操作建议：** 请妥善保管密钥。填写服务地址和密钥后，可以在模型字段旁使用“获取模型”或“测试模型”验证当前连接，测试不会保存尚未提交的配置。

### 常规任务模型
**说明：** 用于 AI 签到、媒体识别、识别词和日志诊断等常规 AI 任务。

**默认值/示例：** 空
- `gpt-3.5-turbo`

**操作建议：** 可手动填写模型名称，也可点击字段旁的“获取模型”从当前连接中搜索并选择。填写后点击“测试模型”，可查看连接是否正常、首字延迟、总延迟和服务商提供的生成速度。

### 灵犀伴影专用模型
**说明：** 位于“灵犀伴影”卡片，专门用于灵犀伴影的模型，可与常规任务模型分开选择。

**默认值/示例：** 留空

**操作建议：** 留空时灵犀伴影会自动使用“常规任务模型”；需要更强的对话、工具调用或推理能力时，再单独配置。测试时若此项为空，系统会按当前常规任务模型进行测试。

### 每周自动生成建议

## 🔌 服务配置

服务配置以卡片形式展示，2K/4K 屏幕下会自动扩展为多列卡片布局；手机端会改为单列，测试按钮和授权按钮会自动撑满可点区域。

### ffprobe 探测组件
**说明：** 系统级媒体探测组件，用于探测媒体文件的规格（分辨率）、编码、音轨字幕语言等信息，云端资源上报的媒体信息采集、strm 媒体信息探测等功能都依赖它。本卡片是全系统 **唯一** 的 ffprobe 安装 / 更新入口。

**卡片内容与操作：**

- **安装状态**：一行显示未安装 / 已安装（版本、来源）；鼠标悬停可查看安装路径与体积，下载失败时可见最近错误
- **一键安装**：后台下载安装包并解包校验安装，完成后通过消息中心通知
- **手动安装**：弹窗内两步完成——①复制下载地址到浏览器下载安装包（zip / tar.xz / tar.gz / 静态二进制），②选择安装包上传，校验通过即安装成功；本地已有缓存包时会提示「重装时无需联网」
- **更新检测 / 一键更新**：对比最新版本，一键更新采用原子替换，校验失败自动保留旧版本继续可用
- **本地缓存包**：安装包自动持久缓存于配置数据目录（随 config 卷持久化），重建容器或离线环境可直接重装，无需重复下载
- **重新检测**：刷新安装状态

**默认值/示例：** 全新环境默认未安装

**操作建议：** 使用云端资源上报媒体信息采集或 strm 媒体信息探测前，可先在此确认已安装；不装也没关系，相关功能首次触发时会自动尝试安装，失败时再到本卡片处理。[系统体检](/usage/system_settings/system_health.html) 中也会对本组件进行检查，异常时提供「去安装」跳转。

### Pansou 网盘搜索
**说明：** Pansou 服务地址，例如：`http://192.168.1.1:8017`，系统对外搜索网盘资源时会使用该地址。

**默认值/示例：** 空
- `http://192.168.1.1:8017`

**操作建议：** 需要搜索网盘资源时配置。填写后可点击“测试服务”验证是否可用，测试前请先保存当前配置。

### Google CSE 搜索
**说明：** 豆列豆单搜索使用，需要同时配置 Google 搜索 API 密钥和搜索引擎 ID。

**默认值/示例：** 空
- API 密钥获取地址：[Google Custom Search JSON API](https://developers.google.com/custom-search/v1/introduction?hl=zh-cn)
- 搜索引擎 ID 创建地址：[Google 可编程搜索引擎](https://programmablesearchengine.google.com/controlpanel/create)

**操作建议：** 先创建 Google 可编程搜索引擎，再把 API 密钥和搜索引擎 ID 填到对应输入框。

### 豆瓣 Cookie
**说明：** 用于需要登录态的豆瓣相关能力。只在功能明确需要 Cookie 时填写，平时可以保持空置。

**默认值/示例：** 空

**操作建议：** 可手动粘贴，也可以点击“获取 Cookie”通过浏览器扩展获取。获取前请确认扩展已安装并已登录豆瓣。

### OCR 服务地址
**说明：** OCR 服务地址，用于网站登录更新 Cookie 以及特殊站点签到等识别验证码场景。配置完成后可点击“测试服务”验证。

**默认值/示例：** 空

**操作建议：** 请参考 [OCR 服务配置指南](/usage/peripheral_services/ocr_service.html)。填写后建议先保存，再测试服务连通性。

### 过盾增强服务
**说明：** 用于站点访问遇到 Cloudflare 防护时自动尝试处理。开启后，还需要在对应站点的站点维护中开启“过盾增强”，系统才会在命中防护页时调用服务并自动重试一次。

**默认值/示例：** 关闭
- 服务类型：`FlareSolverr`
- 可选服务：`FlareSolverr`、`CloudflareBypassForScraping`
- 服务地址：填写所选服务的根地址，例如 `http://127.0.0.1:8191`
- 过盾超时秒数：`45`
- 凭证缓存分钟数：`30`

**操作建议：** 仅对确实经常触发 Cloudflare 防护的站点开启。FlareSolverr 适合已有 `/v1` 服务的部署；CloudflareBypassForScraping 适合提供 `/cookies` 接口的部署。过盾服务的代理出口请在服务自身配置，系统不会把站点代理转交给过盾服务。自动处理失败时，可在浏览器手动通过验证后同步 Cookie，并更新站点 Cookie。配置完成后可在 [系统体检](/usage/system_settings/system_health.html) 中检查所选服务是否可用。

## ❓ 常见问题

**Q: 如何重置某个配置为默认值？**
A: 参考本文的“默认值/示例”手动填入默认值或清空字段，然后点击悬浮保存条保存。

**Q: 修改数量为什么会减少或归零？**
A: 修改数量按“当前值和已保存值是否不同”计算。如果把字段改回原值，该字段会自动从待保存数量中移除。

**Q: 修改配置后何时生效？**
A: 大多数配置保存后生效，涉及系统级别的配置（如 RSS 订阅任务并发数）需要重启应用。

**Q: 某个配置项找不到了？**  
A: 使用页面顶部的快速导航表格或按 `Ctrl+F` 搜索关键词，所有字段都在本文档中。
