# 📋 安全审计

安全审计（页内标题「**登录审计**」）按时间倒序记录所有登录与安全事件，是回答「谁在什么时候试图进入系统」的第一入口。

## 🏷️ 事件类型

| 事件 | 含义 |
| --- | --- |
| 登录成功 | 任何方式的登录成功（记录会标注密码 / OIDC / 扫码） |
| 登录失败 | 密码错误、账号不存在等失败尝试 |
| 自动封禁 | 失败次数达到阈值，系统自动封禁，见[防护策略](./protection.md) |
| 手动封禁 | 管理员手动封禁了 IP 或网段 |
| 解封 | 封禁到期自动解封，或管理员手动解封 |
| 配置变更 | 安全等级、阈值、白名单等防护策略被修改 |
| 凭据处置 | 管理员禁用 / 删除了他人的 API Key |
| 越权访问 | 携带无效或过期凭据访问受限接口 |

## 🔍 筛选

支持按 **事件类型 / 来源 IP / 用户名 / 时间范围** 组合筛选，点「重置」清空全部条件。

## 🃏 事件卡片

每张事件卡片呈现：

- **来源**：IP 加内网 / 公网标识，公网 IP 可一键复制
- **用户名**：部分脱敏展示
- **客户端**：设备名，登录成功的记录标注登录方式（密码 / OIDC / 扫码）
- **聚合**：同一来源的重复事件会采样聚合，标注「实际发生 N 次」——反映真实规模，而不是被刷屏的条数

## 🎯 快捷处置

- **该 IP 事件**：立即按此 IP 筛选，看它还干过什么
- **封禁此 IP**：把这个 IP 加入拦截名单（两步确认，见[拦截名单](./blocks.md)）

::: tip 事件保留多久
事件记录默认保留 30 天，可在[防护策略 → 数据留存](./protection.md)调整；生效中的封禁记录不会被清理。
:::

::: note 空态是好事
没有事件时页面显示「防护运行正常」——说明一切安好，不是功能坏了。
:::
