# 🔑 凭据治理

凭据治理是**全体用户 API Key 的集中治理视图**：谁创建了 Key、还在不在用、闲置了多久，一目了然。

用户自己创建和管理 Key 在[我的信息 → 安全配置](/usage/main_page/my_info.md)；Key 的用途与调用方式见[API 接口鉴权](/usage/other/api_auth.md)。

## 🔍 筛选

- **启用状态**：全部 / 启用 / 禁用
- **闲置状态**：全部 / 长期闲置 / 从未使用
- **所属用户 ID**：定位某个用户的 Key

## 🃏 Key 卡片

每张卡片显示所属用户、Key 标题、启用状态、创建时间、最近使用时间与闲置天数。

::: note 只能看到掩码
列表中的 Key 是服务端掩码后的形态（如 `ms_ab12****wxyz`），任何人都看不到完整 Key；完整 Key 只在用户本人创建时展示一次。
:::

## 🛠️ 处置

- **禁用 / 启用**：暂停或恢复一个 Key 的使用，不删除记录，可随时恢复
- **删除**：彻底删除，被删的 Key 立即失效
- 两种操作都支持**批量**：勾选多张卡片后用顶部批量栏执行

::: tip 闲置只提醒不处置
超过[防护策略](./protection.md)中「API Key 闲置阈值（天）」（默认 90 天）的 Key 会被标记为「长期闲置」，**系统不会自动禁用或删除**——是否处置由管理员根据实际情况决定。
:::

::: info 处置会通知本人
管理员禁用或删除**他人**的 Key 时，Key 所属用户会收到「凭据处置」通知；通知开关在[防护策略 → 安全通知](./protection.md)。
:::
