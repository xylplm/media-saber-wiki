# 🛡️ 安全中心

安全中心是系统的安全指挥台：登录防护、访问审计、凭据治理都在这里完成。**仅管理员可见**，普通用户无需关注。

**入口**：设置 → 安全中心

::: tip 开箱即防护
安全中心默认按「标准」等级自动防护：公网来源登录失败达到阈值会自动封禁。不做任何配置也能工作，想调整细节再往下看。
:::

## 📊 总体态势

进入安全中心，顶部常驻**总体态势**卡：

- **安全评分**：0-100 分环形评分，直观反映当前安全状态
- **统计周期**：右上角切换近 24 小时 / 7 天 / 30 天
- **四项指标**：登录成功、登录失败、生效封禁、独立 IP 数，点击任一指标直达对应分区
- **当前来源**：显示你当前的访问 IP 与内网 / 公网标识

两种需要留意的提示：

| 提示 | 含义 |
| --- | --- |
| 降级运行 | 安全缓存暂不可用，系统已放行请求保证可用性，部分防护能力可能暂时失效 |
| 疑似需配置可信代理 | 你可能在反向代理后访问，但转发头未被采信，来源 IP 可能不准确；点「去配置」完成设置 |
