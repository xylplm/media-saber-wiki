# 🚫 拦截名单

拦截名单（页内标题「**封禁管理**」）管理所有被封禁的对象：谁被拦、为什么被拦、还剩多久、要不要放出来。

## 📌 三种封禁对象

| 对象类型 | 例子 | 说明 |
| --- | --- | --- |
| 单 IP | `203.0.113.7` | 精确封禁一个地址 |
| 网段 | `203.0.113.0/24` | 按 CIDR 封禁一整段地址 |
| 用户名 + IP | `alice @ 203.0.113.7` | 只拦「这个 IP 上试这个账号」的组合 |

## 🔒 封禁从哪来

- **自动封禁**：公网来源登录失败在计数窗口内达到阈值即触发；同一对象反复触发会**指数退避**加长封禁时长——首犯封得短、再犯翻倍、到上限为止。阈值在[防护策略](./protection.md)调整。
- **手动封禁**：在[安全审计](./audit.md)的事件卡上点「封禁此 IP」，两步确认后生效。

## 🃏 封禁卡片

- **状态**：生效中 / 已解封（封禁到期自动变为已解封）
- **剩余**：生效中的封禁实时显示剩余时长，永久封禁显示「永久」
- **失败**：触发封禁时累计的失败次数
- **原因**：自动封禁记录触发原因，手动封禁记录管理员填写的原因

2K 及以上屏幕右侧有常驻详情侧栏，点击卡片可查看完整信息（升级次数、到期时间、操作者等）。

## 🔓 解封

- **单个解封**：卡片底部的「解封」按钮
- **批量解封**：勾选多条记录后点批量栏的「批量解封」
- **全部解封**：右上角「清空全部」，确认后立即恢复所有被封禁对象的访问

::: warning 谨慎封禁网段
手动封禁前系统会二次确认，并提示自我锁定、目标在白名单内、网段过大等风险。封到自己路由器的公网出口会导致所有人都进不来——建议先在[防护策略 → 白名单网段](./protection.md)把自家出口网段加入白名单兜底。
:::

::: tip 白名单不会被自动封
白名单网段以及所有内网私有网段、回环地址，都被自动封禁豁免，见[防护策略](./protection.md)。
:::
