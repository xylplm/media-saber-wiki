# 🏔️ 修为境界

**修为境界** 是 Media Saber 的用户成长体系：真实建设贡献为你积累 **修为**，修为决定境界高低，境界又反过来决定你使用云端资源的 **消费单价** 与 **每日 / 每周配额**。**仙石** 则是可以赚、可以花的货币——消费、转账、历练都不再影响你的境界。

::: tip 修为与仙石是什么关系
- **修为**：只来自真实贡献（云端贡献、云识别词维护、下载分成、举报奖励），只增不减，决定境界。
- **仙石**：通过贡献、活跃、玩法都能获得，用于消费与流转，**与境界彻底解耦**——花光仙石也不会掉境界。
:::

## 🚪 入口

- **工作台境界条**：Hash 贡献榜卡片底部，展示当前境界与修为，点击左侧打开「我的境界」
- **个人信息菜单**：右上角头像菜单中的境界徽章
- 点击后进入境界弹窗，四个页签各司其职：

| 页签 | 内容 |
|------|------|
| **我的境界** | 当前境界、修为、仙石余额、特权状态总览 |
| **仙石账本** | 各维度收入汇总 + 完整流水，鼠标悬停每个维度格有详细解释 |
| **修为境界** | 当前境界与修为进度、境界权益（配额/单价/收益规则）、进阶之路、**修为构成**（按维度的修为获取汇总）与**修为簿**（最近逐条修为变动记录） |
| **进阶之路** | 晋升门槛对比，点击任意档位查看「当前 → 该档」的差异 |

## 💰 仙石与修为怎么赚

| 来源 | 说明 | 默认规则 | 涨修为？ |
|------|------|----------|----------|
| **云端贡献** | 上报的资源被云端收录后按体积计分，体积越大得分越多，单条有封顶 | 按体积曲线计分 | ✅ |
| **云识别词维护** | 为云识别词提交新版本，每版本一笔 | +6 仙石/版本 | ✅ |
| **下载分成** | 其他道友取用你的资源时，你获得分成（自用不计） | +0.1 仙石/次 | ✅ |
| **举报奖励** | 举报的云端资源经管理员审核通过 | +5 仙石/条 | ✅ |
| **每日活跃** | 当天使用系统即可获得（网页操作或接口调用都算） | +1 仙石/天 | ❌ |
| **功德灌顶** | 站长手动发放（正数为修为灌顶、负数为惩罚扣减；灌顶是加冕通道，不受每日上限） | 不设上限 | 可选 |
| **贡献申报** | 维基文档维护、站点适配等人工贡献，主动提交申报由管理员审核 | 额度逐条裁定 | ✅ |

- 每种涨修为的贡献维度设有 **每日修为上限**（修为境界页展示当前生效值）；当日修为到顶后，**仙石照常按仙石侧规则继续入账**
- 修为终身不设独立上限，但每笔入账的修都不会超过对应的仙石入账，因此终身上限合计低于满级门槛——**满级「混元大罗金仙」需站长以修为嘉奖加冕**

::: warning 违禁资源会被扣分
上传的资源若被管理员按 **违禁** 拉黑（或违禁举报经审核通过），仙石按运维配置的倍数（默认 10 倍）扣除作为惩罚，**同时按原始贡献分 1 倍扣回修为**（可能使境界跌落），并推送站内信通知——请勿上传违规资源。死链下架不扣分；后续恢复资源会自动退还仙石与修为。详见 [云端资源](/usage/cloud_storage/resource.html)。
:::

::: important 数值以页面展示为准
上表是默认规则。站长可在「基础配置」中调整各项参数（含每日修为上限），**修为境界页展示的始终是当前生效值**。各维度设有终身上限，部分维度还有单日上限防止爆刷。
:::

::: tip 只有维护贡献才有奖励
订阅别人的云识别词 **不计分**——订阅是全量同步行为，人人可开。只有 **提交新版本** 这类维护贡献才会入账。
:::

## 📝 贡献申报

除了上面这些系统自动计价的贡献，**维基文档维护、站点适配** 等人工贡献可以走 **贡献申报**，由管理员审核后授予修为与仙石：

1. **入口**：「我的境界」页面的 **修为构成** 区与 **仙石账本** 汇总格中的 **贡献申报**（App 在账本页「锦囊互赠」旁或修炼页「修为构成」下方）
2. **提交**：选申报类型，按提示在文本域填写凭证——
   - **维基文档**：GitHub 用户名、相关 PR / 提交链接及改动概述
   - **站点适配**：站点名称、适配说明与验证结果
   - **其他贡献**：描述贡献内容，并附可验证的链接或证据
3. **审核**：管理员逐条审核，通过 = 授予修为与仙石（额度随贡献大小裁定），驳回 = 理由随通知告知

::: tip 申报须知
- 同一账号 **同时只能有一条待审申报**，审核结果出来后才能再次申报；被驳回可补充凭证后重报
- 审核结果通过 **通知中心** 告知，「我的申报」列表可随时查看进度、授予额与驳回理由
- 申报内容请务必真实可查，伪造凭证经核实会按违规处理
:::

## 🧪 仙石怎么花

- **使用云端资源**按当前境界的单价扣仙石，**境界越高单价越低**（从凡人到混元大罗金仙单价陡降）
- 转账赠予道友、万宝阁购置法宝、历练盘缠都消耗仙石——**任何消费都不影响修为与境界**
- 特权境界使用云端资源 **完全免费**

## 🪜 境界与升降

- 凡阶共八档，从最低的「凡人」到最高的「混元大罗金仙」，各档门槛（按修为）与权益在弹窗「进阶之路」页签可查
- 修为 **达到** 下一档门槛立即晋升；修为只增不减，**消费永远不会掉境界**
- 唯一的降档路径：资源因违禁被拉黑时按原始贡献分扣回修为，跌破当前档门槛则境界回落（同事务推送通知）
- 晋升 🎉 与跌落 ⚠️ 都会推送消息通知，文案直接显示境界名称

::: info 口径切换说明
2026-11 之前等级由「仙石余额」定档（消费会跌境）。切换为修为定档时全站按新口径重算过一次，部分道友的境界可能回落——这属于预期内的口径切换，非处罚。签到、被赠与等社交收益从此不再影响境界。
:::

## 👑 特权境界（敕封礼赞）

凡阶之外另有 **仙外特权八档**（天帝 → 鸿蒙至尊），由站长直接 **敕封**：

- 特权期间使用云端资源 **完全免费**，配额更高
- 可设有效期并续期，到期前界面会提示「敕封余 N 天 · 可续期」，到期自动按修为回落凡阶
- 特权用户的界面没有进度条、"还差多少"等升级概念——只有身份色的荣誉展示（敕封横幅、荣誉殿堂）

## 📖 仙石账本

「仙石账本」页签按维度汇总收入并保留完整流水：

- 每个维度格 **鼠标悬停** 即有解释：云端贡献、云识别词维护、下载分成、举报奖励、每日活跃、嘉奖、累计消费
- 流水按时间倒序，每笔标注来源与事由；同时涨修为的流水会带 **修为 +N** 标记
