# 🏔️ 修为境界

**修为境界** 是 Media Saber 的用户成长体系：使用与贡献换取 **仙石**，仙石积累决定境界高低，境界又反过来决定你使用云端资源的 **消费单价** 与 **每日 / 每周配额**——越活跃、贡献越多，用得越便宜、限额越宽。

## 🚪 入口

- **工作台境界条**：Hash 贡献榜卡片底部，展示当前境界与仙石余额，点击左侧打开「我的境界」
- **个人信息菜单**：右上角头像菜单中的境界徽章
- 点击后进入境界弹窗，四个页签各司其职：

| 页签 | 内容 |
|------|------|
| **我的境界** | 当前境界、仙石余额、特权状态总览 |
| **仙石账本** | 各维度收入汇总 + 完整流水，鼠标悬停每个维度格有详细解释 |
| **修为境界** | 各境界档位的消费单价与配额一览 |
| **进阶之路** | 晋升门槛对比，点击任意档位查看「当前 → 该档」的差异 |

## 💰 仙石怎么赚

| 来源 | 说明 | 默认规则 |
|------|------|----------|
| **每日活跃** | 当天使用系统即可获得（网页操作或接口调用都算） | +1 仙石/天 |
| **云端贡献** | 上报的资源被云端收录后按体积计分，体积越大得分越多，单条有封顶 | 按体积曲线计分 |
| **云识别词维护** | 为云识别词提交新版本，每版本一笔 | +6 仙石/版本 |
| **下载分成** | 其他道友取用你的资源时，你获得分成（自用不计） | +0.1 仙石/次 |
| **管理员嘉奖** | 站长手动发放 | 不设上限 |

::: important 数值以页面展示为准
上表是默认规则。站长可在「基础配置」中调整各项参数，**修为境界页展示的始终是当前生效值**。各维度设有终身上限，部分维度还有单日上限防止爆刷。
:::

::: tip 只有维护贡献才有奖励
订阅别人的云识别词 **不计分**——订阅是全量同步行为，人人可开。只有 **提交新版本** 这类维护贡献才会入账。
:::

## 🧪 仙石怎么花

- **使用云端资源**按当前境界的单价扣仙石，**境界越高单价越低**（从凡人到混元大罗金仙单价陡降）
- 境界同时决定 **每日 / 每周** 的使用与搜索配额，境界越高限额越宽
- 特权境界使用云端资源 **完全免费**

## 🪜 境界与升降

- 凡阶共八档，从最低的「凡人」到最高的「混元大罗金仙」，各档门槛与权益在弹窗「进阶之路」页签可查
- 仙石余额 **达到** 下一档门槛立即晋升；余额 **跌破** 当前档门槛则回落（设有缓冲带，不会因一次使用就跳档）
- 晋升 🎉 与跌落 ⚠️ 都会推送消息通知，文案直接显示境界名称

## 👑 特权境界（敕封礼赞）

凡阶之外另有 **仙外特权八档**（天帝 → 鸿蒙至尊），由站长直接 **敕封**：

- 特权期间使用云端资源 **完全免费**，配额更高
- 可设有效期并续期，到期前界面会提示「敕封余 N 天 · 可续期」，到期自动按仙石余额回落凡阶
- 特权用户的界面没有进度条、"还差多少"等升级概念——只有身份色的荣誉展示（敕封横幅、荣誉殿堂）

## 📖 仙石账本

「仙石账本」页签按维度汇总收入并保留完整流水：

- 每个维度格 **鼠标悬停** 即有解释：云端贡献、云识别词维护、下载分成、每日活跃、嘉奖、累计消费
- 流水按时间倒序，每笔标注来源与事由
