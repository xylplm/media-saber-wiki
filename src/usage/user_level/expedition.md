# 🗺️ 出发历练

**历练** 是修仙境界体系的冒险玩法：花费 **盘缠**（仙石）前往各处秘境，收获法宝、仙石际遇，也可能破财甚至遭遇劫匪——一切看机缘。

## 🚪 入口

「我的境界」弹窗 → **出发历练**。秘境卡展示能得到什么 / 损失什么（不含概率），境界达标即可出发，每日次数有限。

## 🎭 剧场演出

每次出发都有三幕全屏剧场：启程 → 途中叙事 → 揭晓。得法宝有金光爆闪、传说法宝更有专属演出；动画可点击提前收下。

## ⚔️ 劫匪模式（打劫玩法）

### 化身劫匪

- 生效境界达到打劫资格线（默认 **地仙**，站长可调）且未被封印使用的道友，可在历练弹窗开启 **劫匪模式**
- 开启后有概率在 **其他道友的历练中** 被抽中，被动参与对决——每场对决都从系统内置文案与通知知晓结果
- 每日参与上限默认 **3 次**（站长可调），被抽中即算一次
- **境界跌落出资格线会自动收回劫匪资格** 并推送通知，重回线上可再开

### 狭路相逢

秘境奖池中设有劫匪档位时，历练者有一定概率 **遇上劫匪**：

- 系统从当次合格的劫匪中随机抽出一人对决，**五五开、与境界无关**
- 历练者胜：**反劫** 劫匪，获得涉案金额的仙石
- 劫匪胜：历练者被劫走涉案金额的仙石
- 对决金额 **零和转移、不抽税**：劫匪赢多少，历练者就输多少

### 吓破胆

抽中劫匪档但 **没有可用劫匪**（没人开启、都无资格、都达当日上限或赔不起）时，触发 **吓破胆**：风声鹤唳连夜逃回起点——**盘缠分文未失，历练次数也不消耗**，纯属虚惊一场。

::: tip 劫匪的自觉
余额不足以赔付涉案金额的劫匪不会被抽中——赔不起就不敢出手。想多被抽中，记得保持钱包鼓鼓。
:::

## 📜 历练志与图鉴

- **历练志**：最近 50 条出发记录，含叙事与对决详情
- **历练图鉴**：结果徽章墙（得法宝 / 得仙石 / 空手而归 / 遭遇不测 / 狭路相逢 / 吓破胆）+ 法宝收集墙 + 生涯统计（含劫匪对决胜负）
