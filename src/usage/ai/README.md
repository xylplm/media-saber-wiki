# 🤖 智能体

Media Saber 的智能能力分为两条清晰的使用路径：应用内的 **灵犀伴影** 用于日常找片、找资源和发起操作；Skills 与 MCP 则用于把 Media Saber 接入你常用的外部 AI 客户端。两者可以同时使用，但操作入口和确认方式各自独立。

## ✨ 在应用内使用灵犀伴影

灵犀伴影位于应用的“智能体”页面。直接说出你的目的即可，例如“找一部适合周末看的科幻电影”“帮我找《沙丘》的高清资源”或“帮我看看云存储里有没有《流浪地球》”。

- 🎬 找影视、探索片单与获取观影推荐
- 🔍 搜索站点种子和已接入的云存储资源
- 🧭 规划续追、记住非敏感观影偏好
- 🔔 发起订阅、下载与云端资源保存，并在实际写入前由你确认
- 💬 在同一会话中查看处理进度、资源卡和执行结果

👉 [阅读灵犀伴影使用指南](./agent_workspace.md)

### 开始前准备

1. 前往 [基础设置](/usage/system_settings/basic_settings.html)，选择接口格式并填写 AI 服务地址、密钥和常规任务模型；需要时可在“灵犀伴影”卡片中另设专用模型。
2. 如需下载种子，先在 [下载管理](/usage/download_management/) 配置至少一个可用下载器。
3. 如需云下载或保存到网盘，先在 [云端存储](/usage/cloud_storage/) 启用并检查目标网盘。

::: tip
涉及订阅、下载和保存资源等会产生实际变更的操作，灵犀伴影会先展示确认界面；在你点击确认前不会提交。
:::

## 🔌 从外部 AI 客户端接入

如果你希望在 OpenClaw、Hermes 或其他支持的外部客户端中使用 Media Saber，可以按下列方式接入。此类能力不等同于应用内的灵犀伴影页面，请以对应客户端的操作与授权提示为准。

| 方式 | 适合场景 |
| --- | --- |
| [Skills 技能包](./skills.md) | 为支持技能包的外部 AI 客户端补充 Media Saber 专项能力。 |
| [MCP 服务](./mcp.md) | 让支持 MCP 的 AI 客户端连接 Media Saber 的工具服务。 |

## 📚 相关设置与帮助

- [基础设置](/usage/system_settings/basic_settings.html)：配置 AI 服务，并可设置每周自动生成欢迎页建议。
- [下载管理](/usage/download_management/)：配置下载器、下载参数和下载目录。
- [云端存储](/usage/cloud_storage/)：配置网盘、挂载路径及云端任务查看入口。
