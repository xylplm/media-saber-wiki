# ✨ 灵犀伴影使用指南

灵犀伴影是 Media Saber 内置的影视智能体。你不需要记住命令或操作路径：用自然语言描述目标，它会把搜索、筛选和后续操作组织在同一段对话中；需要改变订阅、下载或网盘内容时，则由你在清晰的确认界面中完成最后一步。

## 🚀 快速开始

打开应用中的“智能体”页面，直接输入想做的事。下面这些问法都可以作为起点：

```text
帮我找一部适合周末看的科幻电影
帮我找《沙丘》的高清资源
帮我找云存储中的《流浪地球》资源
记住我更喜欢原声、科幻和高评分电影
```

灵犀伴影会根据问题展示影视、种子或云存储资源卡；如果信息还不够，可以继续补充年份、季数、分辨率、时长或当前心情。

::: tip
开始前请在 [基础设置](/usage/system_settings/basic_settings.html) 配置可用的 AI 服务。下载和云端资源操作还分别依赖已配置的下载器与云存储。
:::

## 💬 欢迎页、帮助与会话

### 动态建议

首次进入时，欢迎页会展示约 10 条可直接点击的建议，覆盖找影视、找资源、云存储搜索、追剧计划和偏好记录等常见场景。

- 有近期互动或已保存偏好时，建议会尽量贴合你的观影方向；它们是发起对话的灵感，不代表已经执行任何操作。
- 点击建议即可把问题发送到新会话。
- 建议区右上角的刷新按钮可手动生成新一批建议；生成过程中按钮会显示进行状态，避免重复提交。
- 在“基础设置 → 智能体配置”中开启“每周自动生成建议”后，系统会为近期活跃用户预先整理新建议；关闭后仍可随时手动刷新。

### 会话与能力帮助

- 新会话会在首条有效消息后自动生成简短标题，便于在左侧会话列表中辨认。
- 会话中会保留回答、搜索结果卡、工具步骤和最终结果，方便继续追问或回看。
- 点击页面右上角的“能力帮助”，可以查看灵犀伴影擅长的场景和适合的提问方式。
- 在手机或紧凑布局下，会话列表和处理状态收进侧栏；打开侧栏即可继续切换会话或查看结果。

## 🔎 找影视、种子和云存储资源

### 找影视与片单

可以按片名、类型、年代、时长、评分或心情描述需求，例如“今晚只有两小时，推荐一部高分电影”。灵犀伴影会把候选内容和推荐理由展示在对话中，你可以继续说“更轻松一点”“换成电视剧”来缩小范围。

### 搜索种子资源

当搜索结果中出现可用种子时，资源卡会显示名称、站点、大小和可用操作。种子很多时，卡片会按页展示，避免一次渲染过多内容；展开资源详情也不会撑破会话区域。

想下载某一项时，直接点击卡片中的“下载”。

### 搜索云存储资源

输入“找云存储资源”或直接说明片名后，灵犀伴影会展示已接入来源中可用的云存储资源。可执行的卡片会按资源类型显示准确动作：

| 卡片动作 | 适用资源 | 会做什么 |
| --- | --- | --- |
| 云下载 | 115 离线资源 | 将离线链接提交到已配置的云下载目录。 |
| 保存到网盘 | 123 快链资源 | 将资源保存到已配置的网盘目录。 |

这两种操作不要混称为“转存”：卡片上显示的动作就是实际会执行的操作。

## 📥 从种子卡片发起下载

种子下载采用一次确认的方式，避免在对话里反复回答“是否确认”：

1. 在种子资源卡片中点击“下载”。
2. 在确认界面选择目标下载器；可按需要调整下载参数和下载目录。
3. 确认资源名称、站点、体积和目标配置后，点击“确认下载”。
4. 灵犀伴影会在当前会话中展示提交过程和结果卡。

下载器为必选项。若已配置默认下载器或默认下载参数，确认界面会优先带入；不单独选择下载目录时，系统会按现有下载设置处理。

::: warning
确认提交会占用下载器带宽和存储空间。若没有可用下载器、下载参数或目录，结果卡会说明具体原因；完成配置后重新发起即可。
:::

## ☁️ 从云资源卡片发起操作

云资源操作同样在点击卡片后一次确认，而不是让 AI 再发一条纯文本的“是否确认”问题：

1. 在云资源卡片中点击“云下载”或“保存到网盘”。
2. 在确认界面查看文件名称、品质、大小和动作类型。
3. 选择目标网盘目录；不填写时使用系统的对应默认目录。
4. 点击确认，处理结果会回到当前会话中展示。

提交成功表示系统已经接受该操作。云下载或保存的后续进度可在 [云端存储](/usage/cloud_storage/) 的任务页面查看。

## 🧭 查看处理状态与结果

在一次对话中，灵犀伴影会依次呈现正在处理的状态、搜索结果、需要你确认的操作，以及最终成功或失败结果。

- 搜索完成后，可直接在结果卡中继续查看详情或发起可用操作。
- 操作成功后，结果卡会给出下一步入口，例如查看云端资源或下载任务。
- 操作失败时，结果卡会说明可恢复的原因。优先按提示检查配置或重新选择资源，无需从头重建整段对话。

## ⏳ 资源卡的有效期

资源卡中的下载、云下载和保存到网盘入口仅面向当前实时搜索结果，且有短时有效期。历史会话中的旧卡片仍可用于查看，但当入口显示已失效或资源不可用时，请重新搜索同一资源后再操作。

确认前，系统会再次检查资源和当前配置，并避免重复提交相同目标；如果你改用不同下载器、下载参数、下载目录或网盘目录，会按新的目标处理。

## 🧩 常见问题

### 为什么看不到下载或云资源操作按钮？

只有当前结果支持执行、且资源仍有效时才会显示可用入口。请先确认资源搜索结果是否仍在当前会话中；如果是旧结果，重新搜索即可。

### 点击下载后无法确认或提示没有可用下载器

前往 [下载管理](/usage/download_management/) 添加并启用下载器。建议同时配置常用下载参数和下载目录，以便确认界面自动带入。

### 云下载或保存到网盘失败怎么办？

检查 [云端存储](/usage/cloud_storage/) 中的网盘是否已启用、连接正常，且所选目录仍可用。某些资源只支持特定操作方式；如果当前目标网盘不支持，选择其他目录或重新搜索资源。

### 为什么会话标题仍然显示默认名称？

标题会在首条有效消息后异步生成，处理完成前列表可能短暂显示默认名称。网络或模型暂时不可用时，系统会自动使用首条问题生成简短标题；如果刷新会话列表后仍未更新，请重新进入该会话或稍后再试。
