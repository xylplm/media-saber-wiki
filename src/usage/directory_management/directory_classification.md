# 📚 目录分类

## 📋 分类列表

目录分类页面展示了所有已添加的目录分类配置，以可折叠面板形式展示每个分类及其子分类的详细信息。

:::warning
- 分类匹配顺序是从上到下，请注意顺序！！！
- 自定义分类如动漫、纪录片之类的自定义分类，请放在电影和电视剧之前！！！
- 为了避免无法匹配的情况发生，建议每一种标签类型的分类最后加一个全部来兜底，避免无法区分的媒体
:::

### 🎯 功能操作

- 🔄 **刷新**：点击刷新按钮重新加载分类列表
- 🔄 **生成默认分类**：一键生成系统推荐的默认分类配置
- 🔼 **全部展开/全部折叠**：展开或折叠所有分类面板
- ➕ **新增分类**：添加新的主分类

### 📊 分类信息显示

每个主分类面板会显示以下信息：

- 📝 **分类名称**：自定义的分类名称
- 📊 **子分类数量**：该分类下包含的子分类数量
- 📚 **子分类列表**：该分类下所有子分类的简要信息

在展开的面板中，每个子分类会显示以下详细信息：

- 📝 **子分类名称**：自定义的子分类名称
- 🎬 **电影分类**：适用的电影分类类型
- 📺 **电视剧分类**：适用的电视剧分类类型
- 🌍 **语种**：适用的媒体语种
- 🌎 **地区**：适用的媒体地区
- 🎭 **电影分级**：适用的电影分级标准
- 📺 **电视剧分级**：适用的电视剧分级标准
- 🎯 **订阅过滤规则**：已绑定的规则组名称（未绑定不显示）

### 🎮 分类控制操作

#### 主分类操作

- ➕ **添加二级分类**：为该主分类添加新的子分类
- ✏️ **编辑分类**：修改主分类配置
- 🗑️ **删除分类**：移除主分类及其所有子分类
- 🎯 **拖拽排序**：通过拖拽调整主分类顺序
- 🔼 **展开/收缩面板**：展开或收缩分类详情面板

#### 子分类操作

- ✏️ **编辑**：修改子分类配置
- 🗑️ **删除**：移除子分类
- 🎯 **拖拽排序**：通过拖拽调整子分类顺序

---

## ➕ 新增/编辑主分类

添加或修改主分类需要配置以下字段：

### 📝 基本信息

- **名称**：自定义分类名称，便于识别和管理
- **启用**：控制分类是否启用，关闭后相关功能无法使用该分类

### 🎯 订阅过滤规则（可选）

- **作用**：为该分类下的所有内容绑定一套默认的订阅过滤规则
- **生效方式（从属回落）**：一级分类本身不参与匹配，只有当某个子分类的 TMDB 条件命中、但该子分类没有绑定规则时，才会回落使用所属主分类绑定的规则
- **典型用法**：粗配只在一级绑一套（如「动漫」一套规则同时管国漫和日番），需要更细的差异时再下沉到子分类单独绑定

---

## ➕ 新增/编辑子分类

添加或修改子分类需要配置以下字段：

### 📝 基本信息

- **名称**：自定义子分类名称，便于识别和管理

### 🎬 媒体分类配置

- **电影分类**：选择适用的电影分类类型，可多选
- **电视剧分类**：选择适用的电视剧分类类型，可多选

### 🌍 媒体属性配置

- **语种**：选择适用的媒体语种，可多选
- **地区**：选择适用的媒体地区，可多选
- **电影分级**：选择适用的电影分级标准，可多选
- **电视剧分级**：选择适用的电视剧分级标准，可多选

### 🎯 订阅过滤规则（可选）

- **作用**：为命中该子分类的订阅绑定一套过滤规则，替代每次新增订阅手动选择
- **判定方式**：订阅刷种时用订阅目标的 TMDB 信息（类型 / 语种 / 地区）与子分类条件比对，**取遍历顺序中首个命中的子分类**，一 / 二级分类的名称本身不参与匹配
- **留空**：不绑定，命中该子分类的订阅会沿所属主分类找绑定（见上），再没有才走订阅默认设置的兜底规则

---

## 🎯 订阅过滤规则的自动匹配

分类绑定规则后，订阅的规则选择按以下优先级自动完成（**仅订阅刷种链路生效**，手动搜索等非订阅场景不受影响）：

```
订阅手动指定 > 二级分类绑定 > 一级分类绑定 > 订阅默认设置兜底 > 全部通过
```

也就是说：**新增订阅时不选过滤规则，系统会根据该剧 / 电影的 TMDB 信息自动识别所属子分类并套用对应规则**。同时追日番、国漫、国产剧、欧美剧的用户，只需给每个分类绑好各自的规则组，之后新增订阅全部免选。

::: tip 在哪里看生效结果
- 子分类卡片会以「规则」标签展示已绑定的规则名，主分类面板头部也会汇总显示；一眼可见每个分类用哪套规则
- 绑定的规则组被删除后视为未绑定，自动沿链回落到下一级，不会中断订阅
- 批量编辑订阅时清空过滤规则 = 恢复按分类自动匹配
:::

::: warning 两个注意点
- **条件全空的子分类会匹配所有内容**：未配置任何 TMDB 条件的子分类会命中所有订阅、优先截走规则选择，建议给它配好条件或规则
- 分类判定只看类型 / 语种 / 地区，**不看分级条件**；如果你靠分级（如儿童内容）区分类目，这套自动匹配不适用于该分类
:::

## 🔄 默认分类

系统提供一键生成默认分类功能：

- 点击"生成默认分类"按钮
- 系统会自动创建推荐的分类配置
- 包括电影、电视剧、动画等常用分类
- 电影/电视剧/动画三个分类可以不用添加子分类

---

## ⚠️ 注意事项

- 电影/电视剧/动画三个主分类可以不用添加子分类
- 子分类用于更精细的媒体分类管理
- 分类配置会影响媒体的自动识别和整理
- 可通过拖拽调整分类优先级
- 分类和子分类的组合用于目录匹配和下载任务分类
