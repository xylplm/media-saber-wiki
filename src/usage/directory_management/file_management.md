# 📂 文件管理

入口：**目录管理 → 文件管理**。

用于浏览本地 / 可访问路径上的文件与目录，并手动做转移、识别、刮削、重命名、刷新媒体库、硬链接查询，以及字幕检查 / 目录字幕巡检。

## 🧭 操作布局

页面把高频操作放在主按钮，低频操作收进「更多」，避免按钮堆满：

| 位置 | 主操作 | 更多菜单 |
| --- | --- | --- |
| **顶栏**（当前目录） | 转移 | 刮削当前目录、刷新媒体库、搜索硬链接 |
| **目录行** | 更多 | 字幕巡检、重命名、刷新媒体库 |
| **媒体文件行** | 转移 + 更多 | 识别、字幕、刮削、搜索硬链接、重命名、刷新媒体库 |
| **字幕等非媒体文件行** | 更多 | 识别、转移、刮削、搜索硬链接、重命名、刷新媒体库（按文件类型显示可用项） |

> 💡 「转移」是按整理规则识别并归位到目标目录；「刷新媒体库」只是通知媒体服务器扫描路径，两者不是一回事。

## 📋 文件列表

### 🎯 常用操作

#### 📤 转移

- **单文件转移**：媒体文件行上的「转移」；字幕等文件在「更多」里
- **目录批量转移**：右上角「转移」会处理当前目录下的媒体

转移会按系统整理规则识别、重命名并写入目标目录。

#### ✏️ 重命名

- **文件 / 文件夹**均可在对应行的「更多 → 重命名」中修改名称
- 只改当前层级的名称，不能写成带路径分隔符的完整路径
- 不能改成与同级已有项同名；仅大小写变化也支持
- 成功后列表会刷新为新名称

#### 🔄 刷新媒体库

在顶栏「更多」、目录行「更多」或文件行「更多」中点 **刷新媒体库**：

1. 系统按当前路径提交异步刷库任务
2. 立即提示「已提交刷新媒体库」，不阻塞继续浏览
3. 实际扫描由媒体服务器后台完成，耗时取决于库规模与路径范围

适合改名、移动整理后，希望 Emby / Jellyfin / Plex 等尽快看到最新文件时使用。

#### 🎞️ 刮削

- **单文件刮削**：文件行「更多 → 刮削」
- **目录批量刮削**：右上角「更多 → 刮削当前目录」

> ⚠️ 刮削会覆盖已有 nfo / 图片等元数据，操作前请确认。

#### 🔗 搜索硬链接

- **单文件**：文件行「更多 → 搜索硬链接」
- **当前目录**：右上角「更多 → 搜索硬链接」

查询前需指定查询目录范围；范围越大越慢。结果页可对查到的硬链接做删除等处理。

#### 🎬 字幕

文件管理已与 [字幕中心](/usage/media_services/subtitle_center.html) 打通：

| 入口 | 适用对象 | 位置 | 做什么 |
| --- | --- | --- | --- |
| **字幕** | 单个媒体文件 | 文件行「更多」 | 检查同目录侧车字幕，必要时发起搜索任务 |
| **字幕巡检** | 目录 | 目录行「更多」 | 复用字幕中心巡检批次，扫描目录内媒体并生成缺字幕清单 / 自动补齐 |

##### 单文件「字幕检查」

1. 点文件行「更多 → 字幕」
2. 系统只扫描媒体旁侧车，**不会**读取 STRM 正文或访问网盘
3. 结果会展示：
   - 是否已有可用外挂 / 内封字幕
   - 当前路径能否写入侧车
   - 是否已有进行中的字幕任务
4. 需要补齐时点 **搜索字幕**，会创建字幕中心任务
5. 若尚未配置字幕来源，会提示先去字幕中心配置

##### 目录「字幕巡检」

1. 点目录行「更多 → 字幕巡检」
2. 先估算媒体数量与队列压力（不会写字幕）
3. 选择模式：
   - **仅生成清单**：先看缺哪些，再决定补齐
   - **自动补齐**：高置信候选可安全写入
4. 确认后在后台运行，不阻塞继续浏览文件
5. 完成后可选择：
   - **留在文件管理**
   - 或 **前往字幕中心** 查看巡检进度

目录巡检使用默认字幕策略兜底；更细的来源、语言偏好、繁体转简体等仍在字幕中心配置。

## 📁 目录浏览

- 支持多级目录浏览
- 显示文件 / 目录基本信息
- 可筛选、排序
- 支持点选后批量操作（视页面能力而定）

---

## ⚠️ 注意事项

- 转移会走系统整理规则，批量操作前先确认当前目录
- 重命名只改 basename，不会移动到其他目录
- 刷新媒体库是异步任务，提交成功不等于媒体服已扫完
- 硬链接查询大范围时可能较慢
- 刮削会覆盖现有元数据，重要数据请先备份
- 字幕检查 / 巡检不会读取 STRM 正文；远程无本地目录时可能只能搜不能写
- 删除类操作不可恢复，请谨慎
