:::warning ⚠️ 前置条件
Media Saber 未内置任何站点支持！**在添加站点前必须先配置站点配置文件**，否则即使添加了站点，系统也无法正常搜索和订阅。

👉 **前往配置站点文件**：[站点管理配置指南](/guide/init/sites)

**两种配置方式选其一：**
1. 🌐 **站点配置订阅**（推荐）- 定期自动更新社区站点配置
2. 🔧 **手动添加** - 手工维护私有站点配置
:::

## 📋 站点列表

站点列表页面采用卡片式展示方式，展示了所有已添加的站点，提供站点管理的各种功能。

### 🔧 站点操作

快速操作按钮：

- 🔄 **刷新**：重新加载站点列表数据
- 🌐 **连通性测试**：测试站点是否可以正常连接（[遇到问题？](/guide/problem.html#站点无法连通)）
- 📡 **RSS 测试**：测试站点 RSS 功能是否正常工作

**更多操作菜单：**

- 🔄 **站点配置订阅**：管理站点配置的自动更新（URL 和定时任务）
-  **备份站点**：导出当前所有站点配置
- ♻️ **恢复站点**：从备份文件恢复站点配置
- ➕ **添加站点**：添加新的站点

### 🎚️ 站点状态控制

每个站点卡片展开后可控制以下 9 个功能开关：

| 开关 | 说明 |
|------|------|
| ✅ 启用 | 禁用后所有服务无法使用该站点 |
| 🔍 搜索 | 搜索或订阅时使用该站点 |
| 📡 RSS | 监听该站点的 RSS 内容进行订阅 |
| 📊 统计 | 包含该站点的数据统计 |
| 📝 签到 | 定时对该站点进行签到 |
| 📣 公告 | 获取并显示该站点的公告 |
| 💌 消息 | 获取并显示该站点的私信消息 |
| 🛡️ 代理 | 使用代理服务器访问该站点 |
| 🧩 过盾增强 | 允许该站点在触发 Cloudflare 防护时使用过盾增强服务自动处理 |

**站点卡片标题区域标签：**

- 站点名称（灰显表示已禁用）
- 🔒 **VPN 标签**：启用代理时显示
- 🔐 **2FA 标签**：配置两步验证时显示，点击可查看当前验证码

### 📋 批量操作

展开批量操作面板可同时对所有站点设置上述 8 个功能开关。点击**展开/收起所有**按钮快速展开或收起所有站点卡片。

### 📈 站点优先级排序

拖拽站点卡片调整优先级顺序，影响搜索和订阅时的站点选择。条件：需要至少 2 个站点才能拖拽排序。

## ➕ 新增站点

添加并维护站点是使用订阅、搜索下载等功能的前提条件。

### 基本信息

| 字段 | 说明 |
|------|------|
| 🌐 **选择站点** | 从下拉列表中选择要添加的站点，已添加会显示"已添加"标记 |
| 📝 **名称** | 自定义站点名称（不影响功能，便于识别） |
| ⭐ **优先级** | 数字越小优先级越高，多个站点同时命中时使用高优先级的站点 |
| 🆔 **用户 ID** | 仅部分站点需要，如某些站点获取 HR 列表时需要配置 |

### 域名配置

| 字段 | 说明 |
|------|------|
| 🏠 **域名** | 站点域名，通常无需填写，仅在站点域名变动或网络问题时手动修改 |
| 📡 **API 域名** | 站点 API 域名，通常无需填写，默认使用站点适配文件内置的配置 |

### 认证信息

| 字段 | 说明 |
|------|------|
| 🍪 **Cookie** | 在浏览器 F12 → 网络选项卡获取，或使用 [Cookie 插件](/client/brower_tool/) 快速获取。猪猪、好大等已改为 API 请求方式的站点无需 Cookie，仅需按下方示例配置请求头 |
| 📥 **自定义请求头** | 格式：`key:value`，多个换行分隔。部分站点（馒头、猪猪、好大、飞天拉面等）需要配置才能使用 |
| 🌐 **User-Agent** | 站点签到/搜索/数据获取时的标识信息，为空则使用系统默认设置 |
| 🔐 **两步验证 Key** | 部分站点需要配置 2FA 认证，可通过二维码扫描或选择获取 |

### RSS 配置

| 字段 | 说明 |
|------|------|
| 📡 **RSS 订阅地址** | 用于电影、电视剧订阅和刷流任务，点击站点 RSS 图标获取 |
| 🔍 **解析种子详情** | 是否获取种子的 FREE 和 HR 信息：<br>✅ 开启 - 可实现 FREE 优先规则，但会增加站点访问压力<br>❌ 关闭 - 无法判断 FREE 种 |

### 功能配置

| 字段 | 说明 |
|------|------|
| 🛡️ **使用代理** | 该站点的访问将使用 [代理服务器](/usage/system_settings/basic_settings.html#代理服务器) 配置 |
| 📄 **下载字幕** | 自动查询种子详情页并下载字幕到下载保存目录 |
| 🧩 **过盾增强** | 当该站点触发 Cloudflare 防护时，允许系统使用 [过盾增强服务](/usage/system_settings/basic_settings.html#过盾增强服务) 自动处理 |
| ⏰ **活跃提醒** | 当站点无活跃天数超过设定值时推送消息提醒（依赖数据统计功能） |
| 🚫 **过滤规则** | 该站点仅下载符合指定规则组的种子（仅对 RSS 和内建索引生效） |
| ⬇️ **下载参数** | 订阅搜索下载时的默认参数 |

::: tip 💡 过盾增强使用提示
过盾增强需要同时满足两处配置：先在 **系统设置 → 基础设置 → 服务配置** 中启用、选择 FlareSolverr 或 CloudflareBypassForScraping 并填写服务地址，再在当前站点开启"过盾增强"。系统只会在识别到 Cloudflare 防护页时介入，正常站点访问不会主动调用过盾服务。
:::

### 流控规则

用于控制站点访问频率，防止被站点限流或封禁：

| 字段 | 说明 |
|------|------|
| **单位时间（分钟）** | 时间周期，如 10 表示 10 分钟 |
| **单位时间内访问次数** | 在指定时间内允许的最大访问次数 |
| **访问间隔（秒）** | 每次访问之间的最小间隔秒数 |

**示例**：设置为 `10分钟内最多10次访问，每次访问间隔6秒`

### 📋 自定义请求头示例

不同站点的请求头获取方法略有不同。以下是常见站点的配置方法：

#### 馒头

**步骤：**
1. 登录馒头站点
2. 进入「控制台」→ 「实验室」→ 「存取令牌」
3. 获取或生成 Token
4. 在站点维护中添加请求头：`x-api-key:YOUR_TOKEN`

#### 飞天拉面

**步骤：**
1. 访问飞天拉面站点首页
2. 滑到页面底部，点击「API」
3. 复制类似 `APITOKEN:XXX` 的内容
4. 在站点维护中添加请求头：`APITOKEN:XXX`

#### 朱雀

**步骤：**
1. 登录朱雀站点
2. 按 F12 打开开发者工具 → 「网络」选项卡
3. 点击任意数据请求（注意不是页面请求，数据请求一般在下面），展开「请求标头」
4. 查找 `x-csrf-token` 字段（一般在最下方）
5. 在站点维护中添加请求头：`x-csrf-token:YOUR_TOKEN`

#### 猪猪

猪猪已适配官方 API（api.piggo.me），**无需 Cookie**，通过存取令牌认证。

**步骤：**
1. 登录猪猪站点，进入「二师兄个人中心」→「安全」→ 输入密码 → 创建存取令牌
2. 在站点维护中添加请求头：`Authorization:Bearer YOUR_TOKEN`
3. Cookie 字段可留空，搜索、数据统计均走 API 接口

#### 好大

好大已适配站内 RESTful API，**无需 Cookie**，通过 API Key 认证，签到同样走 API 接口。

**步骤：**
1. 登录好大站点，在控制面板的 API 管理页面生成 API Key（入口以站点实际为准）
2. 在站点维护中添加请求头：`X-API-Key:YOUR_TOKEN`
3. Cookie 字段可留空，签到与数据统计均走 API 接口

#### 好学

好学已适配新版 API 接口，请求需要携带 CSRF Token（Cookie 仍需正常配置）。

**步骤：**
1. 登录好学站点
2. 按 F12 打开开发者工具 → 「网络」选项卡
3. 点击任意数据请求，展开「请求标头」
4. 查找 `X-CSRF-Token` 字段（一般在最下方）
5. 在站点维护中添加请求头：`X-CSRF-Token:YOUR_TOKEN`

#### Sunny

Sunny 已适配新版 API 架构：用户信息、做种统计、搜索、下载走**长效 API Key**，公告与站内消息走**短期访问令牌**，两个请求头都需要配置。

**步骤：**
1. 登录 Sunny 站点，进入控制面板的 API 设置页面（入口以站点实际为准），生成 API Key
2. 在站点维护中添加请求头：`X-API-Key:YOUR_API_KEY`（长效，用于用户信息/做种/搜索/下载）
3. 再抓取访问令牌：按 F12 打开开发者工具 → 「网络」选项卡 → 刷新页面，点击任意数据请求（不是页面请求），展开「请求标头」→ 查找 `Authorization` 字段（一般在最下方），完整复制其值（含 `Bearer ` 前缀）
4. 添加第二个请求头：`Authorization:（粘贴完整复制值）`（⚠️ 约 7 天过期）
5. 过期表现：公告/站内消息同步报 401「用户未登录」；重新登录 Sunny 站点后按第 3 步重新抓取，更新该请求头即可
6. Cookie 字段可留空

## ✏️ 编辑站点

点击站点列表中的编辑按钮修改站点配置。界面与新增站点相同，可修改除站点类型外的所有配置项。

## 🔄 站点配置订阅

**操作路径：** 站点列表 → 更多操作 → 站点配置订阅

用于设置站点配置的自动更新，与 [初始化配置](/guide/init/sites) 中的方式一相同。

### 配置说明

| 配置项 | 说明 |
|--------|------|
| **配置文件 URL** | 站点配置文件的来源地址，系统定期从此拉取最新配置 |
| **Cron 表达式** | 定义自动更新时间计划，使用标准 Cron 格式（如 `0 9 * * *` 表示每天上午 9 点） |

### 操作

- **拉取**：立即从配置 URL 拉取最新的站点配置
- **保存**：保存配置 URL 和定时更新设置

💡 **Cron 配置提示：**
- 点击输入框右侧的「快速生成」按钮可视化生成表达式
- 详细规则请参考 [Cron 规则文档](/usage/other/cron_rule)

## ❌ 删除站点

点击站点列表中的删除按钮删除站点。删除前会弹出确认对话框，删除后该站点无法使用任何服务。

## 🍪 更新站点 Cookie

### 方式一：手动更新

在站点列表中点击编辑按钮，直接修改 Cookie 字段并保存。

### 方式二：插件同步

使用浏览器同步插件自动获取和更新 Cookie。详见 [浏览器同步插件](/client/brower_tool/)。

## 🌐 站点连通性测试

**作用**：验证站点是否可以正常连接

**操作**：站点列表 → 点击「连通性测试」按钮

**遇到错误**：根据报错信息调整站点设置和网络环境，参考 [站点无法连通](/guide/problem.html#站点无法连通)

## 📡 站点 RSS 测试

**作用**：验证站点 RSS 功能是否正常工作

**操作**：站点列表 → 点击「RSS 测试」按钮

**检查内容**：
- RSS 地址配置是否正确
- 是否能正常获取 RSS 内容
- 种子信息解析是否正常

## 📥📤 站点导入/导出

### 📤 备份站点

**作用**：导出所有站点配置为备份文件

**操作**：站点列表 → 更多操作 → 备份站点

**用途**：
- 系统迁移时保留现有配置
- 备份重要站点信息
- 分享站点配置给其他用户

### ♻️ 恢复站点

**作用**：从备份文件恢复站点配置

**操作**：站点列表 → 更多操作 → 恢复站点

**说明**：如果站点已存在，不会被覆盖，需要先删除再恢复以完全替换
