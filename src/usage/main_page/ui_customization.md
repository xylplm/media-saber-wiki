# 🎨 界面自定义

界面自定义用于调整 MediaSaber 的外观：主题明暗、**界面风格（现代 / 玻璃）**、主题配色、侧栏默认状态、卡片边缘，以及**玻璃风格下的背景壁纸**。  
改动会**即时生效**，并自动保存到当前登录账号，换浏览器登录后也会同步。

## 🚪 功能入口

1. 点击顶部导航栏最右侧的**用户头像**
2. 在下拉菜单中选择 **界面自定义**
3. 右侧滑出设置面板

## 🖥️ 面板结构

- **标题栏**：界面自定义 + 关闭按钮
- **主题模式**：亮色 / 暗黑
- **界面风格**：现代 / 玻璃（与配色正交）
- **主题颜色**：多色方案（玻璃风格下同样可选）
- **背景壁纸**：仅选中「玻璃」风格时出现
- **遮罩浓度**：非默认渐变时可选（轻 / 标准 / 浓）
- **侧边栏默认状态**：展开 / 收缩
- **卡片边缘**：阴影 / 边框

## 📋 自定义选项

### 🌗 主题模式

| 模式 | 说明 |
| ---- | ---- |
| 亮色 | 浅色主调，适合明亮环境 |
| 暗黑 | 深色主调，夜间更护眼 |

点击即切换，无需额外保存。

### ✨ 界面风格

| 风格 | 说明 |
| ---- | ---- |
| **现代** | 实色卡片与侧栏，传统界面 |
| **玻璃** | 毛玻璃通透表面，可叠加任意主题配色，并支持背景壁纸 |

风格与配色互不占用：例如「玻璃 + 紫藤」「玻璃 + 海洋」。

### 🎨 主题颜色

系统提供多种主题色（圆点预览 + 中文名），例如：海洋、湖泊、紫藤、森林、天空、日出、玫瑰、采菊、少女、猛男、暮霭、秋叶、深渊、冰川等。

1. 在「主题颜色」区域点击目标方案  
2. 按钮、链接、高亮等会立刻换色  
3. 在「界面风格」中选择 **玻璃** 时，再叠加毛玻璃效果，并出现「背景壁纸」区域  

### 🪟 玻璃风格 · 背景壁纸

仅当界面风格为 **玻璃** 时显示。壁纸只影响背景装饰，不影响业务数据；可与当前配色同时生效。

| 来源 | 说明 | 适合场景 |
| ---- | ---- | -------- |
| **默认渐变** | 系统内置渐变，不拉外网图 | 最稳、零依赖 |
| **必应每日** | 服务端取必应图；**全站共用**，Redis **按天**缓存图片地址，一天只打一次 HPImageArchive | 每天换景、省心 |
| **网络图片** | 填写 https 图片直链，浏览器直接加载 | 指定外链美图 |
| **本地文件** | 读取数据目录中的壁纸文件，走静态资源长缓存 | 自备高清图、内网环境 |

#### 网络图片

1. 选择「网络图片」  
2. 填写以 `http://` 或 `https://` 开头的**公网图片直链**  
3. 点击 **应用**（或回车）  

说明：

- 填写公网可访问的图片直链  
- 浏览器直接加载该地址  
- 加载失败时自动回落默认渐变，并在面板提示状态  

#### 本地文件（自行放置，界面不提供上传）

1. 将壁纸文件放到服务器数据目录：

```text
config/data/static/wallpaper/
```

2. 推荐文件名：`default.webp`（也支持 `.jpg` / `.jpeg` / `.png` / `.gif`）  
3. 在面板选择「本地文件」，文件名默认 `default.webp`，可改成你放的文件名后点 **应用**  

说明：

- **界面没有上传按钮**，请用网盘挂载、SCP、文件管理等方式把文件放进上述目录  
- 仅允许纯文件名，不支持路径（如 `../`）  
- 本地壁纸走 `/static/wallpaper/...` 静态资源，缓存更久、切换更快  
- 文件不存在时回落默认渐变，并提示未找到文件  

#### 遮罩浓度

在非「默认渐变」时可选 **轻 / 标准 / 浓**，用于调节壁纸上的通透遮罩，保证毛玻璃区域文字可读。

#### 加载状态

面板底部会显示：

- 正在加载壁纸…  
- 壁纸已应用  
- 失败原因 + 已回落默认渐变  

### 📐 侧边栏默认状态

| 状态 | 说明 |
| ---- | ---- |
| 展开 | 显示完整菜单文字，适合大屏 |
| 收缩 | 仅图标，节省空间 |

此处保存的是**默认偏好**；临时点开合侧栏不会覆盖你的跨端偏好。

### 🎴 卡片边缘

| 样式 | 说明 |
| ---- | ---- |
| 阴影 | 层次感更强 |
| 边框 | 更干净利落 |

## 💾 设置如何保存

| 项目 | 行为 |
| ---- | ---- |
| 生效 | 点击后立即生效 |
| 账号同步 | 登录用户偏好写入服务端，换浏览器登录会带回 |
| 本机镜像 | 浏览器本地也有一份，便于秒开 |
| 历史用户 | 若账号里尚未保存过界面偏好，会继续沿用本机已有主题，不会被默认色强行覆盖 |

未登录（如登录页）使用本机主题缓存；**玻璃风格登录页默认展示必应壁纸**（出图接口无需登录，全站一日一图）。登录后以账号偏好为准（有有效配置时）。

## 📱 多端适配

- **手机 / 平板 / PC / 2K / 4K**：主题与壁纸均适配；壁纸会按屏幕清晰度选择合适分辨率档位  
- **移动端**：面板铺满侧滑宽度，选项触控友好；本地 / 网络输入与「应用」按钮纵向排布更稳  
- **玻璃 + 壁纸**：背景层固定在内容之下，不影响侧栏、弹窗与点击  

## 🎯 使用建议

1. **先选「玻璃」风格，再调壁纸与配色**；现代风格不显示壁纸区  
2. **内网环境**优先「默认渐变」或「本地文件」，不必依赖外网  
3. **必应每日**适合想每天换景、又不愿维护图片的用户  
4. **网络图片**请使用稳定的 https 图床直链，避免会过期的临时 URL  
5. 本地图建议用 **WebP / JPEG**，体积适中即可（过大可能加载更慢）  

## ❓ 常见问题

**换了浏览器主题丢了？**  
请确认两端都用同一账号登录。偏好在登录后从服务端同步；未登录只认本机。

**选了本地文件却仍是渐变？**  
检查文件是否在 `config/data/static/wallpaper/`，文件名是否与面板一致，以及扩展名是否为 webp/jpg/png/gif。

**网络图片一直失败？**  
确认链接可公网访问、是图片直链、协议为 http/https；内网 IP 与非图片内容会被拒绝。

**壁纸会不会拖慢系统？**  
不会影响业务接口。必应 / 网络图有约 1 天缓存；本地文件走静态长缓存。失败时自动回落渐变。

通过界面自定义，可以把 MediaSaber 调成更顺眼的工作台；玻璃风格叠加喜欢的配色，再配壁纸，整体会更通透、更有层次。
