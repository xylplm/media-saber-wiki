# 📅 订阅日历

> 订阅日历功能以日历形式可视化展示您的电影和电视剧订阅的上映时间，帮助您更好地规划媒体订阅和观看计划。支持多种视图模式和外部日历同步。

---

## 📋 功能概述

订阅日历提供了直观的日历视图来管理和查看您的媒体订阅时间安排，主要功能包括：

- **可视化时间轴**：以日历形式展示媒体的发布和上映时间
- **多视图支持**：支持月视图、周视图、日视图切换
- **媒体信息展示**：直接在日历上显示媒体海报和基本信息
- **外部同步**：支持导出到其他日历应用

---

## 🗓️ 日历视图

### 📊 视图模式

订阅日历支持多种视图模式，方便不同需求的查看：

#### 月视图
- **概览模式**：查看整月的媒体发布计划
- **密度较高**：适合查看长期安排
- **快速导航**：便于跨月份浏览

#### 周视图  
- **详细模式**：查看一周内的详细安排
- **中等密度**：平衡概览和细节
- **便于规划**：适合制定周度观影计划

#### 日视图
- **精细模式**：查看单日的所有发布内容
- **最高详度**：显示完整的媒体信息
- **当日聚焦**：专注于当天的内容

### 🎬 媒体信息显示

每个日历事件会显示以下信息：

#### 电影显示
- **媒体海报**：50x70像素的海报缩略图
- **电影标题**：完整的电影名称
- **发布年份**：电影的上映年份
- **事件类型**：标识为电影类型

#### 电视剧显示
- **媒体海报**：50x70像素的海报缩略图
- **剧集标题**：完整的电视剧名称
- **发布年份**：电视剧的首播年份
- **季集信息**：显示具体的季和集数信息(如S01E01)
- **事件类型**：标识为电视剧类型

### 🎯 数据来源

日历中的信息来源于：

- **已添加订阅**：所有已添加的电影和电视剧订阅
- **TMDB数据**：媒体的发布时间和基本信息
- **实时更新**：订阅变更时自动更新日历显示

## 📅 外部日历同步

订阅日历支持导出标准 iCal（.ics）格式，可将播出计划订阅到 Google Calendar、Apple Calendar、Outlook 等外部日历应用，实现跨平台同步。

### 🔑 前置条件：创建 API Key

iCal 订阅地址通过 API Key 鉴权，使用前需先创建：

1. 前往「账户设置」→「安全设置」→「API Key」
2. 点击「新增」，填写标题（例如：日历订阅），保存
3. 确认该 Key 处于**启用**状态

### 📋 获取订阅地址

1. 进入「订阅管理」→「订阅日历」页面
2. 点击右上角「iCal 日历」按钮
3. 如有多个 API Key，先在弹窗中选择用于订阅的 API Key
4. 点击「iCal 订阅链接」右侧的复制按钮

> ⚠️ 订阅地址包含您的 API Key，请勿分享给他人。
> 如需撤销访问权限，在「账户设置 → 安全设置 → API Key」中停用或删除对应 Key 即可。

### 📲 订阅到各日历应用

#### iOS / macOS 日历
1. 打开「设置」→「日历」→「账户」→「添加账户」→「其他」
2. 选择「添加已订阅的日历」
3. 粘贴订阅地址，点击「下一步」

#### Google 日历
1. 打开 [Google 日历](https://calendar.google.com) 网页版
2. 左侧点击「添加其他日历」→「通过 URL」
3. 粘贴订阅地址，点击「添加日历」

#### Outlook
1. 打开 Outlook 网页版，选择「添加日历」→「从 Internet 订阅」
2. 粘贴订阅地址，设置日历名称后点击「导入」

### ⚙️ 网络要求

外部日历客户端需要能访问到 Media Saber 的外网地址。
请确认「基础设置」→「外网访问地址」已正确配置，且外网可正常访问。

### 🗓️ 数据说明

| 项目 | 说明 |
|---|---|
| 时间范围 | 过去 7 天 + 未来 28 天 |
| 电视剧 | 每集一个日历事件，如：`异人之下 - S02E05` |
| 电影 | 每部一个日历事件，如：`星际穿越 (2014)` |
| 事件类型 | 全天事件（日期精度，来自 TMDB 播出数据） |
| 事件状态 | 已完成订阅 = 确认，订阅中 = 暂定 |

## 🧭 使用说明

### 基本操作

#### 查看日历
1. 进入"订阅管理" > "订阅日历"页面
2. 系统会自动加载所有订阅的媒体时间信息
3. 使用顶部的视图切换按钮选择合适的查看模式

#### 导航时间
- **上一个/下一个**：使用导航按钮切换时间段
- **今天按钮**：快速回到当前日期
- **日期选择**：点击日期标题进行快速跳转

#### 查看详情
- **悬停查看**：鼠标悬停在事件上查看基本信息
- **点击事件**：点击日历事件查看详细信息
- **海报显示**：自动加载并显示媒体海报

### 高级功能

#### 筛选显示
- **类型筛选**：可能支持按电影/电视剧类型筛选显示
- **状态筛选**：可能支持按订阅状态筛选显示
- **时间范围**：可能支持自定义时间范围显示

#### 个性化设置
- **主题配色**：可能支持自定义日历主题
- **信息密度**：可能支持调整显示信息的详细程度
- **时区设置**：可能支持不同时区的时间显示

---

## ⚙️ 配置要求

### 网络访问

#### 内网访问
- 确保Media Saber系统正常运行
- 本地网络可正常访问系统地址

#### 外网同步
- 需要配置[基础设置](/usage/system_settings/basic_settings.html)中的"外网访问地址"
- 确保外网可以正常访问Media Saber系统
- 防火墙需要开放相应端口

### 媒体数据

#### 订阅要求
- 需要先添加电影或电视剧订阅
- 订阅的媒体需要有准确的TMDB信息
- 发布时间信息来源于TMDB数据库

#### 数据同步
- 新增订阅会自动同步到日历
- 删除订阅也会从日历中移除
- 修改订阅信息会更新日历显示

## 🎯 使用技巧

### 规划观影
1. **提前规划**：通过月视图查看即将发布的内容
2. **周度安排**：使用周视图制定具体的观影计划
3. **当日提醒**：通过日视图确认当天的新内容

### 外部同步优化
1. **定期检查同步**：确保外部日历能正常获取更新
2. **网络稳定性**：保证外网访问的稳定性
3. **权限管理**：不再使用的订阅地址可通过停用或删除 API Key 撤销

### 数据管理
1. **及时更新订阅**：保持订阅列表的准确性
2. **清理历史数据**：定期清理不需要的订阅历史
3. **关注发布变更**：注意媒体发布时间的变化

---

## ⚠️ 注意事项

### 技术限制
1. **网络依赖**：外部日历同步需要稳定的网络连接
2. **数据准确性**：日历信息依赖于TMDB数据的准确性
3. **同步延迟**：外部日历应用可能存在数据同步延迟

### 使用建议
1. **合理设置**：根据实际需求配置外网访问
2. **隐私保护**：注意iCal链接的安全性，避免泄露给无关人员
3. **定期维护**：定期检查日历同步状态和数据准确性

### 兼容性
1. **应用支持**：确认目标日历应用支持iCal格式
2. **版本兼容**：部分旧版本日历应用可能存在兼容性问题
3. **功能差异**：不同日历应用对iCal的支持程度可能不同
