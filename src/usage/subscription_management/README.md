# 📺 订阅管理

> 订阅管理功能允许用户通过RSS订阅和主动搜索的方式自动获取感兴趣的媒体内容，包括电影、电视剧等。系统支持智能过滤、排序规则和多站点订阅，实现全自动化的媒体获取。

---

> 💡 除了网页端，还可以在豆瓣、哔哩哔哩、腾讯视频、爱奇艺、优酷、YouTube、Netflix 的影片页一键添加订阅——使用[浏览器扩展的影视页快捷订阅](/client/brower_tool/web-enhancement.html)。

## 📋 功能模块

订阅管理包含以下主要功能模块：

### 🎬 [电影订阅](/usage/subscription_management/movie_subscription.html)
管理和配置电影订阅，通过RSS订阅和主动搜索自动获取感兴趣的电影。

### 📺 [电视剧订阅](/usage/subscription_management/tv_subscription.html)
管理和配置电视剧订阅，支持按季或按集订阅，自动跟踪更新。

### 🛠️ [自定义订阅](/usage/subscription_management/custom_subscription.html)
创建和管理自定义订阅规则，满足特殊订阅需求。

### 📅 [订阅日历](/usage/subscription_management/subscription_calendar.html)
以日历形式展示订阅内容的更新时间，方便用户了解订阅内容的更新计划。

## 🔑 核心概念

### RSS订阅
RSS订阅是通过站点提供的RSS订阅源自动获取资源信息的方式。系统会定期检查订阅源，发现新资源后自动下载。

### 主动搜索
主动搜索是系统按照设定的时间间隔，使用用户配置的关键词在指定站点搜索资源的方式。相比RSS订阅，主动搜索能发现更多资源。

### 订阅状态
订阅内容可能处于以下状态：
- **正在订阅**：订阅已启用，正在等待新资源
- **搜索中**：系统正在搜索该订阅相关的资源
- **已暂停**：临时停追，系统不再为它搜索和下载，随时可恢复
- **已完成**：订阅的目标已达成（如电影已下载，或电视剧已完结）

### 过滤规则
过滤规则用于筛选符合要求的资源，可以根据分辨率、制作组、文件大小等条件过滤资源。详细配置请参考 [过滤规则](/usage/system_settings/filter_rules.html)。

### 排序规则
排序规则用于对搜索到的资源进行智能排序，通过配置不同维度的权重来确定资源的优先级。详细配置请参考 [种子排序](/usage/system_settings/torrent_sort.html)。

### 种子匹配
种子匹配规则用于精确控制种子的筛选条件，可以被过滤规则和排序规则引用。详细配置请参考 [种子匹配](/usage/system_settings/torrent_match.html)。

### 跟随默认
订阅的下载器、站点、过滤规则、保存路径等配置，都可以在「跟随默认」与「自定义」之间切换：

- **跟随默认**（推荐）：该字段不单独设置，始终使用 [默认设置](/usage/subscription_management/tv_subscription.html#⚙️-默认设置) 中的值——之后在默认设置里改一下，所有跟随中的订阅**立即同步生效**，无需逐个修改
- **自定义**：该字段为本订阅单独设置，不受默认设置变化影响

新增订阅时所有配置默认跟随，只有你亲自改过的字段才会转为自定义；列表卡片上用「跟随默认」徽标标识完全跟随的订阅。

### 集数地图
编辑电视剧订阅时可以直观地挑选要补订的集数：缺失的集可点选，已入库（✓）和下载中（↓）不可选，未播出的集可提前预定。适合「只补某几集」「跳过已下载的集」等精细场景，详见 [电视剧订阅 - 集数地图](/usage/subscription_management/tv_subscription.html#🗺️-集数地图)。

## 🔄 工作流程

订阅管理的基本工作流程如下：

1. **添加订阅**：通过搜索或直接添加的方式创建订阅
2. **配置参数**：设置订阅的筛选条件、下载设置等参数
3. **自动检索**：系统通过RSS订阅和主动搜索发现资源
4. **资源筛选**：根据过滤规则筛选符合条件的资源
5. **自动下载**：将符合条件的资源添加到下载器进行下载
6. **文件整理**：下载完成后自动进行文件整理和媒体库更新

> 💡 订阅新增与编辑现已合并为统一窗口，并按基础信息、高级设置、站点选择分区展示。主页面点击「新增订阅」会直接打开新增窗口，默认创建电影订阅，并可在窗口顶部切换为电视剧；编辑已有订阅时类型固定，不显示切换。

## ⏸️ 暂停与恢复

临时不想追某部剧、或想在忙碌时段停下下载，可以**暂停订阅**而不用取消：

- 在订阅卡片的快捷菜单中选择「**暂停订阅**」；暂停后状态显示为灰色「已暂停」，系统不再为它执行 RSS 检查、搜索和下载，追剧提醒和健康中心缺集提示也会一并静默
- 想继续追时选择「**恢复订阅**」，系统会自动补搜一次，把暂停期间错过的更新追回来
- **运行中的订阅也可以直接暂停**；在编辑窗口遇到「运行中不能修改」提示时，点「暂停并编辑」即可解锁修改，保存后保持暂停态

## 🎯 一键对齐默认设置

订阅积累多了，想把老订阅也纳入「跟随默认」时，无需逐条修改：订阅列表右上角「更多」菜单提供「**对齐默认设置**」——系统先预览哪些订阅的哪些配置与当前默认设置一致，确认后一键转为跟随（运行中的订阅也可安全转换，已完成的除外）。转换后这些订阅将随默认设置的调整即时联动。

## 🧰 批量操作

订阅较多时，可在订阅列表对多条订阅一次性处理，无需逐条操作。

### 进入与退出

- 点击订阅列表右上角「更多」菜单中的「批量操作」进入批量模式。
- 进入后，点击卡片即可选中或取消选中，卡片右上角会出现选择框。
- 顶部提供「全选 / 取消全选」；点击右上角「✕」退出批量模式。

### 可执行的操作

选中至少一条订阅后，屏幕底部会浮现操作条，显示已选数量，并提供以下操作：

- **批量编辑**：弹出批量编辑窗口，逐项选择「不修改 / 跟随默认 / 设为指定值」三种模式（覆盖过滤规则、排序规则、下载器、下载参数、保存路径、RSS 站点、搜索站点、包含、排除）。设为「跟随默认」的字段将与默认设置联动，改默认即时生效；「设为指定值」才会应用到所选订阅。
- **重新搜索**：对所选订阅批量发起一次资源搜索。
- **取消订阅**：批量取消所选订阅，需二次确认，取消后无法恢复。

> 💡 重新搜索与取消订阅会逐条执行并显示进度，单条失败不影响其余订阅，结束后汇总成功与失败数量。切换电影/电视剧筛选时会清空已选项，避免误操作到看不见的订阅。

## ⚙️ 相关设置

订阅管理功能的相关设置可以在以下位置找到：

- **[基础设置](/usage/system_settings/basic_settings.html)**：配置订阅的基本参数，如搜索周期、默认过滤和排序规则等
- **[过滤规则](/usage/system_settings/filter_rules.html)**：配置种子过滤规则，支持规则组文件导入导出
- **[种子匹配](/usage/system_settings/torrent_match.html)**：配置种子匹配条件，可被过滤和排序规则引用
- **[种子排序](/usage/system_settings/torrent_sort.html)**：配置基于权重的智能排序规则
- **[站点管理](/usage/site_management/site.html)**：配置用于订阅和搜索的站点
- **[下载管理](/usage/download_management/)**：配置下载器和下载参数
- **[目录管理](/usage/directory_management/directory_management.html)**：配置资源保存目录

电影默认设置和电视剧默认设置仍是两个独立入口，分别保存各自类型的默认配置。与旧版不同，默认设置现在是「跟随默认」订阅的**实时生效配置**——修改后立即作用于所有跟随中的订阅，而不仅是新增订阅的初始值。

## 📝 注意事项

- 合理设置订阅参数，避免订阅过多导致系统资源占用过高
- 定期检查订阅状态，及时更新已失效的订阅
- 根据网络环境和存储空间选择合适的过滤规则
- 注意站点的使用规则，避免过于频繁的搜索影响站点稳定性
