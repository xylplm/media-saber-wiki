# 云存储管理

云存储页面用于浏览已配置的云盘目录，并执行上传、转存和离线下载等操作。

## 📁 浏览文件

- 点击文件夹进入下一级目录。
- 使用面包屑返回上级目录。
- 使用搜索查找文件或目录。
- 支持新建文件夹、重命名和删除等操作。
- 批量选择文件后执行移动、复制或删除。

## ⬆️ 上传文件

1. 打开云存储页面并进入目标目录。
2. 点击上传按钮，选择本地文件。
3. 等待任务完成并刷新文件列表。

部分页面支持将文件拖入上传区域。大文件上传期间请保持浏览器页面和网络连接稳定。

## 🔗 链接转存

1. 打开云存储页面。
2. 点击“转存”或通过网页右键菜单打开转存对话框。
3. 粘贴云盘分享链接或网络链接。
4. 选择云存储目标目录。
5. 点击“开始转存”。

## 📥 离线下载

支持根据服务端配置使用 HTTP、FTP、磁力、电驴或 BT 种子链接发起云端离线下载：

1. 打开离线下载对话框。
2. 填写或粘贴下载链接。
3. 选择云存储保存路径。
4. 点击“开始下载”。
5. 在任务列表查看执行状态。

## 🧩 浏览器扩展辅助获取认证信息

部分云盘需要 Cookie 或 Token。可以先在浏览器中登录云盘，再使用 Media Saber Tools 获取认证信息并填入服务端配置。

使用前请确认：

- 扩展已完成首次配置。
- 浏览器当前登录的是正确账号。
- 不要把 Cookie、Token 或分享链接发送给他人。
