# 常见问题

## ❌ 无法连接 Media Saber

检查以下内容：

1. Media Saber 服务端是否正在运行。
2. 浏览器是否能打开服务地址。
3. 扩展中的协议、域名和端口是否正确。
4. 反向代理、HTTPS 证书和防火墙是否正常。
5. 用户名和密码是否可以登录 Web 页面。

## ❌ Cookie 获取失败

- 确认已在当前浏览器登录目标站点。
- 退出站点后重新登录，再回到扩展同步。
- 检查扩展的网站访问权限。
- 确认目标站点没有被浏览器隐私策略阻止。
- 不要在无痕窗口中使用未允许无痕模式的扩展。

## ❌ CRX 无法安装

Chrome、Edge 和其他 Chromium 浏览器可能限制直接安装 CRX。这通常是浏览器安全策略，不代表文件损坏。

处理方法：

1. 使用对应的官方扩展商店版本。
2. 下载 `.zip` 并通过开发者模式“加载已解压的扩展程序”。
3. 如果下载 `.crx.zip`，先解压得到 `.crx`，再尝试拖拽安装。

## ❌ 网页没有显示下载按钮

- 刷新当前网页。
- 确认扩展已启用并允许访问当前网站。
- 确认当前页面不是 `chrome://` 等浏览器内部页面。
- 检查页面是否为支持的 PT 站点或包含可识别链接。
- 在扩展管理页重新加载扩展后，再刷新网页。

## ❌ 下载任务失败

- 确认下载器在线。
- 检查下载器地址、端口和认证配置。
- 确认下载目录存在且有写入权限。
- 确认链接没有过期或需要额外登录。
- 查看 Media Saber 服务端和下载器日志。

## ❌ Firefox 关闭后扩展消失

Firefox 使用“临时载入附加组件”时，扩展会在浏览器关闭后失效。这是 Firefox 的工作方式。需要长期使用时，请从 [Firefox 附加组件](https://addons.mozilla.org/zh-CN/firefox/addon/media-saber-tools/) 安装商店版本；开发版 / ESR 请按对应浏览器的签名策略安装。

## ❌ Safari 无法直接安装

Safari Web Extension 通常需要通过 Xcode 封装为应用后才能启用。请确认使用 macOS 和 Xcode，并参考 [安装扩展](./installation.md) 中的 Safari 章节。

## 🧪 查看调试信息

1. 打开浏览器扩展管理页。
2. 找到 Media Saber Tools。
3. 点击“检查视图”或“Service Worker”。
4. 查看控制台和网络请求错误。

反馈问题时，请提供：

- 浏览器名称和完整版本。
- 扩展安装包格式或商店来源。
- Media Saber 版本。
- 操作步骤和错误信息。
- 脱敏后的控制台日志。

> 请勿在反馈中提交密码、Cookie、Token 或完整服务端敏感信息。
