# 首次配置

安装扩展后，需要填写 Media Saber 服务地址和登录信息，才能使用站点同步、云存储和下载等功能。

## 🔧 配置步骤

1. 点击浏览器工具栏中的 Media Saber Tools 图标。
2. 在登录页面填写 Media Saber 服务地址。
   - 例如：`http://192.168.1.100:3001`
   - 地址应填写浏览器可以访问的服务地址，不要填写仅 Docker 容器内部可访问的地址。
3. 填写 Media Saber 用户名和密码。
4. 点击“登录”或“测试连接”。
5. 连接成功后进入扩展主界面。

## ✅ 连接检查

如果登录失败，请依次检查：

- 服务端是否正在运行。
- 浏览器是否可以打开服务地址。
- 地址中的协议、域名、端口是否正确。
- 反向代理或 HTTPS 证书是否正常。
- 用户名和密码是否可以登录 Media Saber Web 页面。
- 浏览器是否拦截了扩展请求或弹出了权限提示。

## 🔐 登录信息安全

- 不要把账号密码、Cookie 或 Token 发给他人。
- 只在可信浏览器中安装扩展。
- 共享电脑使用后请退出账号。
- 如果怀疑凭据泄露，请及时修改服务端密码并重新登录扩展。

## 🔄 更换服务器

需要切换 Media Saber 服务时，打开扩展设置或登录界面，修改服务地址并重新测试连接。切换后应检查站点列表、下载器和云存储配置是否来自新的服务端。

## 🧪 首次验证

建议完成登录后依次验证：

1. 打开站点管理，确认可以读取站点列表。
2. 打开站点数据，确认能获取上传、下载和做种信息。
3. 打开云存储，确认目录可以正常加载。
4. 打开下载管理，确认下载器列表可以读取。
5. 在测试网页中确认磁力链接按钮或右键菜单正常显示。
