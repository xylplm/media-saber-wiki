# 首次配置

安装扩展后，需要填写 Media Saber 服务地址和登录信息，才能使用站点同步、云存储和下载等功能。

## 🔧 配置步骤

登录分两步：先填写服务器地址，再选择登录方式。

1. 点击浏览器工具栏中的 Media Saber Tools 图标。
2. 第一步：填写 Media Saber 服务地址，点击“下一步”。
   - 例如：`http://192.168.1.100:3001`
   - 地址应填写浏览器可以访问的服务地址，不要填写仅 Docker 容器内部可访问的地址。
   - 点击“下一步”时扩展会先探测服务器连通性，地址打错会当场提示，通过后才进入第二步。
3. 第二步：选择登录方式。
   - 密码登录：填写用户名和密码。
   - 扫码登录：用手机 Media Saber App 扫码确认，无需输入密码。
4. 登录成功后进入扩展主界面。

登录成功过的服务器地址会被记住，下次打开扩展自动带出并直接进入第二步；需要更换服务器时，点击第二步顶部的“更换”返回。

## 📱 扫码登录

不想在电脑上输入密码时，可以用手机 App 扫码登录扩展：

1. 第一步填写 Media Saber 服务地址，点击“下一步”。
2. 第二步点击「扫码登录」切换到扫码模式。
3. 打开手机 Media Saber App，在「我的」页面点击右上角扫一扫图标。
4. 扫描扩展上的二维码，并在手机上点「确认登录」，扩展即自动登录。

说明：

- 扫码入口由服务端「扫码登录」开关控制（安全设置 → 单点登录 → 扫码登录），关闭时第二步只显示密码登录。
- 每次登录的二维码 2 分钟内有效，过期或取消后点「刷新二维码」重新生成。
- 登录失效后重新打开扩展，服务器地址还在并直达第二步，重新扫一次码就能登录。

## ✅ 连接检查

如果登录失败，请依次检查：

- 服务端是否正在运行。
- 浏览器是否可以打开服务地址。
- 地址中的协议、域名、端口是否正确。
- 反向代理或 HTTPS 证书是否正常。
- 用户名和密码是否可以登录 Media Saber Web 页面。
- 浏览器是否拦截了扩展请求或弹出了权限提示。

## 🔐 登录信息安全

- 不要把账号密码、Cookie 或 Token 发给他人。
- 只在可信浏览器中安装扩展。
- 共享电脑使用后请退出账号。
- 如果怀疑凭据泄露，请及时修改服务端密码并重新登录扩展。

## 🔄 更换服务器

需要切换 Media Saber 服务时，打开扩展设置或登录界面，修改服务地址并重新测试连接。切换后应检查站点列表、下载器和云存储配置是否来自新的服务端。

## 🧪 首次验证

建议完成登录后依次验证：

1. 打开站点管理，确认可以读取站点列表。
2. 打开站点数据，确认能获取上传、下载和做种信息。
3. 打开云存储，确认目录可以正常加载。
4. 打开下载管理，确认下载器列表可以读取。
5. 在测试网页中确认磁力链接按钮或右键菜单正常显示。
