# 下载管理

下载管理用于查看 Media Saber 服务端提交给下载器的任务，并从网页快速创建下载任务。

## 📋 任务管理

可在下载管理页面查看：

- 等待、下载中、已完成和失败状态。
- 文件大小、速度和预计剩余时间。
- 任务创建时间和错误信息。

根据服务端和下载器能力，可以执行暂停、恢复、删除、重试和调整优先级等操作。

## 🧲 添加磁力下载

1. 打开下载管理页面的磁力下载对话框。
2. 填写或确认磁力链接。
3. 选择下载器，例如 qBittorrent 或 Transmission。
4. 选择下载参数。
5. 选择下载目录。
6. 点击“确定添加”。

在网页中发现磁力链接时，也可以直接使用链接旁的下载按钮或右键菜单。

## 📄 添加种子下载

可以通过上传种子文件或填写种子链接创建任务：

1. 选择种子文件或粘贴种子链接。
2. 选择下载器和下载参数。
3. 选择下载目录。
4. 确认提交任务。

## 🎞️ PT 站种子下载

在支持的 PT 站点种子详情页：

1. 打开种子详情页并确认已登录。
2. 点击页面中的 Media Saber 下载按钮。
3. 在扩展弹出的对话框中选择下载器、下载参数和下载目录。
4. 点击“确定下载”。

扩展会将当前种子详情页链接发送到 Media Saber 服务端，由服务端获取种子并提交给下载器。

## ⚠️ 任务失败排查

- 检查下载器是否在线。
- 检查下载器连接配置和认证信息。
- 确认下载目录在下载器中存在且有写入权限。
- 检查磁力、种子或 PT 页面链接是否完整。
- 查看 Media Saber 服务端日志中的具体错误。
