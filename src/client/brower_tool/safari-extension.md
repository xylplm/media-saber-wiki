# Safari 扩展（iOS 版 App 内置）

iOS 版 Media Saber App 内置了同款「Media Saber Tools」Safari 浏览器扩展：无需单独安装，在 iPhone 或 iPad 的 Safari 里就能使用站点、云存储、下载管理和右键快捷操作等完整功能。

扩展会直接连接你的 Media Saber 服务器工作，App 只负责把当前登录账号同步给它——App 不在线时扩展也能正常使用。

## 📱 适用范围

- 平台：iOS / iPadOS 版 Media Saber App（iPhone、iPad 均可）。
- 系统：iOS 15 及以上（Safari Web Extension 要求）。
- 安卓版 App 没有浏览器扩展，也不需要任何相关设置。

## 🔌 启用扩展

首次使用需要在系统设置里手动打开一次：

1. 打开 iOS「设置」→「Safari」→「扩展」（或「设置」→「App」→「Safari」→「扩展」）。
2. 找到「Media Saber Tools」，打开「允许」开关。
3. 进入该扩展的权限设置，把「所有网站」设为「允许」（或按需逐个网站授权）。
4. 也可以在 Safari 内点击地址栏的「拼图」按钮（扩展图标），从菜单里管理扩展权限。

启用后，在 Safari 中即可通过工具栏扩展按钮打开功能面板（popup），部分网页还会出现下载浮动按钮和右键菜单入口。

## 🔑 同步登录账号

扩展有独立登录页。最省事的方式是让 App 把当前账号写进去，扩展下次打开时自动填入：

1. 打开 Media Saber App →「更多」→「扩展与站点」→「Safari 扩展」。
2. 点击「写入当前账号」。
3. 打开 Safari 的扩展面板，扩展会自动退出旧会话并在登录页填入 App 当前账号，确认即可。

几点说明：

- 写入的账号密码只在本机共享，且 15 分钟内有效；扩展领取后立即删除，不会长期保存。
- 如果扩展里已经登录了另一个账号，写入时 App 会弹窗提醒并要求确认，确认后扩展会在下次打开时切换账号。
- 使用「SSO 登录」的账号没有保存密码，无法直接写入；请先在 App 里退出并用账号密码重新登录一次。
- 不想用自动写入也可以在扩展面板里手动登录。

## ✨ 能做什么

- 功能面板：站点数据、云存储管理、下载管理、用户信息等页面。
- 右键菜单：对选中链接快速发起磁力 / 种子 / 链接下载。
- 网页增强：PT 页面、磁力链接、网盘资源上的浮动下载按钮。
- 离线下载：把链接直接交给 Media Saber 服务器下载（需已在服务端配置好下载器）。

## ❓ 常见问题

**扩展列表里找不到 Media Saber Tools？**
确认手机上已安装 iOS 版 App；若刚安装，重启一次 Safari 或重新打开设置页再查看。

**扩展打开后一直停在登录页？**
在 App 里重新「写入当前账号」，然后在 15 分钟内打开扩展面板；或直接在扩展登录页手动输入账号密码。

**提示无法连接服务器？**
扩展直连你的 Media Saber 服务器地址，请确认服务器在线、地址正确，且手机网络可以访问它（外网地址需公网可达，内网地址需处于同一网络）。

**换账号了怎么办？**
App 里切换账号后，重新进入「Safari 扩展」点击「写入当前账号」即可覆盖。
