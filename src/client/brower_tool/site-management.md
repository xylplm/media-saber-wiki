# 站点管理

站点管理用于读取浏览器中已登录的 PT 站点信息，并与 Media Saber 服务端的站点配置进行对比和同步。

## 🔄 同步站点

1. 在浏览器中正常登录目标 PT 站点。
2. 点击工具栏中的 Media Saber Tools 图标。
3. 进入“站点管理”页面。
4. 等待扩展读取浏览器中的站点信息。
5. 根据差异筛选需要同步的站点。
6. 点击“更新”或对应的同步按钮。

扩展会读取站点 Cookie 和 User-Agent，并将信息发送到已配置的 Media Saber 服务端。

## 🔍 筛选方式

| 筛选项 | 含义 |
|---|---|
| 浏览器 | 浏览器中已登录的站点 |
| 服务器 | Media Saber 中已经配置的站点 |
| Cookie 差异 | 浏览器和服务器 Cookie 不一致 |
| UA 差异 | 浏览器和服务器 User-Agent 不一致 |
| 未添加 | 浏览器已登录但服务器尚未配置 |

## 🍪 Cookie 失效

如果站点显示需要登录、数据无法读取或签到失败：

1. 在浏览器中退出目标站点。
2. 重新登录目标站点。
3. 回到扩展的站点管理页面重新获取信息。
4. 选择站点并执行同步。

也可以直接在 Media Saber 站点配置中手动更新 Cookie。请不要把 Cookie 分享给他人。

## 📊 站点数据

站点数据页面通常包含：

- 上传量和下载量。
- 做种数量和活跃度。
- 站点等级、积分和魔力值。
- 数据刷新时间和站点状态。

如果数据加载失败，请先确认站点登录状态、Cookie 有效期和服务端网络是否正常。

## 🔐 安全提示

- 只在可信浏览器中安装扩展。
- 不要在公共电脑中长期保持 PT 站点登录状态。
- 不要在截图、日志或聊天中暴露完整 Cookie。
- 同步前确认扩展连接的是自己的 Media Saber 服务。
