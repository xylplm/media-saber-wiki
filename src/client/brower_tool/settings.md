# 设置与权限

扩展的设置页面用于管理同步方式、通知和部分运行行为。浏览器扩展管理页中的权限决定了网页增强和站点同步能否正常工作。

## 🔄 同步设置

在用户信息或扩展设置中，可以根据版本支持情况配置：

- 每日首次更新。
- 定时更新。
- 后台静默同步。
- 手动立即同步。

首次使用建议先执行一次手动同步，确认服务地址、账号和站点权限均正常，再开启后台或定时同步。

## 🔔 通知设置

扩展可能通过以下方式提示任务结果：

- 浏览器桌面通知。
- 扩展页面内通知。
- 下载任务状态提示。
- 站点同步结果提示。

如果没有收到通知，请检查浏览器系统通知权限、扩展通知权限和操作系统的勿扰模式。

## 🎬 影视页快捷订阅开关

在扩展「用户信息」页的「内嵌功能设置」中可以管理影视页订阅按钮：

- **影视页快捷订阅**：总开关，关闭后所有影视网站都不再显示订阅按钮。
- **站点级开关**：可单独关闭某个站点（如豆瓣、哔哩哔哩）的订阅按钮。

开关修改后刷新对应页面即可生效。

## 🔐 浏览器权限说明

| 权限 | 用途 |
|---|---|
| `cookies` | 读取和同步 PT 站点登录 Cookie |
| `storage` | 保存服务地址、登录状态和用户配置 |
| `activeTab` | 获取当前标签页信息 |
| `scripting` | 向网页注入链接识别和下载按钮 |
| `contextMenus` | 提供网页右键快捷操作 |
| `notifications` | 显示同步和任务结果通知 |
| `alarms` | 执行定时同步和检查任务 |
| 网站访问权限 | 识别网页链接和支持站点 |

这些权限用于扩展的核心功能。若关闭相关权限，站点同步、网页按钮或右键菜单可能无法使用。

## 🛡️ 隐私与安全

- 扩展只应安装来自官方商店或项目固定 Release 的版本。
- 不要把 Cookie、Token、账号密码或服务地址发送给陌生人。
- 公共电脑上使用完毕后及时退出扩展账号。
- 使用 `.crx` 手动包时，确认文件来自项目 Release 页面。
- 如果不再使用某项能力，可以在浏览器扩展管理页关闭对应的网站访问权限。

## 🔧 重新加载扩展

使用 `.zip` 手动安装的版本升级后：

1. 覆盖原扩展目录。
2. 打开浏览器扩展管理页。
3. 点击 Media Saber Tools 的“重新加载”。
4. 刷新已经打开的网页，让内容脚本重新注入。
