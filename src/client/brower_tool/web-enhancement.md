# 网页增强

网页增强功能会在支持的页面中识别下载链接，并提供 Media Saber 快捷操作。

## 🔗 链接识别

扩展可以识别网页中的：

- 磁力链接（`magnet:`）。
- 电驴链接（`ed2k:`）。
- 部分 PT 站点的种子详情页。

识别到链接后，页面附近可能出现 Media Saber 下载按钮或云端离线按钮。

## 🟢 磁力下载按钮

点击磁力下载按钮后，扩展会：

1. 打开扩展主界面。
2. 跳转到下载管理页面。
3. 打开磁力下载对话框。
4. 自动填入当前磁力链接。
5. 等待你选择下载器、下载参数和下载目录。

## 🔵 云端离线按钮

点击云端离线按钮后，扩展会：

1. 打开扩展主界面。
2. 跳转到云存储页面。
3. 打开离线下载对话框。
4. 自动填入当前链接。
5. 等待你选择云存储目标路径。

## 🖱️ 右键菜单

在网页中选中链接或文本后右键，可以使用：

- 磁力下载。
- 云端离线下载。
- 云盘转存。
- 快速打开扩展功能页面。

扩展会尽量将选中的文本自动填入对应对话框。

## 🎞️ PT 站点集成

在支持的 NexusPHP 等 PT 站点种子详情页，扩展可能显示“Media Saber PT 种子下载”按钮。点击后选择下载器、下载参数和下载目录，即可将任务提交到 Media Saber。

如果按钮没有出现，请检查：

- 是否已登录 PT 站点。
- 当前页面是否为种子详情页。
- 扩展是否已启用。
- 页面是否在扩展匹配范围内。
- 是否需要刷新页面让内容脚本重新加载。

## 📺 影视页快捷订阅

在主流影视网站的详情页/播放页，扩展会在标题附近插入一枚贴站点品牌色的「订阅」按钮，直接把影片加入 Media Saber 订阅。

**支持的站点**：豆瓣、哔哩哔哩（番剧）、腾讯视频、爱奇艺、优酷、YouTube、Netflix。其余页面不会出现按钮。

**按钮状态**：

- 「＋ 订阅」：尚未订阅，点击即可添加。
- 「✓ 已订阅」：已有进行中的订阅，点击直接打开编辑。

**添加流程**：点击按钮后扩展会自动识别影片（匹配 TMDB 信息并显示海报），确认卡片上的标题、年份、季数无误后，点「确认订阅」即可完成。需要调整过滤规则、下载器、站点范围等高级配置时，点「自定义订阅…」进入完整表单，字段与网页端订阅编辑一致。

**管理订阅**：扩展侧边栏新增了「订阅」页，可以筛选、分页浏览订阅列表，并进行暂停/恢复、编辑、手动搜索、删除等操作。

**站点开关**：在扩展「用户信息 → 内嵌功能设置」中，可以单独关闭某个站点的订阅按钮，也可以整体关闭影视页快捷订阅。

**说明**：

- 未登录 Media Saber 时不会显示订阅按钮，登录后回到页面按钮会自动出现。
- 若页面结构特殊导致按钮无法贴在标题旁，会退而显示在页面右上角，功能不受影响。
- 站内切换剧集时按钮会自动刷新状态；在扩展里完成订阅后切回页面，按钮也会自动变为「已订阅」。

## 🧪 页面没有出现按钮

1. 刷新当前页面。
2. 确认扩展图标没有被浏览器禁用。
3. 在扩展管理页检查站点访问权限。
4. 确认当前页面不是浏览器内部页面，例如 `chrome://` 页面。
5. 打开开发者工具，检查内容脚本是否有报错。
