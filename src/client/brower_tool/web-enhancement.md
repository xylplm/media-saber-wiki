# 网页增强

网页增强功能会在支持的页面中识别下载链接，并提供 Media Saber 快捷操作。

## 🔗 链接识别

扩展可以识别网页中的：

- 磁力链接（`magnet:`）。
- 电驴链接（`ed2k:`）。
- 部分 PT 站点的种子详情页。

识别到链接后，页面附近可能出现 Media Saber 下载按钮或云端离线按钮。

## 🟢 磁力下载按钮

点击磁力下载按钮后，扩展会：

1. 打开扩展主界面。
2. 跳转到下载管理页面。
3. 打开磁力下载对话框。
4. 自动填入当前磁力链接。
5. 等待你选择下载器、下载参数和下载目录。

## 🔵 云端离线按钮

点击云端离线按钮后，扩展会：

1. 打开扩展主界面。
2. 跳转到云存储页面。
3. 打开离线下载对话框。
4. 自动填入当前链接。
5. 等待你选择云存储目标路径。

## 🖱️ 右键菜单

在网页中选中链接或文本后右键，可以使用：

- 磁力下载。
- 云端离线下载。
- 云盘转存。
- 快速打开扩展功能页面。

扩展会尽量将选中的文本自动填入对应对话框。

## 🎞️ PT 站点集成

在支持的 NexusPHP 等 PT 站点种子详情页，扩展可能显示“Media Saber PT 种子下载”按钮。点击后选择下载器、下载参数和下载目录，即可将任务提交到 Media Saber。

如果按钮没有出现，请检查：

- 是否已登录 PT 站点。
- 当前页面是否为种子详情页。
- 扩展是否已启用。
- 页面是否在扩展匹配范围内。
- 是否需要刷新页面让内容脚本重新加载。

## 🧪 页面没有出现按钮

1. 刷新当前页面。
2. 确认扩展图标没有被浏览器禁用。
3. 在扩展管理页检查站点访问权限。
4. 确认当前页面不是浏览器内部页面，例如 `chrome://` 页面。
5. 打开开发者工具，检查内容脚本是否有报错。
