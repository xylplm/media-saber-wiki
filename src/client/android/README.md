## 🎯 核心功能

### 媒体库管理
- 📚 集中管理电影、电视剧、音乐等媒体文件
- 🎬 从TMDB获取详细信息、评分、海报、简介
- ⭐ 评分和收藏功能
- 🎯 按类型、年份、评分等多维度分类筛选
- 🖼️ 显示高质量的海报、背景图片和剧照

### 日历视图
- 📅 以日历形式查看媒体发布日期和更新时间
- 📆 快速定位特定日期的内容更新
- 🔍 按日期快速查找感兴趣的内容

### 智能推荐
- 🤖 基于观看历史的智能推荐
- ⭐ 热门推荐和评分排行
- 🌟 个性化推荐算法

### 文件浏览和管理
- 📁 完整的文件浏览器（本地、云盘、远程服务器）
- 🔄 自动分析媒体文件的元数据和编码信息
- 📊 按文件类型自动分类
- 🎬 内置视频播放器，支持多种视频格式
- 📥 批量复制、移动、删除文件

### 下载管理
- ⬇️ 支持 Aria2、qBittorrent、Transmission 等多源下载
- 📌 下载任务查看、暂停、恢复、取消
- 📊 实时显示下载速度、剩余时间、进度条
- 🔗 支持BT种子、磁力链接等多种方式
- 🎯 管理下载队列，支持优先级调整

## 🎯 使用技巧

### 提高效率
✅ **建议**:
1. 自定义主页模块，放置常用功能
2. 使用搜索而不是逐级浏览
3. 启用下载提醒，及时完成任务
4. 定期查看统计数据，了解使用习惯
5. 利用Android小部件快速访问常用功能

### 最佳实践
✅ **最佳做法**:
1. 及时更新应用，获得最新功能和安全修复
2. 定期备份个人数据和收藏信息
3. 使用复杂密码和双因素认证保护账户
4. 在WiFi环境下进行大文件传输
5. 检查应用权限，只授予必要的权限

### 问题解决
❓ **常见问题**:
1. **应用闪退** - 清除应用缓存，重新安装
2. **无法连接云盘** - 检查账户密码和网络连接
3. **下载速度慢** - 检查网络质量，尝试使用其他下载源
4. **通知收不到** - 检查通知权限和推送服务设置
5. **文件无法播放** - 尝试更新应用或更换播放器
