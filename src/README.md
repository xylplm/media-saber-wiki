## 🎯 为什么选择 Media Saber？

::: info 🚀 极致性能
采用现代化技术栈（Angular + Flutter + GO），为你提供流畅快速的使用体验
:::

::: tip 🔒 安全可靠
完全自主开发，私有部署，你的数据完全在自己掌控之中
:::

::: note ✨ 功能全面
从媒体搜索到自动整理，从订阅管理到多端同步，一站式解决所有需求
:::
